# zpotri

> Computes the inverse of a complex Hermitian positive definite matrix A using the Cholesky factorization A = Uᴴ·U or A = L·Lᴴ computed by ZPOTRF.

<section class="usage">

## Usage

```javascript
var zpotri = require( '@stdlib/lapack/base/zpotri' );
```

#### zpotri( order, uplo, N, A, LDA )

Computes the inverse of a complex Hermitian positive definite matrix A using the Cholesky factorization A = Uᴴ·U or A = L·Lᴴ computed by ZPOTRF.

```javascript
var zpotri = require( '@stdlib/lapack/base/zpotri' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

zpotri.ndarray( 'upper', N, A, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### zpotri.ndarray( uplo, N, A, strideA1, strideA2, offsetA )

Computes the inverse of a complex Hermitian positive definite matrix A using the Cholesky factorization A = Uᴴ·U or A = L·Lᴴ computed by ZPOTRF, using alternative indexing semantics.

```javascript
var zpotri = require( '@stdlib/lapack/base/zpotri' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

zpotri.ndarray( 'upper', N, A, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZPOTRI`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZPOTRI computes the inverse of a complex Hermitian positive definite matrix A using the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$ computed by ZPOTRF.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A is stored;
-   `= 'L'`: Lower triangle of A is stored.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### A `[in,out]`

_COMPLEX\*16 array, dimension (LDA,N)_

On entry, the triangular factor U or L from the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$, as computed by ZPOTRF. On exit, the upper or lower triangle of the (Hermitian) inverse of A, overwriting the input factor U or L.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `> 0`: if `INFO = i`, the (i,i) element of the factor U or L is zero, and the inverse could not be computed.
