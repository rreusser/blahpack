# zlaqgb

> Equilibrates a complex general band matrix using row and column scaling factors.

<section class="usage">

## Usage

```javascript
var zlaqgb = require( '@stdlib/lapack/base/zlaqgb' );
```

#### zlaqgb( M, N, kl, ku, AB, LDAB, r, strideR, c, strideC, rowcnd, colcnd, amax )

Equilibrates a complex general band matrix using row and column scaling factors.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Complex128Array = require( '@stdlib/array/complex128' );
var zlaqgb = require( '@stdlib/lapack/base/zlaqgb' );

var AB = new Complex128Array( [ 1.0, 0.5, 2.0, -1.0, 3.0, 1.0, 4.0, 2.0 ] );
var r = new Float64Array( [ 0.5, 2.0 ] );
var c = new Float64Array( [ 1.0, 1.0 ] );

zlaqgb.ndarray( 2, 2, 1, 0, AB, 1, 2, 0, r, 1, 0, c, 1, 0, 0.01, 1.0, 5.0 );
```

The function has the following parameters:

-   **M**: number of rows.
-   **N**: number of columns.
-   **kl**: number of subdiagonals.
-   **ku**: number of superdiagonals.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **r**: `r`.
-   **strideR**: stride length for `R`.
-   **c**: `c`.
-   **strideC**: stride length for `C`.
-   **rowcnd**: `rowcnd`.
-   **colcnd**: `colcnd`.
-   **amax**: `amax`.

#### zlaqgb.ndarray( M, N, kl, ku, AB, strideAB1, strideAB2, offsetAB, r, strideR, offsetR, c, strideC, offsetC, rowcnd, colcnd, amax )

Equilibrates a complex general band matrix using row and column scaling factors, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Complex128Array = require( '@stdlib/array/complex128' );
var zlaqgb = require( '@stdlib/lapack/base/zlaqgb' );

var AB = new Complex128Array( [ 1.0, 0.5, 2.0, -1.0, 3.0, 1.0, 4.0, 2.0 ] );
var r = new Float64Array( [ 0.5, 2.0 ] );
var c = new Float64Array( [ 1.0, 1.0 ] );

zlaqgb.ndarray( 2, 2, 1, 0, AB, 1, 2, 0, r, 1, 0, c, 1, 0, 0.01, 1.0, 5.0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **offsetR**: starting index for `R`.
-   **offsetC**: starting index for `C`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAQGB`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Scales a general band matrix, using row and column scaling factors computed by sgbequ.

### Purpose

ZLAQGB equilibrates a general M by N band matrix A with `KL` subdiagonals and `KU` superdiagonals using the row and scaling factors in the vectors R and C.

### Arguments

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### KL `[in]`

_INTEGER_

The number of subdiagonals within the band of A. $\mathrm{KL} \ge 0$.

#### KU `[in]`

_INTEGER_

The number of superdiagonals within the band of A. $\mathrm{KU} \ge 0$.

#### AB `[in,out]`

_COMPLEX\*16 array, dimension (LDAB,N)_

On entry, the matrix A in band storage, in rows 1 to `KL`+`KU`+1. The j-th column of A is stored in the j-th column of the array `AB` as follows: `AB(ku+1+i-j,j) = A(i,j)` for $\max (1,j-\mathrm{ku}) \le i \le \min (m,j+\mathrm{kl})$

On exit, the equilibrated matrix, in the same storage format as A. See `EQUED` for the form of the equilibrated matrix.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDA} \ge \mathrm{KL}+\mathrm{KU}+1$.

#### R `[in]`

_DOUBLE PRECISION array, dimension (M)_

The row scale factors for A.

#### C `[in]`

_DOUBLE PRECISION array, dimension (N)_

The column scale factors for A.

#### ROWCND `[in]`

_DOUBLE PRECISION_

Ratio of the smallest `R(i)` to the largest `R(i)`.

#### COLCND `[in]`

_DOUBLE PRECISION_

Ratio of the smallest `C(i)` to the largest `C(i)`.

#### AMAX `[in]`

_DOUBLE PRECISION_

Absolute value of largest matrix entry.

#### EQUED `[out]`

_CHARACTER\*1_

Specifies the form of equilibration that was done.

-   `= 'N'`: No equilibration
-   `= 'R'`: Row equilibration, i.e., A has been premultiplied by diag(R).
-   `= 'C'`: Column equilibration, i.e., A has been postmultiplied by diag(C).
-   `= 'B'`: Both row and column equilibration, i.e., A has been replaced by $\operatorname{diag}(R) \, A \, \operatorname{diag}(C)$.
