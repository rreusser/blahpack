
{{alias}}( x, y, sigma, out )
    Generates a plane rotation designed to introduce a bulge in implicit QR
    iteration for the bidiagonal SVD problem.

    Parameters
    ----------
    x: number
        (1,1) entry of an upper bidiagonal matrix.

    y: number
        (1,2) entry of an upper bidiagonal matrix.

    sigma: number
        Shift.

    out: Float64Array
        Output array of length at least 2. On return, `out[0] = cs` and
        `out[1] = sn`.

    Returns
    -------
    out: Float64Array
        Output array.

    Examples
    --------
    > var out = new {{alias:@stdlib/array/float64}}( 2 );
    > {{alias}}( 3.0, 4.0, 1.5, out )
    <Float64Array>[ ~0.4903, ~0.8716 ]
