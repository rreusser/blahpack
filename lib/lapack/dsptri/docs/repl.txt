{{alias}}( order, uplo, N, AP, IPIV, strideIPIV, WORK )
    Computes the inverse of a real symmetric matrix in packed storage using
    the factorization computed by dsptrf.

    Parameters
    ----------
    order: string
        Storage layout (`'row-major'` or `'column-major'`).

    uplo: string
        Specifies whether the upper or lower triangle of `A` is stored (`'upper'` or `'lower'`).

    N: integer
        Order of the matrix `A`.

    AP: Float64Array
        Packed factored matrix from `dsptrf`; on exit, the packed inverse.

    IPIV: Int32Array
        Pivot indices from the factorization.

    strideIPIV: integer
        Stride length for `IPIV`.

    WORK: Float64Array|null
        Workspace of length at least `N`; if `null`, a workspace is allocated internally.

    Returns
    -------
    out: Float64Array
        Result.
