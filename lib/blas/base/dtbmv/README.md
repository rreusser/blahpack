# dtbmv

> Performs one of the matrix-vector operations `x := A*x` or `x := A**T*x`.

<section class="usage">

## Usage

```javascript
var dtbmv = require( '@stdlib/blas/base/dtbmv' );
```

#### dtbmv( order, uplo, trans, diag, N, K, A, LDA, x, strideX )

Performs one of the matrix-vector operations `x := A*x` or `x := A**T*x`.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dtbmv = require( '@stdlib/blas/base/dtbmv' );

var A = new Float64Array( [ 0.0, 1.0, 2.0, 3.0 ] );
var x = new Float64Array( [ 1.0, 1.0 ] );

dtbmv.ndarray( 'upper', 'no-transpose', 'non-unit', 2, 1, A, 2, 1, 0, x, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **trans**: specifies whether the matrix should be transposed.
-   **diag**: specifies whether the matrix is unit triangular.
-   **N**: number of columns.
-   **K**: inner dimension.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **x**: `x`.
-   **strideX**: stride length for `X`.

#### dtbmv.ndarray( uplo, trans, diag, N, K, A, strideA1, strideA2, offsetA, x, strideX, offsetX )

Performs one of the matrix-vector operations `x := A*x` or `x := A**T*x`, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dtbmv = require( '@stdlib/blas/base/dtbmv' );

var A = new Float64Array( [ 0.0, 1.0, 2.0, 3.0 ] );
var x = new Float64Array( [ 1.0, 1.0 ] );

dtbmv.ndarray( 'upper', 'no-transpose', 'non-unit', 2, 1, A, 2, 1, 0, x, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetX**: starting index for `X`.

## Reference notes

The mathematical description from the reference BLAS 3.12.0 source of `DTBMV`. Indices are the 1-based Fortran indices of the source.

### Purpose

DTBMV performs one of the matrix-vector operations

$$
x := A \, x, \quad\text{or}\quad x := A^T \, x
$$

where x is an n element vector and A is an n by n unit, or non-unit, upper or lower triangular band matrix, with ( k + 1 ) diagonals.

### Further Details

Level 2 Blas routine. The vector and matrix arguments are not referenced when $N = 0$, or $M = 0$
