# dstev

> Computes the eigenvalues and, optionally, the left and/or right eigenvectors.

<section class="usage">

## Usage

```javascript
var dstev = require( '@stdlib/lapack/base/dstev' );
```

#### dstev( jobz, N, d, strideD, e, strideE, Z, LDZ, WORK, strideWORK )

Computes the eigenvalues and, optionally, the left and/or right eigenvectors.

```javascript
var dstev = require( '@stdlib/lapack/base/dstev' );

var N = 3;
var Z = discreteUniform( N * N, -10, 10, opts );
var d = discreteUniform( N, -10, 10, opts );
var e = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dstev.ndarray( 'compute-vectors', N, d, 1, 0, e, 1, 0, Z, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **jobz**: `jobz`.
-   **N**: number of columns.
-   **d**: `d`.
-   **strideD**: stride length for `D`.
-   **e**: `e`.
-   **strideE**: stride length for `E`.
-   **Z**: input array `Z`.
-   **LDZ**: leading dimension of `Z`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### dstev.ndarray( jobz, N, d, strideD, offsetD, e, strideE, offsetE, Z, strideZ1, strideZ2, offsetZ, WORK, strideWORK, offsetWORK )

Computes the eigenvalues and, optionally, the left and/or right eigenvectors, using alternative indexing semantics.

```javascript
var dstev = require( '@stdlib/lapack/base/dstev' );

var N = 3;
var Z = discreteUniform( N * N, -10, 10, opts );
var d = discreteUniform( N, -10, 10, opts );
var e = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dstev.ndarray( 'compute-vectors', N, d, 1, 0, e, 1, 0, Z, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **offsetD**: starting index for `D`.
-   **offsetE**: starting index for `E`.
-   **strideZ1**: stride of dimension 1 of `Z`.
-   **strideZ2**: stride of dimension 2 of `Z`.
-   **offsetZ**: starting index for `Z`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DSTEV`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the eigenvalues and, optionally, the left and/or right eigenvectors for OTHER matrices

### Purpose

DSTEV computes all eigenvalues and, optionally, eigenvectors of a real symmetric tridiagonal matrix A.

### Arguments

#### JOBZ `[in]`

_CHARACTER\*1_

-   `= 'N'`: Compute eigenvalues only;
-   `= 'V'`: Compute eigenvalues and eigenvectors.

#### N `[in]`

_INTEGER_

The order of the matrix. $N \ge 0$.

#### D `[in,out]`

_DOUBLE PRECISION array, dimension (N)_

On entry, the n diagonal elements of the tridiagonal matrix A. On exit, if `INFO = 0`, the eigenvalues in ascending order.

#### E `[in,out]`

_DOUBLE PRECISION array, dimension (N-1)_

On entry, the (n-1) subdiagonal elements of the tridiagonal matrix A, stored in elements 1 to N-1 of E. On exit, the contents of E are destroyed.

#### Z `[out]`

_DOUBLE PRECISION array, dimension (LDZ, N)_

If `JOBZ = 'V'`, then if `INFO = 0`, Z contains the orthonormal eigenvectors of the matrix A, with the i-th column of Z holding the eigenvector associated with `D(i)`. If `JOBZ = 'N'`, then Z is not referenced.

#### LDZ `[in]`

_INTEGER_

The leading dimension of the array Z. $\mathrm{LDZ} \ge 1$, and if `JOBZ = 'V'`, $\mathrm{LDZ} \ge \max (1,N)$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (max(1,2\*N-2))_

If `JOBZ = 'N'`, `WORK` is not referenced.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `> 0`: if `INFO = i`, the algorithm failed to converge; i off-diagonal elements of E did not converge to zero.
