# zla_gerpvgrw

> Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a complex general matrix.

<section class="usage">

## Usage

```javascript
var zla_gerpvgrw = require( '@stdlib/lapack/base/zla_gerpvgrw' );
```

#### zla_gerpvgrw( N, ncols, A, LDA, AF, LDAF )

Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a complex general matrix.

```javascript
var zla_gerpvgrw = require( '@stdlib/lapack/base/zla_gerpvgrw' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AF = discreteUniform( N * N, -10, 10, opts );

zla_gerpvgrw.ndarray( N, 1, A, N, 1, 0, AF, N, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **ncols**: `ncols`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **AF**: input array `AF`.
-   **LDAF**: leading dimension of `AF`.

#### zla_gerpvgrw.ndarray( N, ncols, A, strideA1, strideA2, offsetA, AF, strideAF1, strideAF2, offsetAF )

Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a complex general matrix, using alternative indexing semantics.

```javascript
var zla_gerpvgrw = require( '@stdlib/lapack/base/zla_gerpvgrw' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AF = discreteUniform( N * N, -10, 10, opts );

zla_gerpvgrw.ndarray( N, 1, A, N, 1, 0, AF, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **strideAF1**: stride of dimension 1 of `AF`.
-   **strideAF2**: stride of dimension 2 of `AF`.
-   **offsetAF**: starting index for `AF`.

</section>

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZLA_GERPVGRW`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZLA\_GERPVGRW computes the reciprocal pivot growth factor norm(A)/norm(U). The "max absolute element" norm is used. If this is much less than 1, the stability of the LU factorization of the (equilibrated) matrix A could be poor. This also means that the solution X, estimated condition numbers, and error bounds could be unreliable.
