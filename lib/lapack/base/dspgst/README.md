# dspgst

> Reduces a real symmetric-definite generalized eigenproblem to standard form using packed storage.

<section class="usage">

## Usage

```javascript
var dspgst = require( '@stdlib/lapack/base/dspgst' );
```

#### dspgst( itype, uplo, N, AP, BP )

Reduces a real symmetric-definite generalized eigenproblem to standard form using packed storage.

```javascript
var dspgst = require( '@stdlib/lapack/base/dspgst' );

dspgst( 1, 'upper', 3, AP, BP );
```

The function has the following parameters:

-   **itype**: `itype`.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **BP**: input array `BP`.

#### dspgst.ndarray( itype, uplo, N, AP, strideAP, offsetAP, BP, strideBP, offsetBP )

Reduces a real symmetric-definite generalized eigenproblem to standard form using packed storage, using alternative indexing semantics.

```javascript
var dspgst = require( '@stdlib/lapack/base/dspgst' );

dspgst( 1, 'upper', 3, AP, BP );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideBP**: stride length for `BP`.
-   **offsetBP**: starting index for `BP`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DSPGST`. Indices are the 1-based Fortran indices of the source.

### Purpose

DSPGST reduces a real symmetric-definite generalized eigenproblem to standard form, using packed storage.

If `ITYPE = 1`, the problem is $A \, x = \lambda \, B \, x$, and A is overwritten by $\operatorname{inv}(U^T) \, A \, \operatorname{inv}(U)$ or $\operatorname{inv}(L) \, A \, \operatorname{inv}(L^T)$

If `ITYPE = 2` or 3, the problem is $A \, B \, x = \lambda \, x$ or $B \, A \, x = \lambda \, x$, and A is overwritten by $U \, A \, U^T$ or $L^T \, A \, L$.

B must have been previously factorized as $U^T \, U$ or $L \, L^T$ by DPPTRF.
