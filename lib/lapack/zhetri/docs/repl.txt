{{alias}}( order, uplo, N, A, LDA, IPIV, strideIPIV, WORK )
    Computes the inverse of a complex Hermitian matrix using the
    factorization computed by zhetrf.

    Parameters
    ----------
    order: string
        Storage layout (`'row-major'` or `'column-major'`).

    uplo: string
        Specifies whether the upper or lower triangle of `A` is stored (`'upper'` or `'lower'`).

    N: integer
        Order of the matrix `A`.

    A: Complex128Array
        Input/output matrix `A`.

    LDA: integer
        Leading dimension of `A`.

    IPIV: Int32Array
        Pivot indices from the factorization.

    strideIPIV: integer
        Stride length for `IPIV`.

    WORK: Complex128Array|null
        Workspace of length at least `N`; if `null`, a workspace is allocated internally.

    Returns
    -------
    out: Float64Array
        Result.

    strideIPIV: integer

    offsetIPIV: integer
