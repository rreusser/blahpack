# ztfsm

> Solves a matrix equation with a complex triangular matrix in Rectangular Full Packed format.

<section class="usage">

## Usage

```javascript
var ztfsm = require( '@stdlib/lapack/base/ztfsm' );
```

#### ztfsm( order, transr, side, uplo, trans, diag, M, N, alpha, A, strideA, B, LDB )

Solves a matrix equation with a complex triangular matrix in Rectangular Full Packed format.

```javascript
var ztfsm = require( '@stdlib/lapack/base/ztfsm' );

ztfsm( 'column-major', 'no-transpose', 'left', 'lower', 'no-transpose', 'non-unit', 3, 1, alpha, A, 1, B, 3 );
```

The function has the following parameters:

-   **transr**: `transr`.
-   **side**: specifies the side of the operation.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **trans**: specifies whether the matrix should be transposed.
-   **diag**: specifies whether the matrix is unit triangular.
-   **M**: number of rows.
-   **N**: number of columns.
-   **alpha**: scalar constant.
-   **A**: input array `A`.
-   **B**: input array `B`.

#### ztfsm.ndarray( transr, side, uplo, trans, diag, M, N, alpha, A, strideA, offsetA, B, strideB1, strideB2, offsetB )

Solves a matrix equation with a complex triangular matrix in Rectangular Full Packed format, using alternative indexing semantics.

```javascript
var ztfsm = require( '@stdlib/lapack/base/ztfsm' );

ztfsm( 'column-major', 'no-transpose', 'left', 'lower', 'no-transpose', 'non-unit', 3, 1, alpha, A, 1, B, 3 );
```

The function has the following additional parameters:

-   **strideA**: stride length for `A`.
-   **offsetA**: starting index for `A`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZTFSM`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Solves a matrix equation (one operand is a triangular matrix in RFP format).

### Purpose

Level 3 BLAS like routine for A in RFP Format.

ZTFSM solves the matrix equation

$$
\operatorname{op}( A ) \, X = \alpha \, B \quad\text{or}\quad X \, \operatorname{op}( A ) = \alpha \, B
$$

where $\alpha$ is a scalar, X and B are m by n matrices, A is a unit, or non-unit, upper or lower triangular matrix and op( A ) is one of

$$
\operatorname{op}( A ) = A \quad\text{or}\quad \operatorname{op}( A ) = A^H
$$

A is in Rectangular Full Packed (RFP) Format.

The matrix X is overwritten on B.

### Arguments

#### TRANSR `[in]`

_CHARACTER\*1_

-   `= 'N'`: The Normal Form of RFP A is stored;
-   `= 'C'`: The Conjugate-transpose Form of RFP A is stored.

#### SIDE `[in]`

_CHARACTER\*1_

On entry, `SIDE` specifies whether op( A ) appears on the left or right of X as follows:

$$
\mathrm{SIDE} = \text{'L'} \quad\text{or}\quad \text{'l'} \operatorname{op}( A ) \, X = \alpha \, B
$$

$$
\mathrm{SIDE} = \text{'R'} \quad\text{or}\quad \text{'r'} X \, \operatorname{op}( A ) = \alpha \, B
$$

Unchanged on exit.

#### UPLO `[in]`

_CHARACTER\*1_

On entry, `UPLO` specifies whether the RFP matrix A came from an upper or lower triangular matrix as follows: `UPLO = 'U'` or 'u' RFP A came from an upper triangular matrix `UPLO = 'L'` or 'l' RFP A came from a lower triangular matrix

Unchanged on exit.

#### TRANS `[in]`

_CHARACTER\*1_

On entry, `TRANS` specifies the form of op( A ) to be used in the matrix multiplication as follows:

$$
\mathrm{TRANS} = \text{'N'} \quad\text{or}\quad \text{'n'} \operatorname{op}( A ) = A
$$

$$
\mathrm{TRANS} = \text{'C'} \quad\text{or}\quad \text{'c'} \operatorname{op}( A ) = \overline{ A' }
$$

Unchanged on exit.

#### DIAG `[in]`

_CHARACTER\*1_

On entry, `DIAG` specifies whether or not RFP A is unit triangular as follows:

`DIAG = 'U'` or 'u' A is assumed to be unit triangular.

`DIAG = 'N'` or 'n' A is not assumed to be unit

triangular.

Unchanged on exit.

#### M `[in]`

_INTEGER_

On entry, M specifies the number of rows of B. M must be at least zero. Unchanged on exit.

#### N `[in]`

_INTEGER_

On entry, N specifies the number of columns of B. N must be at least zero. Unchanged on exit.

#### ALPHA `[in]`

_COMPLEX\*16_

On entry, `ALPHA` specifies the scalar $\alpha$. When $\alpha$ is zero then A is not referenced and B need not be set before entry. Unchanged on exit.

#### A `[in]`

_COMPLEX\*16 array, dimension (N\*(N+1)/2)_

$\mathrm{NT} = N \, (N+1)/2$. On entry, the matrix A in RFP Format. RFP Format is described by `TRANSR`, `UPLO` and N as follows: If `TRANSR='N'` then RFP A is (0:N,0:K-1) when N is even; $K=N/2$. RFP A is (0:N-1,0:K) when N is odd; $K=N/2$. If `TRANSR = 'C'` then RFP is the Conjugate-transpose of RFP A as defined when `TRANSR = 'N'`. The contents of RFP A are defined by `UPLO` as follows: If `UPLO = 'U'` the RFP A contains the NT elements of upper packed A either in normal or conjugate-transpose Format. If `UPLO = 'L'` the RFP A contains the NT elements of lower packed A either in normal or conjugate-transpose Format. The LDA of RFP A is (N+1)/2 when `TRANSR = 'C'`. When `TRANSR` is 'N' the LDA is N+1 when N is even and is N when is odd. See the Note below for more details. Unchanged on exit.

#### B `[in,out]`

_COMPLEX\*16 array, dimension (LDB,N)_

Before entry, the leading m by n part of the array B must contain the right-hand side matrix B, and on exit is overwritten by the solution matrix X.

#### LDB `[in]`

_INTEGER_

On entry, `LDB` specifies the first dimension of B as declared in the calling (sub) program. `LDB` must be at least max( 1, m ). Unchanged on exit.

### Further Details

We first consider Standard Packed Format when N is even. We give an example where $N = 6$.

```text
AP is Upper             AP is Lower
```

```text
00 01 02 03 04 05       00
   11 12 13 14 15       10 11
      22 23 24 25       20 21 22
         33 34 35       30 31 32 33
            44 45       40 41 42 43 44
               55       50 51 52 53 54 55
```

Let `TRANSR = 'N'`. RFP holds AP as follows: For `UPLO = 'U'` the upper trapezoid `A(0:5,0:2)` consists of the last three columns of AP upper. The lower triangle `A(4:6,0:2)` consists of conjugate-transpose of the first three columns of AP upper. For `UPLO = 'L'` the lower trapezoid `A(1:6,0:2)` consists of the first three columns of AP lower. The upper triangle `A(0:2,0:2)` consists of conjugate-transpose of the last three columns of AP lower. To denote conjugate we place -- above the element. This covers the case N even and `TRANSR = 'N'`.

```text
RFP A                   RFP A
```

```text
                        -- -- --
03 04 05                33 43 53
                           -- --
13 14 15                00 44 54
                              --
23 24 25                10 11 55
```

```text
33 34 35                20 21 22
--
00 44 45                30 31 32
-- --
01 11 55                40 41 42
-- -- --
02 12 22                50 51 52
```

Now let `TRANSR = 'C'`. RFP A in both `UPLO` cases is just the conjugate- transpose of RFP A above. One therefore gets:

```text
RFP A                   RFP A
```

```text
-- -- -- --                -- -- -- -- -- --
03 13 23 33 00 01 02    33 00 10 20 30 40 50
-- -- -- -- --                -- -- -- -- --
04 14 24 34 44 11 12    43 44 11 21 31 41 51
-- -- -- -- -- --                -- -- -- --
05 15 25 35 45 55 22    53 54 55 22 32 42 52
```

We next consider Standard Packed Format when N is odd. We give an example where $N = 5$.

```text
AP is Upper                 AP is Lower
```

```text
00 01 02 03 04              00
   11 12 13 14              10 11
      22 23 24              20 21 22
         33 34              30 31 32 33
            44              40 41 42 43 44
```

Let `TRANSR = 'N'`. RFP holds AP as follows: For `UPLO = 'U'` the upper trapezoid `A(0:4,0:2)` consists of the last three columns of AP upper. The lower triangle `A(3:4,0:1)` consists of conjugate-transpose of the first two columns of AP upper. For `UPLO = 'L'` the lower trapezoid `A(0:4,0:2)` consists of the first three columns of AP lower. The upper triangle `A(0:1,1:2)` consists of conjugate-transpose of the last two columns of AP lower. To denote conjugate we place -- above the element. This covers the case N odd and `TRANSR = 'N'`.

```text
RFP A                   RFP A
```

```text
                           -- --
02 03 04                00 33 43
                              --
12 13 14                10 11 44
```

```text
22 23 24                20 21 22
--
00 33 34                30 31 32
-- --
01 11 44                40 41 42
```

Now let `TRANSR = 'C'`. RFP A in both `UPLO` cases is just the conjugate- transpose of RFP A above. One therefore gets:

```text
RFP A                   RFP A
```

```text
-- -- --                   -- -- -- -- -- --
02 12 22 00 01             00 10 20 30 40 50
-- -- -- --                   -- -- -- -- --
03 13 23 33 11             33 11 21 31 41 51
-- -- -- -- --                   -- -- -- --
04 14 24 34 44             43 44 22 32 42 52
```
