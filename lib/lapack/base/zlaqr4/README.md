> Complex multishift QR with aggressive early deflation (non-recursive).

```javascript
var zlaqr4 = require( '@stdlib/lapack/base/zlaqr4' );
```

#### zlaqr4( v, idx )

Complex multishift QR with aggressive early deflation (non-recursive).

```javascript
var zlaqr4 = require( '@stdlib/lapack/base/zlaqr4' );

var N = 3;
var H = discreteUniform( N * N, -10, 10, opts );
var Z = discreteUniform( N * N, -10, 10, opts );

var WORK = discreteUniform( N, -10, 10, opts );

zlaqr4.ndarray( 1, 1, N, N, N, H, N, 1, 0, w, 1, 0, 1, 1, Z, N, 1, 0, WORK, 1, 0, N );
```

-   **v**: `v`.
-   **idx**: `idx`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAQR4`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the eigenvalues of a Hessenberg matrix, and optionally the matrices from the Schur decomposition.

### Purpose

ZLAQR4 implements one level of recursion for ZLAQR0. It is a complete implementation of the small bulge multi-shift QR algorithm. It may be called by ZLAQR0 and, for large enough deflation window size, it may be called by ZLAQR3. This subroutine is identical to ZLAQR0 except that it calls ZLAQR2 instead of ZLAQR3.

ZLAQR4 computes the eigenvalues of a Hessenberg matrix H and, optionally, the matrices T and Z from the Schur decomposition $H = Z$ T $Z^H$, where T is an upper triangular matrix (the Schur form), and Z is the unitary matrix of Schur vectors.

Optionally Z may be postmultiplied into an input unitary matrix Q so that this routine can give the Schur factorization of a matrix A which has been reduced to the Hessenberg form H by the unitary matrix Q: $A = Q \, H \, Q^H = (\mathrm{QZ}) \, H \, (\mathrm{QZ})^H$.

### Arguments

#### WANTT `[in]`

_LOGICAL_

= .TRUE. : the full Schur form T is required; = .FALSE.: only eigenvalues are required.

#### WANTZ `[in]`

_LOGICAL_

= .TRUE. : the matrix of Schur vectors Z is required; = .FALSE.: Schur vectors are not required.

#### N `[in]`

_INTEGER_

The order of the matrix H. $N \ge 0$.

#### ILO `[in]`

_INTEGER_

#### IHI `[in]`

_INTEGER_

It is assumed that H is already upper triangular in rows and columns 1:`ILO`-1 and `IHI`+1:N and, if $\mathrm{ILO} > 1$, `H(ILO,ILO-1)` is zero. `ILO` and `IHI` are normally set by a previous call to ZGEBAL, and then passed to ZGEHRD when the matrix output by ZGEBAL is reduced to Hessenberg form. Otherwise, `ILO` and `IHI` should be set to 1 and N, respectively. If $N > 0$, then $1 \le \mathrm{ILO} \le \mathrm{IHI} \le N$. If $N = 0$, then `ILO = 1` and `IHI = 0`.

#### H `[in,out]`

_COMPLEX\*16 array, dimension (LDH,N)_

On entry, the upper Hessenberg matrix H. On exit, if `INFO = 0` and `WANTT` is .TRUE., then H contains the upper triangular matrix T from the Schur decomposition (the Schur form). If `INFO = 0` and WANT is .FALSE., then the contents of H are unspecified on exit. (The output value of H when $\mathrm{INFO} > 0$ is given under the description of `INFO` below.)

This subroutine may explicitly set $H(i,j) = 0$ for $i > j$ and $j = 1$, 2, ... `ILO`-1 or $j = \mathrm{IHI}+1$, `IHI`+2, ... N.

#### LDH `[in]`

_INTEGER_

The leading dimension of the array H. $\mathrm{LDH} \ge \max (1,N)$.

#### W `[out]`

_COMPLEX\*16 array, dimension (N)_

The computed eigenvalues of `H(ILO:IHI,ILO:IHI)` are stored in `W(ILO:IHI)`. If `WANTT` is .TRUE., then the eigenvalues are stored in the same order as on the diagonal of the Schur form returned in H, with $W(i) = H(i,i)$.

#### ILOZ `[in]`

_INTEGER_

#### IHIZ `[in]`

_INTEGER_

Specify the rows of Z to which transformations must be applied if `WANTZ` is .TRUE.. $1 \le \mathrm{ILOZ} \le \mathrm{ILO}$; $\mathrm{IHI} \le \mathrm{IHIZ} \le N$.

#### Z `[in,out]`

_COMPLEX\*16 array, dimension (LDZ,IHI)_

If `WANTZ` is .FALSE., then Z is not referenced. If `WANTZ` is .TRUE., then `Z(ILO:IHI,ILOZ:IHIZ)` is replaced by $Z(\mathrm{ILO}:\mathrm{IHI},\mathrm{ILOZ}:\mathrm{IHIZ}) \, U$ where U is the orthogonal Schur factor of `H(ILO:IHI,ILO:IHI)`. (The output value of Z when $\mathrm{INFO} > 0$ is given under the description of `INFO` below.)

#### LDZ `[in]`

_INTEGER_

The leading dimension of the array Z. if `WANTZ` is .TRUE. then $\mathrm{LDZ} \ge \max (1,\mathrm{IHIZ})$. Otherwise, $\mathrm{LDZ} \ge 1$.

#### WORK `[out]`

_COMPLEX\*16 array, dimension LWORK_

On exit, if `LWORK = -1`, `WORK(1)` returns an estimate of the optimal value for `LWORK`.

#### LWORK `[in]`

_INTEGER_

The dimension of the array `WORK`. $\mathrm{LWORK} \ge \max (1,N)$ is sufficient, but `LWORK` typically as large as $6 \, N$ may be required for optimal performance. A workspace query to determine the optimal workspace size is recommended.

If `LWORK = -1`, then ZLAQR4 does a workspace query. In this case, ZLAQR4 checks the input parameters and estimates the optimal workspace size for the given values of N, `ILO` and `IHI`. The estimate is returned in `WORK(1)`. No error message related to `LWORK` is issued by XERBLA. Neither H nor Z are accessed.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `> 0`: if `INFO = i`, ZLAQR4 failed to compute all of the eigenvalues.  Elements 1:ilo-1 and i+1:n of WR and WI contain those eigenvalues which have been successfully computed.  (Failures are rare.)

If $\mathrm{INFO} > 0$ and WANT is .FALSE., then on exit, the remaining unconverged eigenvalues are the eigen- values of the upper Hessenberg matrix rows and columns `ILO` through `INFO` of the final, output value of H.

If $\mathrm{INFO} > 0$ and `WANTT` is .TRUE., then on exit

```text
(*)  (initial value of H)*U  = U*(final value of H)
```

where U is a unitary matrix. The final value of H is upper Hessenberg and triangular in rows and columns `INFO`+1 through `IHI`.

If $\mathrm{INFO} > 0$ and `WANTZ` is .TRUE., then on exit

(final value of `Z(ILO:IHI,ILOZ:IHIZ)` = (initial value of $Z(\mathrm{ILO}:\mathrm{IHI},\mathrm{ILOZ}:\mathrm{IHIZ}) \, U$

where U is the unitary matrix in (\*) (regard- less of the value of `WANTT`.)

If $\mathrm{INFO} > 0$ and `WANTZ` is .FALSE., then Z is not accessed.
