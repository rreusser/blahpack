# dgemqrt

> Overwrites a real M-by-N matrix `C` with `op(Q)*C` or `C*op(Q)`, where `Q` is the orthogonal factor in the compact WY representation produced by `dgeqrt`.

<section class="usage">

## Usage

```javascript
var dgemqrt = require( '@stdlib/lapack/base/dgemqrt' );
```

#### dgemqrt( order, side, trans, M, N, K, nb, V, LDV, T, LDT, C, LDC, WORK, strideWORK )

Overwrites the M-by-N matrix `C` with one of `Q*C`, `Q^T*C`, `C*Q`, or `C*Q^T` according to `side` and `trans`.

```javascript
var Float64Array = require( '@stdlib/array/float64' );

var V = new Float64Array( 12 );
var T = new Float64Array( 6 );
var C = new Float64Array( 16 );
var WORK = new Float64Array( 8 );

dgemqrt( 'column-major', 'left', 'no-transpose', 4, 4, 3, 2, V, 4, T, 2, C, 4, WORK, 1 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **side**: `'left'` to apply `Q` from the left, `'right'` to apply from the right.
-   **trans**: `'no-transpose'` to apply `Q`, `'transpose'` to apply `Q^T`.
-   **M**: number of rows of `C`.
-   **N**: number of columns of `C`.
-   **K**: number of elementary reflectors.
-   **nb**: block size used to build `T` (must equal the value used in `dgeqrt`).
-   **V**: reflector vectors from `dgeqrt`.
-   **LDV**: leading dimension of `V`.
-   **T**: block triangular factors from `dgeqrt`.
-   **LDT**: leading dimension of `T` (must be `>= nb`).
-   **C**: input/output matrix.
-   **LDC**: leading dimension of `C`.
-   **WORK**: workspace buffer (logically `ldwork`-by-`nb`).
-   **strideWORK**: element stride for `WORK`.

#### dgemqrt.ndarray( side, trans, M, N, K, nb, V, strideV1, strideV2, offsetV, T, strideT1, strideT2, offsetT, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Same operation as `dgemqrt`, using alternative indexing semantics with explicit strides and offsets.

```javascript
var Float64Array = require( '@stdlib/array/float64' );

var V = new Float64Array( 12 );
var T = new Float64Array( 6 );
var C = new Float64Array( 16 );
var WORK = new Float64Array( 8 );

dgemqrt.ndarray( 'left', 'no-transpose', 4, 4, 3, 2, V, 1, 4, 0, T, 1, 2, 0, C, 1, 4, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideV1**: stride of dimension 1 of `V`.
-   **strideV2**: stride of dimension 2 of `V`.
-   **offsetV**: starting index for `V`.
-   **strideT1**: stride of dimension 1 of `T`.
-   **strideT2**: stride of dimension 2 of `T`.
-   **offsetT**: starting index for `T`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

</section>

<section class="notes">

## Notes

-   The `WORK` buffer should provide at least `ldwork * nb` elements where `ldwork = max(1,N)` for `side='left'` or `max(1,M)` for `side='right'`. If the buffer is too small, an internal scratch array is allocated.
-   `V` and `T` must come from a prior call to `dgeqrt` with the same block size `nb`.

</section>

<!-- /.notes -->

<section class="examples">

## Examples

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dgemqrt = require( '@stdlib/lapack/base/dgemqrt' );

var V = new Float64Array( 12 );
var T = new Float64Array( 6 );
var C = new Float64Array( 16 );
var WORK = new Float64Array( 8 );

dgemqrt.ndarray( 'left', 'no-transpose', 4, 4, 3, 2, V, 1, 4, 0, T, 1, 2, 0, C, 1, 4, 0, WORK, 1, 0 );
console.log( C );
```

## Reference documentation

From the reference LAPACK 3.12.0 source of `DGEMQRT`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DGEMQRT overwrites the general real M-by-N matrix C with

```text
                SIDE = 'L'     SIDE = 'R'
TRANS = 'N':      Q C            C Q
TRANS = 'T':   Q**T C            C Q**T
```

where Q is a real orthogonal matrix defined as the product of K elementary reflectors:

$$
Q = H(1) H(2) \cdots H(K) = I - V T V^T
$$

generated using the compact WY representation as returned by DGEQRT.

Q is of order M if `SIDE = 'L'` and of order N if `SIDE = 'R'`.

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^T$ from the Left;
-   `= 'R'`: apply Q or $Q^T$ from the Right.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: No transpose, apply Q;
-   `= 'C'`: Transpose, apply $Q^T$.

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### K `[in]`

_INTEGER_

The number of elementary reflectors whose product defines the matrix Q. If `SIDE = 'L'`, $M \ge K \ge 0$; if `SIDE = 'R'`, $N \ge K \ge 0$.

#### NB `[in]`

_INTEGER_

The block size used for the storage of T. $K \ge \mathrm{NB} \ge 1$. This must be the same value of `NB` used to generate T in DGEQRT.

#### V `[in]`

_DOUBLE PRECISION array, dimension (LDV,K)_

The i-th column must contain the vector which defines the elementary reflector H(i), for $i = 1$,2,...,k, as returned by DGEQRT in the first K columns of its array argument A.

#### LDV `[in]`

_INTEGER_

The leading dimension of the array V. If `SIDE = 'L'`, $\mathrm{LDA} \ge \max (1,M)$; if `SIDE = 'R'`, $\mathrm{LDA} \ge \max (1,N)$.

#### T `[in]`

_DOUBLE PRECISION array, dimension (LDT,K)_

The upper triangular factors of the block reflectors as returned by DGEQRT, stored as a `NB`-by-N matrix.

#### LDT `[in]`

_INTEGER_

The leading dimension of the array T. $\mathrm{LDT} \ge \mathrm{NB}$.

#### C `[in,out]`

_DOUBLE PRECISION array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by Q C, $Q^T$ C, C $Q^T$ or C Q.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_DOUBLE PRECISION array. The dimension of_

`WORK` is $N \, \mathrm{NB}$ if `SIDE = 'L'`, or $M \, \mathrm{NB}$ if `SIDE = 'R'`.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
