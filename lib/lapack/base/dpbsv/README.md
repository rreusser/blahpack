# dpbsv

> Computes the solution to system of linear equations A·X = B.

<section class="usage">

## Usage

```javascript
var dpbsv = require( '@stdlib/lapack/base/dpbsv' );
```

#### dpbsv( order, uplo, N, kd, nrhs, AB, LDAB, B, LDB )

Computes the solution to system of linear equations A·X = B.

```javascript
var dpbsv = require( '@stdlib/lapack/base/dpbsv' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );

dpbsv.ndarray( 'upper', N, 1, N, AB, N, 1, 0, B, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **kd**: `kd`.
-   **nrhs**: number of right-hand sides.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### dpbsv.ndarray( uplo, N, kd, nrhs, AB, strideAB1, strideAB2, offsetAB, B, strideB1, strideB2, offsetB )

Computes the solution to system of linear equations A·X = B,, using alternative indexing semantics.

```javascript
var dpbsv = require( '@stdlib/lapack/base/dpbsv' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );

dpbsv.ndarray( 'upper', N, 1, N, AB, N, 1, 0, B, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DPBSV`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the solution to system of linear equations $A \, X = B$ for OTHER matrices

### Purpose

DPBSV computes the solution to a real system of linear equations

$$
A \, X = B
$$

where A is an N-by-N symmetric positive definite band matrix and X and B are N-by-`NRHS` matrices.

The Cholesky decomposition is used to factor A as

$$
A = U^T \, U, \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$$
A = L \, L^T, \quad\text{if}\quad \mathrm{UPLO} = \text{'L'}
$$

where U is an upper triangular band matrix, and L is a lower triangular band matrix, with the same number of superdiagonals or subdiagonals as A. The factored form of A is then used to solve the system of equations $A \, X = B$.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A is stored;
-   `= 'L'`: Lower triangle of A is stored.

#### N `[in]`

_INTEGER_

The number of linear equations, i.e., the order of the matrix A. $N \ge 0$.

#### KD `[in]`

_INTEGER_

The number of superdiagonals of the matrix A if `UPLO = 'U'`, or the number of subdiagonals if `UPLO = 'L'`. $\mathrm{KD} \ge 0$.

#### NRHS `[in]`

_INTEGER_

The number of right hand sides, i.e., the number of columns of the matrix B. $\mathrm{NRHS} \ge 0$.

#### AB `[in,out]`

_DOUBLE PRECISION array, dimension (LDAB,N)_

On entry, the upper or lower triangle of the symmetric band matrix A, stored in the first `KD`+1 rows of the array. The j-th column of A is stored in the j-th column of the array `AB` as follows: if `UPLO = 'U'`, `AB(KD+1+i-j,j) = A(i,j)` for $\max (1,j-\mathrm{KD}) \le i \le j$; if `UPLO = 'L'`, `AB(1+i-j,j) = A(i,j)` for $j \le i \le \min (N,j+\mathrm{KD})$. See below for further details.

On exit, if `INFO = 0`, the triangular factor U or L from the Cholesky factorization $A = U^T \, U$ or $A = L \, L^T$ of the band matrix A, in the same storage format as A.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge \mathrm{KD}+1$.

#### B `[in,out]`

_DOUBLE PRECISION array, dimension (LDB,NRHS)_

On entry, the N-by-`NRHS` right hand side matrix B. On exit, if `INFO = 0`, the N-by-`NRHS` solution matrix X.

#### LDB `[in]`

_INTEGER_

The leading dimension of the array B. $\mathrm{LDB} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `> 0`: if `INFO = i`, the leading principal minor of order i of A is not positive, so the factorization could not be completed, and the solution has not been computed.

### Further Details

The band storage scheme is illustrated by the following example, when $N = 6$, `KD = 2`, and `UPLO = 'U'`:

```text
On entry:                       On exit:
```

```text
 *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
 *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
```

Similarly, if `UPLO = 'L'` the format of A is as follows:

```text
On entry:                       On exit:
```

```text
a11  a22  a33  a44  a55  a66     l11  l22  l33  l44  l55  l66
a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *
```

Array elements marked \* are not used by the routine.
