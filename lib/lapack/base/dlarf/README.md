# dlarf

> Applies an elementary reflector to a general rectangular matrix.

<section class="usage">

## Usage

```javascript
var dlarf = require( '@stdlib/lapack/base/dlarf' );
```

#### dlarf( order, side, M, N, v, strideV, tau, C, LDC, WORK, strideWORK )

Applies an elementary reflector to a general rectangular matrix.

```javascript
var dlarf = require( '@stdlib/lapack/base/dlarf' );

var N = 3;
var C = discreteUniform( N * N, -10, 10, opts );
var v = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dlarf.ndarray( 'left', N, N, v, 1, 0, 1.0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **side**: specifies the side of the operation.
-   **M**: number of rows.
-   **N**: number of columns.
-   **v**: `v`.
-   **strideV**: stride length for `V`.
-   **tau**: `tau`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### dlarf.ndarray( side, M, N, v, strideV, offsetV, tau, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Applies an elementary reflector to a general rectangular matrix,, using alternative indexing semantics.

```javascript
var dlarf = require( '@stdlib/lapack/base/dlarf' );

var N = 3;
var C = discreteUniform( N * N, -10, 10, opts );
var v = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dlarf.ndarray( 'left', N, N, v, 1, 0, 1.0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **offsetV**: starting index for `V`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLARF`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Applies an elementary reflector to a general rectangular matrix.

### Purpose

DLARF applies a real elementary reflector H to a real m by n matrix C, from either the left or the right. H is represented in the form

$$
H = I - \tau \, v \, v^T
$$

where $\tau$ is a real scalar and v is a real vector.

If $\tau = 0$, then H is taken to be the unit matrix.

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: form  $H \, C$
-   `= 'R'`: form  $C \, H$

#### M `[in]`

_INTEGER_

The number of rows of the matrix C.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C.

#### V `[in]`

_DOUBLE PRECISION array, dimension (1 + (M-1)\*abs(INCV)) if SIDE = 'L'_

or (1 + (N-1)\*abs(`INCV`)) if `SIDE = 'R'` The vector v in the representation of H. V is not used if `TAU = 0`.

#### INCV `[in]`

_INTEGER_

The increment between elements of v. `INCV` \<\> 0.

#### TAU `[in]`

_DOUBLE PRECISION_

The value $\tau$ in the representation of H.

#### C `[in,out]`

_DOUBLE PRECISION array, dimension (LDC,N)_

On entry, the m by n matrix C. On exit, C is overwritten by the matrix $H \, C$ if `SIDE = 'L'`, or $C \, H$ if `SIDE = 'R'`.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (N) if SIDE = 'L'_

or (M) if `SIDE = 'R'`
