# dsbgst

> Reduces a real symmetric-definite banded generalized eigenproblem to standard form.

<section class="usage">

## Usage

```javascript
var dsbgst = require( '@stdlib/lapack/base/dsbgst' );
```

#### dsbgst( vect, uplo, N, ka, kb, AB, LDAB, BB, LDBB, X, LDX, WORK )

Reduces a real symmetric-definite banded generalized eigenproblem to standard form.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dsbgst = require( '@stdlib/lapack/base/dsbgst' );

var AB = new Float64Array( [ 0, 5, 1, 6, 0.5, 7 ] );
var BB = new Float64Array( [ 2, 3, 4 ] );
var X = new Float64Array( 1 );
var WORK = new Float64Array( 6 );

dsbgst.ndarray( 'none', 'upper', 3, 1, 0, AB, 1, 2, 0, BB, 1, 1, 0, X, 1, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **vect**: `vect`.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **ka**: `ka`.
-   **kb**: `kb`.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **BB**: input array `BB`.
-   **LDBB**: leading dimension of `BB`.
-   **X**: input array `X`.
-   **LDX**: leading dimension of `X`.
-   **WORK**: input array `WORK`.

#### dsbgst.ndarray( vect, uplo, N, ka, kb, AB, strideAB1, strideAB2, offsetAB, BB, strideBB1, strideBB2, offsetBB, X, strideX1, strideX2, offsetX, WORK, strideWORK, offsetWORK )

Reduces a real symmetric-definite banded generalized eigenproblem to standard form, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dsbgst = require( '@stdlib/lapack/base/dsbgst' );

var AB = new Float64Array( [ 0, 5, 1, 6, 0.5, 7 ] );
var BB = new Float64Array( [ 2, 3, 4 ] );
var X = new Float64Array( 1 );
var WORK = new Float64Array( 6 );

dsbgst.ndarray( 'none', 'upper', 3, 1, 0, AB, 1, 2, 0, BB, 1, 1, 0, X, 1, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **strideBB1**: stride of dimension 1 of `BB`.
-   **strideBB2**: stride of dimension 2 of `BB`.
-   **offsetBB**: starting index for `BB`.
-   **strideX1**: stride of dimension 1 of `X`.
-   **strideX2**: stride of dimension 2 of `X`.
-   **offsetX**: starting index for `X`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DSBGST`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DSBGST reduces a real symmetric-definite banded generalized eigenproblem $A \, x = \lambda \, B \, x$ to standard form $C \, y = \lambda \, y$, such that C has the same bandwidth as A.

B must have been previously factorized as $S^T \, S$ by DPBSTF, using a split Cholesky factorization. A is overwritten by $C = X^T \, A \, X$, where $X = S^{-1} \, Q$ and Q is an orthogonal matrix chosen to preserve the bandwidth of A.

### Arguments

#### VECT `[in]`

_CHARACTER\*1_

-   `= 'N'`: do not form the transformation matrix X;
-   `= 'V'`: form X.

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A is stored;
-   `= 'L'`: Lower triangle of A is stored.

#### N `[in]`

_INTEGER_

The order of the matrices A and B. $N \ge 0$.

#### KA `[in]`

_INTEGER_

The number of superdiagonals of the matrix A if `UPLO = 'U'`, or the number of subdiagonals if `UPLO = 'L'`. $\mathrm{KA} \ge 0$.

#### KB `[in]`

_INTEGER_

The number of superdiagonals of the matrix B if `UPLO = 'U'`, or the number of subdiagonals if `UPLO = 'L'`. $\mathrm{KA} \ge \mathrm{KB} \ge 0$.

#### AB `[in,out]`

_DOUBLE PRECISION array, dimension (LDAB,N)_

On entry, the upper or lower triangle of the symmetric band matrix A, stored in the first ka+1 rows of the array. The j-th column of A is stored in the j-th column of the array `AB` as follows: if `UPLO = 'U'`, `AB(ka+1+i-j,j) = A(i,j)` for $\max (1,j-\mathrm{ka}) \le i \le j$; if `UPLO = 'L'`, `AB(1+i-j,j) = A(i,j)` for $j \le i \le \min (n,j+\mathrm{ka})$.

On exit, the transformed matrix $X^T \, A \, X$, stored in the same format as A.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge \mathrm{KA}+1$.

#### BB `[in]`

_DOUBLE PRECISION array, dimension (LDBB,N)_

The banded factor S from the split Cholesky factorization of B, as returned by DPBSTF, stored in the first `KB`+1 rows of the array.

#### LDBB `[in]`

_INTEGER_

The leading dimension of the array `BB`. $\mathrm{LDBB} \ge \mathrm{KB}+1$.

#### X `[out]`

_DOUBLE PRECISION array, dimension (LDX,N)_

If `VECT = 'V'`, the n-by-n matrix X. If `VECT = 'N'`, the array X is not referenced.

#### LDX `[in]`

_INTEGER_

The leading dimension of the array X. $\mathrm{LDX} \ge \max (1,N)$ if `VECT = 'V'`; $\mathrm{LDX} \ge 1$ otherwise.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (2\*N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value.
