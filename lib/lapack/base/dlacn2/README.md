# dlacn2

> Estimates the 1-norm of a square matrix, using reverse communication for evaluating matrix-vector products.

<section class="usage">

## Usage

```javascript
var dlacn2 = require( '@stdlib/lapack/base/dlacn2' );
```

#### dlacn2( N, v, strideV, x, strideX, ISGN, strideISGN, EST, KASE, ISAVE, strideISAVE )

Estimates the 1-norm of a square matrix, using reverse communication for evaluating matrix-vector products.

```javascript
var dlacn2 = require( '@stdlib/lapack/base/dlacn2' );

var N = 3;
var v = discreteUniform( N, -10, 10, opts );
var x = discreteUniform( N, -10, 10, opts );
var ISGN = discreteUniform( N, -10, 10, opts );
var ISAVE = discreteUniform( N, -10, 10, opts );

dlacn2.ndarray( N, v, 1, 0, x, 1, 0, ISGN, 1, 0, 1, 1, ISAVE, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **v**: `v`.
-   **strideV**: stride length for `V`.
-   **x**: `x`.
-   **strideX**: stride length for `X`.
-   **ISGN**: input array `ISGN`.
-   **strideISGN**: stride length for `ISGN`.
-   **EST**: input array `EST`.
-   **KASE**: input array `KASE`.
-   **ISAVE**: input array `ISAVE`.
-   **strideISAVE**: stride length for `ISAVE`.

#### dlacn2.ndarray( N, v, strideV, offsetV, x, strideX, offsetX, ISGN, strideISGN, offsetISGN, EST, KASE, ISAVE, strideISAVE, offsetISAVE )

Estimates the 1-norm of a square matrix, using reverse communication for evaluating matrix-vector products, using alternative indexing semantics.

```javascript
var dlacn2 = require( '@stdlib/lapack/base/dlacn2' );

var N = 3;
var v = discreteUniform( N, -10, 10, opts );
var x = discreteUniform( N, -10, 10, opts );
var ISGN = discreteUniform( N, -10, 10, opts );
var ISAVE = discreteUniform( N, -10, 10, opts );

dlacn2.ndarray( N, v, 1, 0, x, 1, 0, ISGN, 1, 0, 1, 1, ISAVE, 1, 0 );
```

The function has the following additional parameters:

-   **offsetV**: starting index for `V`.
-   **offsetX**: starting index for `X`.
-   **offsetISGN**: starting index for `ISGN`.
-   **offsetISAVE**: starting index for `ISAVE`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLACN2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Estimates the 1-norm of a square matrix, using reverse communication for evaluating matrix-vector products.

### Purpose

DLACN2 estimates the 1-norm of a square, real matrix A. Reverse communication is used for evaluating matrix-vector products.

### Arguments

#### N `[in]`

_INTEGER_

The order of the matrix. $N \ge 1$.

#### V `[out]`

_DOUBLE PRECISION array, dimension (N)_

On the final return, $V = A \, W$, where $\mathrm{EST} = \operatorname{norm}(V)/\operatorname{norm}(W)$ (W is not returned).

#### X `[in,out]`

_DOUBLE PRECISION array, dimension (N)_

On an intermediate return, X should be overwritten by

$$
A \, X, \quad\text{if}\quad \mathrm{KASE}=1
$$

$$
A^T \, X, \quad\text{if}\quad \mathrm{KASE}=2
$$

and DLACN2 must be re-called with all the other parameters unchanged.

#### ISGN `[out]`

_INTEGER array, dimension (N)_

#### EST `[in,out]`

_DOUBLE PRECISION_

On entry with `KASE = 1` or 2 and `ISAVE(1) = 3`, `EST` should be unchanged from the previous call to DLACN2. On exit, `EST` is an estimate (a lower bound) for norm(A).

#### KASE `[in,out]`

_INTEGER_

On the initial call to DLACN2, `KASE` should be 0. On an intermediate return, `KASE` will be 1 or 2, indicating whether X should be overwritten by $A \, X$ or $A^T \, X$. On the final return from DLACN2, `KASE` will again be 0.

#### ISAVE `[in,out]`

_INTEGER array, dimension (3)_

`ISAVE` is used to save variables between calls to DLACN2

### Further Details

Originally named SONEST, dated March 16, 1988.

This is a thread safe version of DLACON, which uses the array `ISAVE` in place of a SAVE statement, as follows:

| DLACON | DLACN2 |
| --- | --- |
| JUMP | `ISAVE(1)` |
| J | `ISAVE(2)` |
| ITER | `ISAVE(3)` |
