# zlacn2

> Estimates the 1-norm of a square complex matrix A using reverse communication.

<section class="usage">

## Usage

```javascript
var zlacn2 = require( '@stdlib/lapack/base/zlacn2' );
```

#### zlacn2( N, V, strideV, X, strideX, EST, KASE, ISAVE, strideISAVE )

Estimates the 1-norm of a square complex matrix A using reverse communication.

```javascript
var zlacn2 = require( '@stdlib/lapack/base/zlacn2' );

var N = 3;
var V = discreteUniform( N, -10, 10, opts );
var X = discreteUniform( N, -10, 10, opts );
var ISAVE = discreteUniform( N, -10, 10, opts );

zlacn2.ndarray( N, V, 1, 0, X, 1, 0, 1, 1, ISAVE, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **V**: input array `V`.
-   **strideV**: stride length for `V`.
-   **X**: input array `X`.
-   **strideX**: stride length for `X`.
-   **EST**: input array `EST`.
-   **KASE**: input array `KASE`.
-   **ISAVE**: input array `ISAVE`.
-   **strideISAVE**: stride length for `ISAVE`.

#### zlacn2.ndarray( N, V, strideV, offsetV, X, strideX, offsetX, EST, KASE, ISAVE, strideISAVE, offsetISAVE )

Estimates the 1-norm of a square complex matrix A using reverse communication, using alternative indexing semantics.

```javascript
var zlacn2 = require( '@stdlib/lapack/base/zlacn2' );

var N = 3;
var V = discreteUniform( N, -10, 10, opts );
var X = discreteUniform( N, -10, 10, opts );
var ISAVE = discreteUniform( N, -10, 10, opts );

zlacn2.ndarray( N, V, 1, 0, X, 1, 0, 1, 1, ISAVE, 1, 0 );
```

The function has the following additional parameters:

-   **offsetV**: starting index for `V`.
-   **offsetX**: starting index for `X`.
-   **offsetISAVE**: starting index for `ISAVE`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLACN2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Estimates the 1-norm of a square matrix, using reverse communication for evaluating matrix-vector products.

### Purpose

ZLACN2 estimates the 1-norm of a square, complex matrix A. Reverse communication is used for evaluating matrix-vector products.

### Arguments

#### N `[in]`

_INTEGER_

The order of the matrix. $N \ge 1$.

#### V `[out]`

_COMPLEX\*16 array, dimension (N)_

On the final return, $V = A \, W$, where $\mathrm{EST} = \operatorname{norm}(V)/\operatorname{norm}(W)$ (W is not returned).

#### X `[in,out]`

_COMPLEX\*16 array, dimension (N)_

On an intermediate return, X should be overwritten by

$$
A \, X, \quad\text{if}\quad \mathrm{KASE}=1
$$

$$
A^H \, X, \quad\text{if}\quad \mathrm{KASE}=2
$$

where $A^H$ is the conjugate transpose of A, and ZLACN2 must be re-called with all the other parameters unchanged.

#### EST `[in,out]`

_DOUBLE PRECISION_

On entry with `KASE = 1` or 2 and `ISAVE(1) = 3`, `EST` should be unchanged from the previous call to ZLACN2. On exit, `EST` is an estimate (a lower bound) for norm(A).

#### KASE `[in,out]`

_INTEGER_

On the initial call to ZLACN2, `KASE` should be 0. On an intermediate return, `KASE` will be 1 or 2, indicating whether X should be overwritten by $A \, X$ or $A^H \, X$. On the final return from ZLACN2, `KASE` will again be 0.

#### ISAVE `[in,out]`

_INTEGER array, dimension (3)_

`ISAVE` is used to save variables between calls to ZLACN2

### Further Details

Originally named CONEST, dated March 16, 1988.

Last modified: April, 1999

This is a thread safe version of ZLACON, which uses the array `ISAVE` in place of a SAVE statement, as follows:

| ZLACON | ZLACN2 |
| --- | --- |
| JUMP | `ISAVE(1)` |
| J | `ISAVE(2)` |
| ITER | `ISAVE(3)` |
