{{alias}}( order, trans, M, N, nrhs, A, LDA, B, LDB, WORK )
    Solves overdetermined or underdetermined complex linear systems involving an
    M-by-N matrix `A`, or its conjugate transpose, using a QR or LQ
    factorization of `A`.

    Parameters
    ----------
    order: string
        Storage layout (`'row-major'` or `'column-major'`).

    trans: string
        Specifies whether to solve with `A` (`'no-transpose'`) or its conjugate transpose (`'conjugate-transpose'`).

    M: integer
        Number of rows of `A`.

    N: integer
        Number of columns of `A`.

    nrhs: integer
        Number of right-hand sides.

    A: Complex128Array
        Input matrix `A`; overwritten with its factorization.

    LDA: integer
        Leading dimension of `A`.

    B: Complex128Array
        `max(M,N)`-by-`nrhs` matrix: the right-hand sides on entry, the solution on exit.

    LDB: integer
        Leading dimension of `B` (column-major: `>= max(1,M,N)`; row-major: `>= max(1,nrhs)`).

    WORK: Complex128Array|null
        Workspace; if `null`, a workspace is allocated internally.

    Returns
    -------
    info: integer
        Status code.

    Solves overdetermined or underdetermined systems for general matrices,
    using alternative indexing semantics.

    Parameters
    ----------
    trans: string
        specifies whether the matrix should be transposed.

    M: integer
        number of rows.

    N: integer
        number of columns.

    nrhs: integer
        number of right-hand sides.

    A: Float64Array
        `A`.

    strideA1: integer
        stride of dimension 1 of `A`.

    strideA2: integer
        stride of dimension 2 of `A`.

    offsetA: integer
        starting index for `A`.

    B: Float64Array
        `B`.

    strideB1: integer
        stride of dimension 1 of `B`.

    strideB2: integer
        stride of dimension 2 of `B`.

    offsetB: integer
        starting index for `B`.

    WORK: Float64Array
        `WORK`.

    strideWORK: integer
        stride length for `WORK`.

    offsetWORK: integer
        starting index for `WORK`.

    lwork: integer
        `lwork`.

    -------
    out: Float64Array
