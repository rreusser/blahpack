{{alias}}( order, N, A, LDA, k1, k2, inck, IPIV, strideIPIV )
    Performs a series of row interchanges on a general rectangular matrix.

    Parameters
    ----------
    order: string
        Row-major (C-style) or column-major (Fortran-style) order.

    N: integer
        number of columns.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    k1: number
        `k1`.

    k2: number
        `k2`.

    inck: integer
        Direction in which to apply pivots (-1 to apply pivots in reverse
        order; otherwise, apply in provided order).

    IPIV: Int32Array
        `IPIV`.

    strideIPIV: integer
        stride length for `IPIV`.

    Returns
    -------
    out: Float64Array
        Result.
