# dla_porpvgrw

> Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a symmetric positive-definite matrix.

<section class="usage">

## Usage

```javascript
var dla_porpvgrw = require( '@stdlib/lapack/base/dla_porpvgrw' );
```

#### dla_porpvgrw( uplo, ncols, A, LDA, AF, LDAF, WORK )

Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a symmetric positive-definite matrix.

```javascript
var dla_porpvgrw = require( '@stdlib/lapack/base/dla_porpvgrw' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AF = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dla_porpvgrw.ndarray( 'upper', 1, A, N, 1, 0, AF, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **ncols**: `ncols`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **AF**: input array `AF`.
-   **LDAF**: leading dimension of `AF`.
-   **WORK**: input array `WORK`.

#### dla_porpvgrw.ndarray( uplo, ncols, A, strideA1, strideA2, offsetA, AF, strideAF1, strideAF2, offsetAF, WORK, strideWORK, offsetWORK )

Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a symmetric positive-definite matrix, using alternative indexing semantics.

```javascript
var dla_porpvgrw = require( '@stdlib/lapack/base/dla_porpvgrw' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AF = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dla_porpvgrw.ndarray( 'upper', 1, A, N, 1, 0, AF, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **strideAF1**: stride of dimension 1 of `AF`.
-   **strideAF2**: stride of dimension 2 of `AF`.
-   **offsetAF**: starting index for `AF`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

</section>
