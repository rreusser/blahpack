# dgeql2

> Compute a QL factorization of a real M-by-N matrix

<section class="usage">

## Usage

```javascript
var dgeql2 = require( '@stdlib/lapack/base/dgeql2' );
```

#### dgeql2( order, M, N, A, LDA, TAU, strideTAU, WORK, strideWORK )

Compute a QL factorization of a real M-by-N matrix

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dgeql2 = require( '@stdlib/lapack/base/dgeql2' );

var M = 3;
var N = 3;
var A = discreteUniform( M * N, -10, 10, opts );
var TAU = new Float64Array( Math.min( M, N ) );
var WORK = new Float64Array( N );

dgeql2( 'column-major', M, N, A, M, TAU, 1, WORK, 1 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input matrix.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array.
-   **strideTAU**: stride length for `TAU`.
-   **WORK**: output array.
-   **strideWORK**: stride length for `WORK`.

#### dgeql2.ndarray( M, N, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, WORK, strideWORK, offsetWORK )

Compute a QL factorization of a real M-by-N matrix, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dgeql2 = require( '@stdlib/lapack/base/dgeql2' );

var M = 3;
var N = 3;
var A = discreteUniform( M * N, -10, 10, opts );
var TAU = new Float64Array( Math.min( M, N ) );
var WORK = new Float64Array( N );

dgeql2( 'column-major', M, N, A, M, TAU, 1, WORK, 1 );
```

The function has the following additional parameters:

-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input matrix.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **TAU**: input array.
-   **strideTAU**: stride length for `TAU`.
-   **offsetTAU**: starting index for `TAU`.
-   **WORK**: output array.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DGEQL2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the QL factorization of a general rectangular matrix using an unblocked algorithm.

### Purpose

DGEQL2 computes a QL factorization of a real m by n matrix A: $A = Q \, L$.

### Arguments

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### A `[in,out]`

_DOUBLE PRECISION array, dimension (LDA,N)_

On entry, the m by n matrix A. On exit, if $m \ge n$, the lower triangle of the subarray `A(m-n+1:m,1:n)` contains the n by n lower triangular matrix L; if $m \le n$, the elements on and below the (n-m)-th superdiagonal contain the m by n lower trapezoidal matrix L; the remaining elements, with the array `TAU`, represent the orthogonal matrix Q as a product of elementary reflectors (see Further Details).

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,M)$.

#### TAU `[out]`

_DOUBLE PRECISION array, dimension (min(M,N))_

The scalar factors of the elementary reflectors (see Further Details).

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value

### Further Details

The matrix Q is represented as a product of elementary reflectors

$$
Q = H(k) \cdots H(2) H(1), \quad\text{where}\quad k = \min (m,n)
$$

Each H(i) has the form

$$
H(i) = I - \tau \, v \, v^T
$$

where $\tau$ is a real scalar, and v is a real vector with $v(m-k+i+1:m) = 0$ and $v(m-k+i) = 1$; v(1:m-k+i-1) is stored on exit in `A(1:m-k+i-1,n-k+i)`, and $\tau$ in `TAU(i)`.
