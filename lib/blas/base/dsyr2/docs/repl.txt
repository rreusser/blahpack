{{alias}}( order, uplo, N, alpha, x, strideX, y, strideY, A, LDA )
    Performs the symmetric rank 2 operation A := α·x·yᵀ + α·y·xᵀ + A.

    Parameters
    ----------
    order: string
        Row-major (C-style) or column-major (Fortran-style) order.

    uplo: string
        specifies whether the upper or lower triangular part is referenced.

    N: integer
        number of columns.

    alpha: number
        scalar constant.

    x: Float64Array
        `x`.

    strideX: integer
        stride length for `X`.

    y: Float64Array
        `y`.

    strideY: integer
        stride length for `Y`.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    Returns
    -------
    out: Float64Array
        Result.
