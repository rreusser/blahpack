{{alias}}( order, M, N, nrhs, A, LDA, B, LDB, S, strideS, rcond, rank, WORK, RWORK )
    Computes the minimum norm solution to a complex linear least squares problem
    using the singular value decomposition of `A`.

    Parameters
    ----------
    order: string
        Storage layout (`'row-major'` or `'column-major'`).

    M: integer
        Number of rows of `A`.

    N: integer
        Number of columns of `A`.

    nrhs: integer
        Number of right-hand sides.

    A: Complex128Array
        Input matrix `A`; overwritten on exit.

    LDA: integer
        Leading dimension of `A`.

    B: Complex128Array
        `max(M,N)`-by-`nrhs` matrix: the right-hand sides on entry, the solution on exit.

    LDB: integer
        Leading dimension of `B` (column-major: `>= max(1,M,N)`; row-major: `>= max(1,nrhs)`).

    S: Float64Array
        Output singular values in decreasing order (length `min(M,N)`).

    strideS: integer
        Stride length for `S`.

    rcond: number
        Threshold used to determine the effective rank of `A`.

    rank: Array
        Output array; `rank[0]` is set to the effective rank of `A`.

    WORK: Complex128Array|null
        Complex workspace; if `null`, a workspace is allocated internally.

    RWORK: Float64Array|null
        Real workspace (length `>= 5*min(M,N)`); if `null`, a workspace is allocated internally.

    Returns
    -------
    info: integer
        Status code.
