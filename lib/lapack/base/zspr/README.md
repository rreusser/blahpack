# zspr

> Perform the symmetric rank-1 update of a complex symmetric packed matrix.

<section class="usage">

## Usage

```javascript
var zspr = require( '@stdlib/lapack/base/zspr' );
```

#### zspr( uplo, N, alpha, x, strideX, AP, strideAP )

Perform the symmetric rank-1 update of a complex symmetric packed matrix.

```javascript
var zspr = require( '@stdlib/lapack/base/zspr' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );
var AP = discreteUniform( N, -10, 10, opts );

zspr.ndarray( 'upper', N, 1.0, x, 1, 0, AP, 1, 0 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **alpha**: scalar constant.
-   **x**: `x`.
-   **strideX**: stride length for `X`.
-   **AP**: input array `AP`.
-   **strideAP**: stride length for `AP`.

#### zspr.ndarray( uplo, N, alpha, x, strideX, offsetX, AP, strideAP, offsetAP )

Perform the symmetric rank-1 update of a complex symmetric packed matrix, using alternative indexing semantics.

```javascript
var zspr = require( '@stdlib/lapack/base/zspr' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );
var AP = discreteUniform( N, -10, 10, opts );

zspr.ndarray( 'upper', N, 1.0, x, 1, 0, AP, 1, 0 );
```

The function has the following additional parameters:

-   **offsetX**: starting index for `X`.
-   **offsetAP**: starting index for `AP`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZSPR`. Indices are the 1-based Fortran indices of the source.

### Purpose

```text
ZSPR    performs the symmetric rank 1 operation
```

$$
A := \alpha \, x \, x^H + A
$$

where $\alpha$ is a complex scalar, x is an n element vector and A is an n by n symmetric matrix, supplied in packed form.
