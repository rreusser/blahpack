# ztrsyl

> Solves the complex Sylvester matrix equation: op(A)·X + X·op(B) = scale·C or op(A)·X - X·op(B) = scale·C.

<section class="usage">

## Usage

```javascript
var ztrsyl = require( '@stdlib/lapack/base/ztrsyl' );
```

#### ztrsyl( trana, tranb, isgn, M, N, A, LDA, B, LDB, C, LDC, scale )

Solves the complex Sylvester matrix equation: op(A)·X + X·op(B) = scale·C or op(A)·X - X·op(B) = scale·C.

```javascript
var ztrsyl = require( '@stdlib/lapack/base/ztrsyl' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );

ztrsyl.ndarray( 1, 1, 1, N, N, A, N, 1, 0, B, N, 1, 0, C, N, 1, 0, 1.0 );
```

The function has the following parameters:

-   **trana**: `trana`.
-   **tranb**: `tranb`.
-   **isgn**: `isgn`.
-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **scale**: `scale`.

#### ztrsyl.ndarray( trana, tranb, isgn, M, N, A, strideA1, strideA2, offsetA, B, strideB1, strideB2, offsetB, C, strideC1, strideC2, offsetC, scale )

Solves the complex Sylvester matrix equation: op(A)·X + X·op(B) = scale·C or op(A)·X - X·op(B) = scale·C, using alternative indexing semantics.

```javascript
var ztrsyl = require( '@stdlib/lapack/base/ztrsyl' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );

ztrsyl.ndarray( 1, 1, 1, N, N, A, N, 1, 0, B, N, 1, 0, C, N, 1, 0, 1.0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZTRSYL`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZTRSYL solves the complex Sylvester matrix equation:

$\operatorname{op}(A) \, X + X \, \operatorname{op}(B)$ = scale\*C or $\operatorname{op}(A) \, X - X \, \operatorname{op}(B)$ = scale\*C,

where $\operatorname{op}(A) = A$ or $A^H$, and A and B are both upper triangular. A is M-by-M and B is N-by-N; the right hand side C and the solution X are M-by-N; and scale is an output scale factor, set \<= 1 to avoid overflow in X.

### Arguments

#### TRANA `[in]`

_CHARACTER\*1_

Specifies the option op(A):

-   `= 'N'`: $\operatorname{op}(A) = A$    (No transpose)
-   `= 'C'`: $\operatorname{op}(A) = A^H$ (Conjugate transpose)

#### TRANB `[in]`

_CHARACTER\*1_

Specifies the option op(B):

-   `= 'N'`: $\operatorname{op}(B) = B$    (No transpose)
-   `= 'C'`: $\operatorname{op}(B) = B^H$ (Conjugate transpose)

#### ISGN `[in]`

_INTEGER_

Specifies the sign in the equation: = +1: solve $\operatorname{op}(A) \, X + X \, \operatorname{op}(B)$ = scale\*C

-   `= -1`: solve $\operatorname{op}(A) \, X - X \, \operatorname{op}(B)$ = scale\*C

#### M `[in]`

_INTEGER_

The order of the matrix A, and the number of rows in the matrices X and C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The order of the matrix B, and the number of columns in the matrices X and C. $N \ge 0$.

#### A `[in]`

_COMPLEX\*16 array, dimension (LDA,M)_

The upper triangular matrix A.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,M)$.

#### B `[in]`

_COMPLEX\*16 array, dimension (LDB,N)_

The upper triangular matrix B.

#### LDB `[in]`

_INTEGER_

The leading dimension of the array B. $\mathrm{LDB} \ge \max (1,N)$.

#### C `[in,out]`

_COMPLEX\*16 array, dimension (LDC,N)_

On entry, the M-by-N right hand side matrix C. On exit, C is overwritten by the solution matrix X.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$

#### SCALE `[out]`

_DOUBLE PRECISION_

The scale factor, scale, set \<= 1 to avoid overflow in X.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `= 1`: A and B have common or very close eigenvalues; perturbed values were used to solve the equation (but the matrices A and B are unchanged).
