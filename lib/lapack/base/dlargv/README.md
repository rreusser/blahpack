# dlargv

> Generates a vector of real plane rotations (Givens rotations).

<section class="usage">

## Usage

```javascript
var dlargv = require( '@stdlib/lapack/base/dlargv' );
```

#### dlargv( N, x, strideX, y, strideY, c, strideC )

Generates a vector of real plane rotations (Givens rotations).

```javascript
var dlargv = require( '@stdlib/lapack/base/dlargv' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );
var y = discreteUniform( N, -10, 10, opts );
var c = discreteUniform( N, -10, 10, opts );

dlargv.ndarray( N, x, 1, 0, y, 1, 0, c, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **x**: `x`.
-   **strideX**: stride length for `X`.
-   **y**: `y`.
-   **strideY**: stride length for `Y`.
-   **c**: `c`.
-   **strideC**: stride length for `C`.

#### dlargv.ndarray( N, x, strideX, offsetX, y, strideY, offsetY, c, strideC, offsetC )

Generates a vector of real plane rotations (Givens rotations), using alternative indexing semantics.

```javascript
var dlargv = require( '@stdlib/lapack/base/dlargv' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );
var y = discreteUniform( N, -10, 10, opts );
var c = discreteUniform( N, -10, 10, opts );

dlargv.ndarray( N, x, 1, 0, y, 1, 0, c, 1, 0 );
```

The function has the following additional parameters:

-   **offsetX**: starting index for `X`.
-   **offsetY**: starting index for `Y`.
-   **offsetC**: starting index for `C`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLARGV`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Generates a vector of plane rotations with real cosines and real sines.

### Purpose

DLARGV generates a vector of real plane rotations, determined by elements of the real vectors x and y. For $i = 1$,2,...,n

```text
(  c(i)  s(i) ) ( x(i) ) = ( a(i) )
( -s(i)  c(i) ) ( y(i) ) = (   0  )
```

### Arguments

#### N `[in]`

_INTEGER_

The number of plane rotations to be generated.

#### X `[in,out]`

_DOUBLE PRECISION array_

dimension (1+(N-1)\*`INCX`) On entry, the vector x. On exit, x(i) is overwritten by a(i), for $i = 1$,...,n.

#### INCX `[in]`

_INTEGER_

The increment between elements of X. $\mathrm{INCX} > 0$.

#### Y `[in,out]`

_DOUBLE PRECISION array_

dimension (1+(N-1)\*`INCY`) On entry, the vector y. On exit, the sines of the plane rotations.

#### INCY `[in]`

_INTEGER_

The increment between elements of Y. $\mathrm{INCY} > 0$.

#### C `[out]`

_DOUBLE PRECISION array, dimension (1+(N-1)\*INCC)_

The cosines of the plane rotations.

#### INCC `[in]`

_INTEGER_

The increment between elements of C. $\mathrm{INCC} > 0$.
