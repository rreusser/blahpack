## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZLARTG`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZLARTG generates a plane rotation so that

$$
\begin{bmatrix} C & S \\ -\overline{S} & C \end{bmatrix} \cdot \begin{bmatrix} F \\ G \end{bmatrix} = \begin{bmatrix} R \\ 0 \end{bmatrix}
$$

where C is real and $C^2$ + \|S\|\*\*$2 = 1$.

The mathematical formulas used for C and S are

```text
sgn(x) = {  x / |x|,   x != 0
```

```text
{  1,         x  = 0
```

$$
R = \operatorname{sgn}(F) \, \sqrt{|F|^2 + |G|^2}
$$

$$
C = |F| / \sqrt{|F|^2 + |G|^2}
$$

$$
S = \operatorname{sgn}(F) \, \overline{G} / \sqrt{|F|^2 + |G|^2}
$$

Special conditions:

-   If $G=0$, then $C=1$ and $S=0$.
-   If $F=0$, then $C=0$ and S is chosen so that R is real.

When F and G are real, the formulas simplify to $C = F/R$ and $S = G/R$, and the returned values of C, S, and R should be identical to those returned by DLARTG.

The algorithm used to compute these quantities incorporates scaling to avoid overflow or underflow in computing the square root of the sum of squares.

This is the same routine ZROTG fom BLAS1, except that F and G are unchanged on return.

Below, wp=\>dp stands for double precision from LA\_CONSTANTS module.

### Further Details

Based on the algorithm from

Anderson E. (2017) Algorithm 978: Safe Scaling in the Level 1 BLAS ACM Trans Math Softw 44:1--28 https://doi.org/10.1145/3061665
