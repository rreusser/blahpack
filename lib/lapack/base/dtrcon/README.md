# dtrcon

> Estimates the reciprocal of the condition number of a triangular matrix A, in either the 1-norm or the infinity-norm.

<section class="usage">

## Usage

```javascript
var dtrcon = require( '@stdlib/lapack/base/dtrcon' );
```

#### dtrcon( norm, uplo, diag, N, A, LDA, RCOND, WORK, strideWORK, IWORK, strideIWORK )

Estimates the reciprocal of the condition number of a triangular matrix A, in either the 1-norm or the infinity-norm.

```javascript
var dtrcon = require( '@stdlib/lapack/base/dtrcon' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );
var IWORK = discreteUniform( N, -10, 10, opts );

dtrcon.ndarray( '1', 'upper', 'non-unit', N, A, N, 1, 0, 1.0, WORK, 1, 0, IWORK, 1, 0 );
```

The function has the following parameters:

-   **norm**: `norm`.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **diag**: specifies whether the matrix is unit triangular.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **RCOND**: input array `RCOND`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.
-   **IWORK**: input array `IWORK`.
-   **strideIWORK**: stride length for `IWORK`.

#### dtrcon.ndarray( norm, uplo, diag, N, A, strideA1, strideA2, offsetA, RCOND, WORK, strideWORK, offsetWORK, IWORK, strideIWORK, offsetIWORK )

Estimates the reciprocal of the condition number of a triangular matrix A, in either the 1-norm or the infinity-norm,, using alternative indexing semantics.

```javascript
var dtrcon = require( '@stdlib/lapack/base/dtrcon' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );
var IWORK = discreteUniform( N, -10, 10, opts );

dtrcon.ndarray( '1', 'upper', 'non-unit', N, A, N, 1, 0, 1.0, WORK, 1, 0, IWORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetWORK**: starting index for `WORK`.
-   **offsetIWORK**: starting index for `IWORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DTRCON`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DTRCON estimates the reciprocal of the condition number of a triangular matrix A, in either the 1-norm or the infinity-norm.

The norm of A is computed and an estimate is obtained for norm(inv(A)), then the reciprocal of the condition number is computed as

$$
\mathrm{RCOND} = 1 / ( \operatorname{norm}(A) \, \operatorname{norm}(\operatorname{inv}(A)) )
$$

### Arguments

#### NORM `[in]`

_CHARACTER\*1_

Specifies whether the 1-norm condition number or the infinity-norm condition number is required: = '1' or 'O': 1-norm;

-   `= 'I'`: Infinity-norm.

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: A is upper triangular;
-   `= 'L'`: A is lower triangular.

#### DIAG `[in]`

_CHARACTER\*1_

-   `= 'N'`: A is non-unit triangular;
-   `= 'U'`: A is unit triangular.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### A `[in]`

_DOUBLE PRECISION array, dimension (LDA,N)_

The triangular matrix A. If `UPLO = 'U'`, the leading N-by-N upper triangular part of the array A contains the upper triangular matrix, and the strictly lower triangular part of A is not referenced. If `UPLO = 'L'`, the leading N-by-N lower triangular part of the array A contains the lower triangular matrix, and the strictly upper triangular part of A is not referenced. If `DIAG = 'U'`, the diagonal elements of A are also not referenced and are assumed to be 1.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### RCOND `[out]`

_DOUBLE PRECISION_

The reciprocal of the condition number of the matrix A, computed as $\mathrm{RCOND} = 1/(\operatorname{norm}(A) \, \operatorname{norm}(\operatorname{inv}(A)))$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (3\*N)_

#### IWORK `[out]`

_INTEGER array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
