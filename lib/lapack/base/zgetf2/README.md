# zgetf2

> Computes an LU factorization of a general M-by-N complex matrix using partial pivoting with row interchanges (unblocked algorithm).

<section class="usage">

## Usage

```javascript
var zgetf2 = require( '@stdlib/lapack/base/zgetf2' );
```

#### zgetf2( order, M, N, A, LDA, IPIV, strideIPIV )

Computes an LU factorization of a general M-by-N complex matrix using partial pivoting with row interchanges (unblocked algorithm).

```javascript
var zgetf2 = require( '@stdlib/lapack/base/zgetf2' );

zgetf2( 'column-major', 3, 3, A, 3, IPIV, 1 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.

#### zgetf2.ndarray( M, N, A, strideA1, strideA2, offsetA, IPIV, strideIPIV, offsetIPIV )

Computes an LU factorization of a general M-by-N complex matrix using partial pivoting with row interchanges (unblocked algorithm), using alternative indexing semantics.

```javascript
var zgetf2 = require( '@stdlib/lapack/base/zgetf2' );

zgetf2( 'column-major', 3, 3, A, 3, IPIV, 1 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetIPIV**: starting index for `IPIV`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZGETF2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the LU factorization of a general m-by-n matrix using partial pivoting with row interchanges (unblocked algorithm).

### Purpose

ZGETF2 computes an LU factorization of a general m-by-n matrix A using partial pivoting with row interchanges.

The factorization has the form

$$
A = P \, L \, U
$$

where P is a permutation matrix, L is lower triangular with unit diagonal elements (lower trapezoidal if $m > n$), and U is upper triangular (upper trapezoidal if $m < n$).

This is the right-looking Level 2 BLAS version of the algorithm.

### Arguments

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### A `[in,out]`

_COMPLEX\*16 array, dimension (LDA,N)_

On entry, the m by n matrix to be factored. On exit, the factors L and U from the factorization $A = P \, L \, U$; the unit diagonal elements of L are not stored.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,M)$.

#### IPIV `[out]`

_INTEGER array, dimension (min(M,N))_

The pivot indices; for $1 \le i \le \min (M,N)$, row i of the matrix was interchanged with row `IPIV(i)`.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -k`, the k-th argument had an illegal value
-   `> 0`: if `INFO = k`, U(k,k) is exactly zero. The factorization has been completed, but the factor U is exactly singular, and division by zero will occur if it is used to solve a system of equations.
