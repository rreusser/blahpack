# dlapy2

> Returns sqrt(x2+y2).

<section class="usage">

## Usage

```javascript
var dlapy2 = require( '@stdlib/lapack/base/dlapy2' );
```

#### dlapy2( x, y )

Returns sqrt(x2+y2).

```javascript
var dlapy2 = require( '@stdlib/lapack/base/dlapy2' );

dlapy2.ndarray( 1, 1 );
```

The function has the following parameters:

-   **x**: `x`.
-   **y**: `y`.
