# zunmhr

> Overwrites the general complex M-by-N matrix C with SIDE = 'L' SIDE = 'R' TRANS = 'N': Q·C C·Q TRANS = 'C': Qᴴ·C C·Qᴴ.

<section class="usage">

## Usage

```javascript
var zunmhr = require( '@stdlib/lapack/base/zunmhr' );
```

#### zunmhr( side, trans, M, N, ilo, ihi, A, LDA, TAU, strideTAU, C, LDC, WORK, strideWORK, lwork )

Overwrites the general complex M-by-N matrix C with SIDE = 'L' SIDE = 'R' TRANS = 'N': Q·C C·Q TRANS = 'C': Qᴴ·C C·Qᴴ.

```javascript
var zunmhr = require( '@stdlib/lapack/base/zunmhr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zunmhr.ndarray( 'left', 'no-transpose', N, N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0, N );
```

The function has the following parameters:

-   **side**: specifies the side of the operation.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **ilo**: `ilo`.
-   **ihi**: `ihi`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array `TAU`.
-   **strideTAU**: stride length for `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.
-   **lwork**: `lwork`.

#### zunmhr.ndarray( side, trans, M, N, ilo, ihi, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK, lwork )

Overwrites the general complex M-by-N matrix C with SIDE = 'L' SIDE = 'R' TRANS = 'N': Q·C C·Q TRANS = 'C': Qᴴ·C C·Qᴴ, using alternative indexing semantics.

```javascript
var zunmhr = require( '@stdlib/lapack/base/zunmhr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zunmhr.ndarray( 'left', 'no-transpose', N, N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0, N );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZUNMHR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZUNMHR overwrites the general complex M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $Q \, C$ | $C \, Q$ |
| `TRANS = 'C'`: | $Q^H \, C$ | $C \, Q^H$ |

where Q is a complex unitary matrix of order nq, with $\mathrm{nq} = m$ if `SIDE = 'L'` and $\mathrm{nq} = n$ if `SIDE = 'R'`. Q is defined as the product of `IHI`-`ILO` elementary reflectors, as returned by ZGEHRD:

Q = H(ilo) H(ilo+1) . . . H(ihi-1).

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^H$ from the Left;
-   `= 'R'`: apply Q or $Q^H$ from the Right.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: apply Q  (No transpose)
-   `= 'C'`: apply $Q^H$ (Conjugate transpose)

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### ILO `[in]`

_INTEGER_

#### IHI `[in]`

_INTEGER_

`ILO` and `IHI` must have the same values as in the previous call of ZGEHRD. Q is equal to the unit matrix except in the submatrix Q(ilo+1:ihi,ilo+1:ihi). If `SIDE = 'L'`, then $1 \le \mathrm{ILO} \le \mathrm{IHI} \le M$, if $M > 0$, and `ILO = 1` and `IHI = 0`, if $M = 0$; if `SIDE = 'R'`, then $1 \le \mathrm{ILO} \le \mathrm{IHI} \le N$, if $N > 0$, and `ILO = 1` and `IHI = 0`, if $N = 0$.

#### A `[in]`

_COMPLEX\*16 array, dimension (LDA,M) if SIDE = 'L'_

(`LDA`,N) if `SIDE = 'R'` The vectors which define the elementary reflectors, as returned by ZGEHRD.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,M)$ if `SIDE = 'L'`; $\mathrm{LDA} \ge \max (1,N)$ if `SIDE = 'R'`.

#### TAU `[in]`

_COMPLEX\*16 array, dimension (M-1) if SIDE = 'L'_

(N-1) if `SIDE = 'R'` `TAU(i)` must contain the scalar factor of the elementary reflector H(i), as returned by ZGEHRD.

#### C `[in,out]`

_COMPLEX\*16 array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by $Q \, C$ or $Q^H \, C$ or $C \, Q^H$ or $C \, Q$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (MAX(1,LWORK))_

On exit, if `INFO = 0`, `WORK(1)` returns the optimal `LWORK`.

#### LWORK `[in]`

_INTEGER_

The dimension of the array `WORK`. If `SIDE = 'L'`, $\mathrm{LWORK} \ge \max (1,N)$; if `SIDE = 'R'`, $\mathrm{LWORK} \ge \max (1,M)$. For optimum performance $\mathrm{LWORK} \ge N \, \mathrm{NB}$ if `SIDE = 'L'`, and $\mathrm{LWORK} \ge M \, \mathrm{NB}$ if `SIDE = 'R'`, where NB is the optimal blocksize.

If `LWORK = -1`, then a workspace query is assumed; the routine only calculates the optimal size of the `WORK` array, returns this value as the first entry of the `WORK` array, and no error message related to `LWORK` is issued by XERBLA.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
