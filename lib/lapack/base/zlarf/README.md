# zlarf

> Applies an elementary reflector to a general rectangular matrix.

<section class="usage">

## Usage

```javascript
var zlarf = require( '@stdlib/lapack/base/zlarf' );
```

#### zlarf( order, side, M, N, v, strideV, tau, offsetTau, C, LDC, WORK, strideWORK )

Applies an elementary reflector to a general rectangular matrix.

```javascript
var zlarf = require( '@stdlib/lapack/base/zlarf' );

var N = 3;
var C = discreteUniform( N * N, -10, 10, opts );
var v = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zlarf.ndarray( 'left', N, N, v, 1, 0, 1.0, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **side**: specifies the side of the operation.
-   **M**: number of rows.
-   **N**: number of columns.
-   **v**: `v`.
-   **strideV**: stride length for `V`.
-   **tau**: `tau`.
-   **offsetTau**: starting index for `Tau`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### zlarf.ndarray( side, M, N, v, strideV, offsetV, tau, offsetTau, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Applies an elementary reflector to a general rectangular matrix,, using alternative indexing semantics.

```javascript
var zlarf = require( '@stdlib/lapack/base/zlarf' );

var N = 3;
var C = discreteUniform( N * N, -10, 10, opts );
var v = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zlarf.ndarray( 'left', N, N, v, 1, 0, 1.0, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **offsetV**: starting index for `V`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZLARF`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZLARF applies a complex elementary reflector H to a complex M-by-N matrix C, from either the left or the right. H is represented in the form

$$
H = I - \tau \, v \, v^H
$$

where $\tau$ is a complex scalar and v is a complex vector.

If $\tau = 0$, then H is taken to be the unit matrix.

To apply $H^H$, supply conjg($\tau$) instead $\tau$.
