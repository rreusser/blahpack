# zpocon

> CABS1: |re(z)| + |im(z)|.

<section class="usage">

## Usage

```javascript
var zpocon = require( '@stdlib/lapack/base/zpocon' );
```

#### zpocon( v, idx )

CABS1: |re(z)| + |im(z)|.

```javascript
var zpocon = require( '@stdlib/lapack/base/zpocon' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );
var RWORK = discreteUniform( N, -10, 10, opts );

zpocon.ndarray( 'upper', N, A, N, 1, 0, 1.0, 1.0, WORK, 1, 0, RWORK, 1, 0 );
```

The function has the following parameters:

-   **v**: `v`.
-   **idx**: `idx`.

#### zpocon.ndarray( uplo, N, A, strideA1, strideA2, offsetA, anorm, rcond, WORK, strideWORK, offsetWORK, RWORK, strideRWORK, offsetRWORK )

CABS1: |re(z)| + |im(z)|, using alternative indexing semantics.

```javascript
var zpocon = require( '@stdlib/lapack/base/zpocon' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );
var RWORK = discreteUniform( N, -10, 10, opts );

zpocon.ndarray( 'upper', N, A, N, 1, 0, 1.0, 1.0, WORK, 1, 0, RWORK, 1, 0 );
```

The function has the following additional parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **anorm**: `anorm`.
-   **rcond**: `rcond`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.
-   **RWORK**: input array `RWORK`.
-   **strideRWORK**: stride length for `RWORK`.
-   **offsetRWORK**: starting index for `RWORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZPOCON`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZPOCON estimates the reciprocal of the condition number (in the 1-norm) of a complex Hermitian positive definite matrix using the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$ computed by ZPOTRF.

An estimate is obtained for norm(inv(A)), and the reciprocal of the condition number is computed as $\mathrm{RCOND} = 1 / (\mathrm{ANORM} \, \operatorname{norm}(\operatorname{inv}(A)))$.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A is stored;
-   `= 'L'`: Lower triangle of A is stored.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### A `[in]`

_COMPLEX\*16 array, dimension (LDA,N)_

The triangular factor U or L from the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$, as computed by ZPOTRF.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### ANORM `[in]`

_DOUBLE PRECISION_

The 1-norm (or infinity-norm) of the Hermitian matrix A.

#### RCOND `[out]`

_DOUBLE PRECISION_

The reciprocal of the condition number of the matrix A, computed as $\mathrm{RCOND} = 1/(\mathrm{ANORM} \, \mathrm{AINVNM})$, where AINVNM is an estimate of the 1-norm of inv(A) computed in this routine.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (2\*N)_

#### RWORK `[out]`

_DOUBLE PRECISION array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
