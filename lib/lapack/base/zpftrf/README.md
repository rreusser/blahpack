# zpftrf

> Computes the Cholesky factorization of a complex Hermitian positive definite matrix in Rectangular Full Packed format.

<section class="usage">

## Usage

```javascript
var zpftrf = require( '@stdlib/lapack/base/zpftrf' );
```

#### zpftrf( transr, uplo, N, A )

Computes the Cholesky factorization of a complex Hermitian positive definite matrix in Rectangular Full Packed format.

```javascript
var zpftrf = require( '@stdlib/lapack/base/zpftrf' );

zpftrf( 'no-transpose', 'lower', 3, A, 1, 0 );
```

The function has the following parameters:

-   **transr**: `transr`.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **A**: input array `A`.

#### zpftrf.ndarray( transr, uplo, N, A, strideA, offsetA )

Computes the Cholesky factorization of a complex Hermitian positive definite matrix in Rectangular Full Packed format, using alternative indexing semantics.

```javascript
var zpftrf = require( '@stdlib/lapack/base/zpftrf' );

zpftrf( 'no-transpose', 'lower', 3, A, 1, 0 );
```

The function has the following additional parameters:

-   **strideA**: stride length for `A`.
-   **offsetA**: starting index for `A`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZPFTRF`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZPFTRF computes the Cholesky factorization of a complex Hermitian positive definite matrix A.

The factorization has the form

$$
A = U^H \, U, \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$$
A = L \, L^H, \quad\text{if}\quad \mathrm{UPLO} = \text{'L'}
$$

where U is an upper triangular matrix and L is lower triangular.

This is the block version of the algorithm, calling Level 3 BLAS.
