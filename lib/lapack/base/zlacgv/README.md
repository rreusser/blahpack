# zlacgv

> Conjugate a complex vector in-place.

<section class="usage">

## Usage

```javascript
var zlacgv = require( '@stdlib/lapack/base/zlacgv' );
```

#### zlacgv( N, x, stride )

Conjugate a complex vector in-place.

```javascript
var zlacgv = require( '@stdlib/lapack/base/zlacgv' );

zlacgv.ndarray( N, 1, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **x**: `x`.
-   **stride**: `stride`.

#### zlacgv.ndarray( N, x, stride, offset )

Conjugate a complex vector in-place, using alternative indexing semantics.

```javascript
var zlacgv = require( '@stdlib/lapack/base/zlacgv' );

zlacgv.ndarray( N, 1, 1, 0 );
```

The function has the following additional parameters:

-   **offset**: `offset`.

</section>

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLACGV`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Conjugates a complex vector.

### Purpose

ZLACGV conjugates a complex vector of length N.

### Arguments

#### N `[in]`

_INTEGER_

The length of the vector X. $N \ge 0$.

#### X `[in,out]`

_COMPLEX\*16 array, dimension (1+(N-1)\*abs(INCX))_

On entry, the vector of length N to be conjugated. On exit, X is overwritten with conjg(X).

#### INCX `[in]`

_INTEGER_

The spacing between successive elements of X.
