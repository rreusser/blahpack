# dtpttr

> Copies a triangular matrix from standard packed format (TP) to full format (TR).

<section class="usage">

## Usage

```javascript
var dtpttr = require( '@stdlib/lapack/base/dtpttr' );
```

#### dtpttr( order, uplo, N, AP, A, LDA )

Copies a triangular matrix from standard packed format (TP) to full format (TR).

```javascript
var dtpttr = require( '@stdlib/lapack/base/dtpttr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AP = discreteUniform( N, -10, 10, opts );

dtpttr.ndarray( 'upper', N, AP, 1, 0, A, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### dtpttr.ndarray( uplo, N, AP, strideAP, offsetAP, A, strideA1, strideA2, offsetA )

Copies a triangular matrix from standard packed format (TP) to full format (TR), using alternative indexing semantics.

```javascript
var dtpttr = require( '@stdlib/lapack/base/dtpttr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AP = discreteUniform( N, -10, 10, opts );

dtpttr.ndarray( 'upper', N, AP, 1, 0, A, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DTPTTR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Copies a triangular matrix from the standard packed format (TP) to the standard full format (TR).

### Purpose

DTPTTR copies a triangular matrix A from standard packed format (TP) to standard full format (TR).

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: A is upper triangular.
-   `= 'L'`: A is lower triangular.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### AP `[in]`

_DOUBLE PRECISION array, dimension ( N\*(N+1)/2 )_

On entry, the upper or lower triangular matrix A, packed columnwise in a linear array. The j-th column of A is stored in the array `AP` as follows: if `UPLO = 'U'`, `AP(i + (j-1)*j/2) = A(i,j)` for $1 \le i \le j$; if `UPLO = 'L'`, `AP(i + (j-1)*(2n-j)/2) = A(i,j)` for $j \le i \le n$.

#### A `[out]`

_DOUBLE PRECISION array, dimension ( LDA, N )_

On exit, the triangular matrix A. If `UPLO = 'U'`, the leading N-by-N upper triangular part of A contains the upper triangular part of the matrix A, and the strictly lower triangular part of A is not referenced. If `UPLO = 'L'`, the leading N-by-N lower triangular part of A contains the lower triangular part of the matrix A, and the strictly upper triangular part of A is not referenced.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
