## Usage

```javascript
var dggbal = require( '@stdlib/lapack/base/dggbal' );
```

#### dggbal( order, job, N, A, LDA, B, LDB, LSCALE, strideLSCALE, RSCALE, strideRSCALE, WORK, strideWORK )

@license Apache-2.0.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dggbal = require( '@stdlib/lapack/base/dggbal' );

var A = new Float64Array( [ 1.0, 2.0, 3.0, 4.0 ] );
var B = new Float64Array( [ 1.0, 0.0, 0.0, 1.0 ] );
var LSCALE = new Float64Array( 2 );
var RSCALE = new Float64Array( 2 );
var WORK = new Float64Array( 12 );

dggbal.ndarray( 'both', 2, A, 1, 2, 0, B, 1, 2, 0, LSCALE, 1, 0, RSCALE, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **job**: `job`.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.
-   **LSCALE**: input array `LSCALE`.
-   **strideLSCALE**: stride length for `LSCALE`.
-   **RSCALE**: input array `RSCALE`.
-   **strideRSCALE**: stride length for `RSCALE`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

-   **offsetB**: starting index for `B`.
-   **offsetLSCALE**: starting index for `LSCALE`.
-   **offsetRSCALE**: starting index for `RSCALE`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DGGBAL`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DGGBAL balances a pair of general real matrices (A,B). This involves, first, permuting A and B by similarity transformations to isolate eigenvalues in the first 1 to `ILO`\$-\$1 and last `IHI`+1 to N elements on the diagonal; and second, applying a diagonal similarity transformation to rows and columns `ILO` to `IHI` to make the rows and columns as close in norm as possible. Both steps are optional.

Balancing may reduce the 1-norm of the matrices, and improve the accuracy of the computed eigenvalues and/or eigenvectors in the generalized eigenvalue problem $A \, x = \lambda \, B \, x$.

### Arguments

#### JOB `[in]`

_CHARACTER\*1_

Specifies the operations to be performed on A and B:

-   `= 'N'`: none:  simply set `ILO = 1`, `IHI = N`, `LSCALE(I) = 1.0` and `RSCALE(I) = 1.0` for $i = 1$,...,N.
-   `= 'P'`: permute only;
-   `= 'S'`: scale only;
-   `= 'B'`: both permute and scale.

#### N `[in]`

_INTEGER_

The order of the matrices A and B. $N \ge 0$.

#### A `[in,out]`

_DOUBLE PRECISION array, dimension (LDA,N)_

On entry, the input matrix A. On exit, A is overwritten by the balanced matrix. If `JOB = 'N'`, A is not referenced.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### B `[in,out]`

_DOUBLE PRECISION array, dimension (LDB,N)_

On entry, the input matrix B. On exit, B is overwritten by the balanced matrix. If `JOB = 'N'`, B is not referenced.

#### LDB `[in]`

_INTEGER_

The leading dimension of the array B. $\mathrm{LDB} \ge \max (1,N)$.

#### ILO `[out]`

_INTEGER_

#### IHI `[out]`

_INTEGER_

`ILO` and `IHI` are set to integers such that on exit $A(i,j) = 0$ and $B(i,j) = 0$ if $i > j$ and $j = 1$,...,`ILO`-1 or $i = \mathrm{IHI}+1$,...,N. If `JOB = 'N'` or 'S', `ILO = 1` and `IHI = N`.

#### LSCALE `[out]`

_DOUBLE PRECISION array, dimension (N)_

Details of the permutations and scaling factors applied to the left side of A and B. If P(j) is the index of the row interchanged with row j, and D(j) is the scaling factor applied to row j, then

```text
LSCALE(j) = P(j)    for J = 1,...,ILO-1
          = D(j)    for J = ILO,...,IHI
          = P(j)    for J = IHI+1,...,N.
```

The order in which the interchanges are made is N to `IHI`+1, then 1 to `ILO`-1.

#### RSCALE `[out]`

_DOUBLE PRECISION array, dimension (N)_

Details of the permutations and scaling factors applied to the right side of A and B. If P(j) is the index of the column interchanged with column j, and D(j) is the scaling factor applied to column j, then

```text
LSCALE(j) = P(j)    for J = 1,...,ILO-1
          = D(j)    for J = ILO,...,IHI
          = P(j)    for J = IHI+1,...,N.
```

The order in which the interchanges are made is N to `IHI`+1, then 1 to `ILO`-1.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (lwork)_

lwork must be at least max(1,6\*N) when `JOB = 'S'` or 'B', and at least 1 when `JOB = 'N'` or 'P'.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value.

### Further Details

See R.C. WARD, Balancing the generalized eigenvalue problem,

SIAM J. Sci. Stat. Comp. 2 (1981), 141-152.
