## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAQR2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Performs the unitary similarity transformation of a Hessenberg matrix to detect and deflate fully converged eigenvalues from a trailing principal submatrix (aggressive early deflation).

### Purpose

ZLAQR2 is identical to ZLAQR3 except that it avoids recursion by calling ZLAHQR instead of ZLAQR4.

Aggressive early deflation:

ZLAQR2 accepts as input an upper Hessenberg matrix H and performs an unitary similarity transformation designed to detect and deflate fully converged eigenvalues from a trailing principal submatrix. On output H has been over- written by a new Hessenberg matrix that is a perturbation of an unitary similarity transformation of H. It is to be hoped that the final version of H has many zero subdiagonal entries.

### Arguments

#### WANTT `[in]`

_LOGICAL_

If .TRUE., then the Hessenberg matrix H is fully updated so that the triangular Schur factor may be computed (in cooperation with the calling subroutine). If .FALSE., then only enough of H is updated to preserve the eigenvalues.

#### WANTZ `[in]`

_LOGICAL_

If .TRUE., then the unitary matrix Z is updated so so that the unitary Schur factor may be computed (in cooperation with the calling subroutine). If .FALSE., then Z is not referenced.

#### N `[in]`

_INTEGER_

The order of the matrix H and (if `WANTZ` is .TRUE.) the order of the unitary matrix Z.

#### KTOP `[in]`

_INTEGER_

It is assumed that either `KTOP = 1` or $H(\mathrm{KTOP},\mathrm{KTOP}-1)=0$. `KBOT` and `KTOP` together determine an isolated block along the diagonal of the Hessenberg matrix.

#### KBOT `[in]`

_INTEGER_

It is assumed without a check that either `KBOT = N` or $H(\mathrm{KBOT}+1,\mathrm{KBOT})=0$. `KBOT` and `KTOP` together determine an isolated block along the diagonal of the Hessenberg matrix.

#### NW `[in]`

_INTEGER_

Deflation window size. $1 \le \mathrm{NW} \le (\mathrm{KBOT}-\mathrm{KTOP}+1)$.

#### H `[in,out]`

_COMPLEX\*16 array, dimension (LDH,N)_

On input the initial N-by-N section of H stores the Hessenberg matrix undergoing aggressive early deflation. On output H has been transformed by a unitary similarity transformation, perturbed, and the returned to Hessenberg form that (it is to be hoped) has some zero subdiagonal entries.

#### LDH `[in]`

_INTEGER_

Leading dimension of H just as declared in the calling subroutine. $N \le \mathrm{LDH}$

#### ILOZ `[in]`

_INTEGER_

#### IHIZ `[in]`

_INTEGER_

Specify the rows of Z to which transformations must be applied if `WANTZ` is .TRUE.. $1 \le \mathrm{ILOZ} \le \mathrm{IHIZ} \le N$.

#### Z `[in,out]`

_COMPLEX\*16 array, dimension (LDZ,N)_

IF `WANTZ` is .TRUE., then on output, the unitary similarity transformation mentioned above has been accumulated into `Z(ILOZ:IHIZ,ILOZ:IHIZ)` from the right. If `WANTZ` is .FALSE., then Z is unreferenced.

#### LDZ `[in]`

_INTEGER_

The leading dimension of Z just as declared in the calling subroutine. $1 \le \mathrm{LDZ}$.

#### NS `[out]`

_INTEGER_

The number of unconverged (ie approximate) eigenvalues returned in SR and SI that may be used as shifts by the calling subroutine.

#### ND `[out]`

_INTEGER_

The number of converged eigenvalues uncovered by this subroutine.

#### SH `[out]`

_COMPLEX\*16 array, dimension (KBOT)_

On output, approximate eigenvalues that may be used for shifts are stored in `SH(KBOT-ND-NS+1)` through SR(`KBOT`-`ND`). Converged eigenvalues are stored in `SH(KBOT-ND+1)` through `SH(KBOT)`.

#### V `[out]`

_COMPLEX\*16 array, dimension (LDV,NW)_

An `NW`-by-`NW` work array.

#### LDV `[in]`

_INTEGER_

The leading dimension of V just as declared in the calling subroutine. $\mathrm{NW} \le \mathrm{LDV}$

#### NH `[in]`

_INTEGER_

The number of columns of T. $\mathrm{NH} \ge \mathrm{NW}$.

#### T `[out]`

_COMPLEX\*16 array, dimension (LDT,NW)_

#### LDT `[in]`

_INTEGER_

The leading dimension of T just as declared in the calling subroutine. $\mathrm{NW} \le \mathrm{LDT}$

#### NV `[in]`

_INTEGER_

The number of rows of work array `WV` available for workspace. $\mathrm{NV} \ge \mathrm{NW}$.

#### WV `[out]`

_COMPLEX\*16 array, dimension (LDWV,NW)_

#### LDWV `[in]`

_INTEGER_

The leading dimension of W just as declared in the calling subroutine. $\mathrm{NW} \le \mathrm{LDV}$

#### WORK `[out]`

_COMPLEX\*16 array, dimension (LWORK)_

On exit, `WORK(1)` is set to an estimate of the optimal value of `LWORK` for the given values of N, `NW`, `KTOP` and `KBOT`.

#### LWORK `[in]`

_INTEGER_

The dimension of the work array `WORK`. $\mathrm{LWORK} = 2 \, \mathrm{NW}$ suffices, but greater efficiency may result from larger values of `LWORK`.

If `LWORK = -1`, then a workspace query is assumed; ZLAQR2 only estimates the optimal workspace size for the given values of N, `NW`, `KTOP` and `KBOT`. The estimate is returned in `WORK(1)`. No error message related to `LWORK` is issued by XERBLA. Neither H nor Z are accessed.
