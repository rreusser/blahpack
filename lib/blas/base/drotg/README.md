# drotg

> Constructs a Givens plane rotation.

<section class="usage">

## Usage

```javascript
var drotg = require( '@stdlib/blas/base/drotg' );
```

#### drotg( a, b, c, s )

Constructs a Givens plane rotation.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var drotg = require( '@stdlib/blas/base/drotg' );

var ab = new Float64Array( [ 3.0, 4.0 ] );
var cs = new Float64Array( 2 );

drotg.ndarray( ab, 1, 0, cs, 1, 0 );
```

The function has the following parameters:

-   **ab**: `ab`.
-   **strideAB**: stride length for `AB`.
-   **cs**: `cs`.
-   **strideCS**: stride length for `CS`.

#### drotg.ndarray( a, b, c, s )

Constructs a Givens plane rotation, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var drotg = require( '@stdlib/blas/base/drotg' );

var ab = new Float64Array( [ 3.0, 4.0 ] );
var cs = new Float64Array( 2 );

drotg.ndarray( ab, 1, 0, cs, 1, 0 );
```

The function has the following additional parameters:

-   **offsetAB**: starting index for `AB`.
-   **offsetCS**: starting index for `CS`.

## Reference notes

The mathematical description from the reference BLAS 3.12.0 source of `DROTG`. Indices are the 1-based Fortran indices of the source.

### Purpose

DROTG constructs a plane rotation

$$
\begin{bmatrix} c & s \\ -s & c \end{bmatrix} \begin{bmatrix} a \\ b \end{bmatrix} = \begin{bmatrix} r \\ 0 \end{bmatrix}
$$

satisfying $c^2 + s^2 = 1$.

The computation uses the formulas

```text
   sigma = sgn(a)    if |a| >  |b|
         = sgn(b)    if |b| >= |a|
   r = sigma*sqrt( a**2 + b**2 )
   c = 1; s = 0      if r = 0
   c = a/r; s = b/r  if r != 0
The subroutine also computes
   z = s    if |a| > |b|,
     = 1/c  if |b| >= |a| and c != 0
     = 1    if c = 0
This allows c and s to be reconstructed from z as follows:
   If z = 1, set c = 0, s = 1.
   If |z| < 1, set c = sqrt(1 - z**2) and s = z.
   If |z| > 1, set c = 1/z and s = sqrt( 1 - c**2).
```

### Further Details

Anderson E. (2017) Algorithm 978: Safe Scaling in the Level 1 BLAS ACM Trans Math Softw 44:1--28 https://doi.org/10.1145/3061665
