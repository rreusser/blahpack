# zla_syrpvgrw

> Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a complex symmetric indefinite matrix.

<section class="usage">

## Usage

```javascript
var zla_syrpvgrw = require( '@stdlib/lapack/base/zla_syrpvgrw' );
```

#### zla_syrpvgrw( uplo, N, info, A, LDA, AF, LDAF, IPIV, WORK )

Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a complex symmetric indefinite matrix.

```javascript
var zla_syrpvgrw = require( '@stdlib/lapack/base/zla_syrpvgrw' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AF = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zla_syrpvgrw.ndarray( 'upper', N, 1, A, N, 1, 0, AF, N, 1, 0, IPIV, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **info**: `info`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **AF**: input array `AF`.
-   **LDAF**: leading dimension of `AF`.
-   **IPIV**: input array `IPIV`.
-   **WORK**: input array `WORK`.

#### zla_syrpvgrw.ndarray( uplo, N, info, A, strideA1, strideA2, offsetA, AF, strideAF1, strideAF2, offsetAF, IPIV, strideIPIV, offsetIPIV, WORK, strideWORK, offsetWORK )

Computes the reciprocal pivot growth factor `norm(A)/norm(U)` for a complex symmetric indefinite matrix, using alternative indexing semantics.

```javascript
var zla_syrpvgrw = require( '@stdlib/lapack/base/zla_syrpvgrw' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var AF = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zla_syrpvgrw.ndarray( 'upper', N, 1, A, N, 1, 0, AF, N, 1, 0, IPIV, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **strideAF1**: stride of dimension 1 of `AF`.
-   **strideAF2**: stride of dimension 2 of `AF`.
-   **offsetAF**: starting index for `AF`.
-   **strideIPIV**: stride length for `IPIV`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

</section>
