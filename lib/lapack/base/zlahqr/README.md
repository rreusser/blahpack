# zlahqr

> CABS1(z) = |Re(z)| + |Im(z)|.

<section class="usage">

## Usage

```javascript
var zlahqr = require( '@stdlib/lapack/base/zlahqr' );
```

#### zlahqr( v, idx )

CABS1(z) = |Re(z)| + |Im(z)|.

```javascript
var zlahqr = require( '@stdlib/lapack/base/zlahqr' );

var N = 3;
var H = discreteUniform( N * N, -10, 10, opts );
var Z = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N, -10, 10, opts );

zlahqr.ndarray( 1, 1, N, N, N, H, N, 1, 0, W, 1, 0, 1, 1, Z, N, 1, 0 );
```

The function has the following parameters:

-   **v**: `v`.
-   **idx**: `idx`.

#### zlahqr.ndarray( wantt, wantz, N, ilo, ihi, H, strideH1, strideH2, offsetH, W, strideW, offsetW, iloz, ihiz, Z, strideZ1, strideZ2, offsetZ )

-   **W**: input array `W`.
-   **strideW**: stride length for `W`.
-   **offsetW**: starting index for `W`.
-   **iloz**: `iloz`.
-   **ihiz**: `ihiz`.
-   **Z**: input array `Z`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAHQR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the eigenvalues and Schur factorization of an upper Hessenberg matrix, using the double-shift/single-shift QR algorithm.

### Purpose

ZLAHQR is an auxiliary routine called by CHSEQR to update the eigenvalues and Schur decomposition already computed by CHSEQR, by dealing with the Hessenberg submatrix in rows and columns `ILO` to `IHI`.

### Arguments

#### WANTT `[in]`

_LOGICAL_

= .TRUE. : the full Schur form T is required; = .FALSE.: only eigenvalues are required.

#### WANTZ `[in]`

_LOGICAL_

= .TRUE. : the matrix of Schur vectors Z is required; = .FALSE.: Schur vectors are not required.

#### N `[in]`

_INTEGER_

The order of the matrix H. $N \ge 0$.

#### ILO `[in]`

_INTEGER_

#### IHI `[in]`

_INTEGER_

It is assumed that H is already upper triangular in rows and columns `IHI`+1:N, and that $H(\mathrm{ILO},\mathrm{ILO}-1) = 0$ (unless `ILO = 1`). ZLAHQR works primarily with the Hessenberg submatrix in rows and columns `ILO` to `IHI`, but applies transformations to all of H if `WANTT` is .TRUE.. $1 \le \mathrm{ILO} \le \max (1,\mathrm{IHI})$; $\mathrm{IHI} \le N$.

#### H `[in,out]`

_COMPLEX\*16 array, dimension (LDH,N)_

On entry, the upper Hessenberg matrix H. On exit, if `INFO` is zero and if `WANTT` is .TRUE., then H is upper triangular in rows and columns `ILO`:`IHI`. If `INFO` is zero and if `WANTT` is .FALSE., then the contents of H are unspecified on exit. The output state of H in case INF is positive is below under the description of `INFO`.

#### LDH `[in]`

_INTEGER_

The leading dimension of the array H. $\mathrm{LDH} \ge \max (1,N)$.

#### W `[out]`

_COMPLEX\*16 array, dimension (N)_

The computed eigenvalues `ILO` to `IHI` are stored in the corresponding elements of W. If `WANTT` is .TRUE., the eigenvalues are stored in the same order as on the diagonal of the Schur form returned in H, with $W(i) = H(i,i)$.

#### ILOZ `[in]`

_INTEGER_

#### IHIZ `[in]`

_INTEGER_

Specify the rows of Z to which transformations must be applied if `WANTZ` is .TRUE.. $1 \le \mathrm{ILOZ} \le \mathrm{ILO}$; $\mathrm{IHI} \le \mathrm{IHIZ} \le N$.

#### Z `[in,out]`

_COMPLEX\*16 array, dimension (LDZ,N)_

If `WANTZ` is .TRUE., on entry Z must contain the current matrix Z of transformations accumulated by CHSEQR, and on exit Z has been updated; transformations are applied only to the submatrix `Z(ILOZ:IHIZ,ILO:IHI)`. If `WANTZ` is .FALSE., Z is not referenced.

#### LDZ `[in]`

_INTEGER_

The leading dimension of the array Z. $\mathrm{LDZ} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `> 0`: if `INFO = i`, ZLAHQR failed to compute all the eigenvalues `ILO` to `IHI` in a total of 30 iterations per eigenvalue; elements i+1:ihi of W contain those eigenvalues which have been successfully computed.

If $\mathrm{INFO} > 0$ and `WANTT` is .FALSE., then on exit, the remaining unconverged eigenvalues are the eigenvalues of the upper Hessenberg matrix rows and columns `ILO` through `INFO` of the final, output value of H.

```text
        If INFO > 0 and WANTT is .TRUE., then on exit
(*)       (initial value of H)*U  = U*(final value of H)
        where U is an orthogonal matrix.    The final
        value of H is upper Hessenberg and triangular in
        rows and columns INFO+1 through IHI.
```

If $\mathrm{INFO} > 0$ and `WANTZ` is .TRUE., then on exit

(final value of Z) = (initial value of Z)\*U

where U is the orthogonal matrix in (\*) (regardless of the value of `WANTT`.)
