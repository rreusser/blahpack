# zdrscl

> Multiplies a vector by the reciprocal of a real scalar.

<section class="usage">

## Usage

```javascript
var zdrscl = require( '@stdlib/lapack/base/zdrscl' );
```

#### zdrscl( N, sa, x, strideX )

Multiplies a vector by the reciprocal of a real scalar.

```javascript
var zdrscl = require( '@stdlib/lapack/base/zdrscl' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );

zdrscl.ndarray( N, 1, x, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **sa**: `sa`.
-   **x**: `x`.
-   **strideX**: stride length for `X`.

#### zdrscl.ndarray( N, sa, x, strideX, offsetX )

Multiplies a vector by the reciprocal of a real scalar, using alternative indexing semantics.

```javascript
var zdrscl = require( '@stdlib/lapack/base/zdrscl' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );

zdrscl.ndarray( N, 1, x, 1, 0 );
```

The function has the following additional parameters:

-   **offsetX**: starting index for `X`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZDRSCL`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Multiplies a vector by the reciprocal of a real scalar.

### Purpose

ZDRSCL multiplies an n-element complex vector x by the real scalar 1/a. This is done without overflow or underflow as long as the final result x/a does not overflow or underflow.

### Arguments

#### N `[in]`

_INTEGER_

The number of components of the vector x.

#### SA `[in]`

_DOUBLE PRECISION_

The scalar a which is used to divide each component of x. `SA` must be \>= 0, or the subroutine will divide by zero.

#### SX `[in,out]`

_COMPLEX\*16 array, dimension (1+(N-1)\*abs(INCX))_

The n-element vector x.

#### INCX `[in]`

_INTEGER_

The increment between successive values of the vector `SX`.

-   `> 0`: `SX(1) = X(1)` and `SX(1+(i-1)*INCX) = x(i)`,     $1< i \le n$
