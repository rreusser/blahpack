# zlahef

> CABS1: |re(z)| + |im(z)|.

<section class="usage">

## Usage

```javascript
var zlahef = require( '@stdlib/lapack/base/zlahef' );
```

#### zlahef( v, idx )

CABS1: |re(z)| + |im(z)|.

```javascript
var zlahef = require( '@stdlib/lapack/base/zlahef' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zlahef.ndarray( 'upper', N, N, N, A, N, 1, 0, IPIV, 1, 0, W, N, 1, 0 );
```

The function has the following parameters:

-   **v**: `v`.
-   **idx**: `idx`.

#### zlahef.ndarray( uplo, N, nb, kb, A, strideA1, strideA2, offsetA, IPIV, strideIPIV, offsetIPIV, W, strideW1, strideW2, offsetW )

CABS1: |re(z)| + |im(z)|, using alternative indexing semantics.

```javascript
var zlahef = require( '@stdlib/lapack/base/zlahef' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zlahef.ndarray( 'upper', N, N, N, A, N, 1, 0, IPIV, 1, 0, W, N, 1, 0 );
```

The function has the following additional parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **nb**: `nb`.
-   **kb**: `kb`.
-   **A**: input array `A`.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **W**: input array `W`.
-   **strideW1**: stride of dimension 1 of `W`.
-   **strideW2**: stride of dimension 2 of `W`.
-   **offsetW**: starting index for `W`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZLAHEF`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZLAHEF computes a partial factorization of a complex Hermitian matrix A using the Bunch-Kaufman diagonal pivoting method. The partial factorization has the form:

$$
A = \begin{pmatrix} I & U_{12} \\ 0 & U_{22} \end{pmatrix} \begin{pmatrix} A_{11} & 0 \\ 0 & D \end{pmatrix} \begin{pmatrix} I & 0 \\ U_{12}^H & U_{22}^H \end{pmatrix} \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$A = ( L_{11} 0 )$ ( D 0 ) $( L_{11}^H L_{21}^H )$ if `UPLO = 'L'`

( L21 I ) ( 0 A22 ) ( 0 I )

where the order of D is at most `NB`. The actual order is returned in the argument `KB`, and is either `NB` or `NB`-1, or N if $N \le \mathrm{NB}$. Note that $U^H$ denotes the conjugate transpose of U.

ZLAHEF is an auxiliary routine called by ZHETRF. It uses blocked code (calling Level 3 BLAS) to update the submatrix A11 (if `UPLO = 'U'`) or A22 (if `UPLO = 'L'`).
