# zgbtrs

> Solves a system of linear equations `A*X = B`, `A^T*X = B`, or `A^H*X = B`.

<section class="usage">

## Usage

```javascript
var zgbtrs = require( '@stdlib/lapack/base/zgbtrs' );
```

#### zgbtrs( order, trans, N, kl, ku, nrhs, AB, LDAB, IPIV, strideIPIV, B, LDB )

Solves a system of linear equations `A*X = B`, `A^T*X = B`, or `A^H*X = B`.

```javascript
var zgbtrs = require( '@stdlib/lapack/base/zgbtrs' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zgbtrs.ndarray( 'no-transpose', N, N, N, N, AB, N, 1, 0, IPIV, 1, 0, B, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **trans**: specifies whether the matrix should be transposed.
-   **N**: number of columns.
-   **kl**: number of subdiagonals.
-   **ku**: number of superdiagonals.
-   **nrhs**: number of right-hand sides.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### zgbtrs.ndarray( trans, N, kl, ku, nrhs, AB, strideAB1, strideAB2, offsetAB, IPIV, strideIPIV, offsetIPIV, B, strideB1, strideB2, offsetB )

Solves a system of linear equations `A*X = B`, `A^T*X = B`, or `A^H*X = B`, using alternative indexing semantics.

```javascript
var zgbtrs = require( '@stdlib/lapack/base/zgbtrs' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zgbtrs.ndarray( 'no-transpose', N, N, N, N, AB, N, 1, 0, IPIV, 1, 0, B, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

</section>

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZGBTRS`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZGBTRS solves a system of linear equations

$$
A \, X = B, A^T \, X = B, \quad\text{or}\quad A^H \, X = B
$$

with a general band matrix A using the LU factorization computed by ZGBTRF.
