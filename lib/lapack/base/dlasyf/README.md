# dlasyf

> Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method.

<section class="usage">

## Usage

```javascript
var dlasyf = require( '@stdlib/lapack/base/dlasyf' );
```

#### dlasyf( order, uplo, N, nb, kb, A, LDA, IPIV, strideIPIV, W, LDW )

Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method.

```javascript
var dlasyf = require( '@stdlib/lapack/base/dlasyf' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

dlasyf.ndarray( 'upper', N, N, A, N, 1, 0, IPIV, 1, 0, W, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **nb**: `nb`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.
-   **W**: input array `W`.
-   **LDW**: leading dimension of `W`.

#### dlasyf.ndarray( uplo, N, nb, kb, A, strideA1, strideA2, offsetA, IPIV, strideIPIV, offsetIPIV, W, strideW1, strideW2, offsetW )

Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method, using alternative indexing semantics.

```javascript
var dlasyf = require( '@stdlib/lapack/base/dlasyf' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

dlasyf.ndarray( 'upper', N, N, A, N, 1, 0, IPIV, 1, 0, W, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideW1**: stride of dimension 1 of `W`.
-   **strideW2**: stride of dimension 2 of `W`.
-   **offsetW**: starting index for `W`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DLASYF`. Indices are the 1-based Fortran indices of the source.

### Purpose

DLASYF computes a partial factorization of a real symmetric matrix A using the Bunch-Kaufman diagonal pivoting method. The partial factorization has the form:

$$
A = \begin{pmatrix} I & U_{12} \\ 0 & U_{22} \end{pmatrix} \begin{pmatrix} A_{11} & 0 \\ 0 & D \end{pmatrix} \begin{pmatrix} I & 0 \\ U_{12}^T & U_{22}^T \end{pmatrix} \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$A = ( L_{11} 0 )$ ( D 0 ) $( L_{11}^T L_{21}^T )$ if `UPLO = 'L'`

( L21 I ) ( 0 A22 ) ( 0 I )

where the order of D is at most `NB`. The actual order is returned in the argument `KB`, and is either `NB` or `NB`-1, or N if $N \le \mathrm{NB}$.

DLASYF is an auxiliary routine called by DSYTRF. It uses blocked code (calling Level 3 BLAS) to update the submatrix A11 (if `UPLO = 'U'`) or A22 (if `UPLO = 'L'`).
