# dger

> Performs the rank 1 operation A := alpha_x_y**T + A.

<section class="usage">

## Usage

```javascript
var dger = require( '@stdlib/blas/base/dger' );
```

#### dger( order, M, N, alpha, x, strideX, y, strideY, A, LDA )

Performs the rank 1 operation A := alpha_x_y**T + A.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dger = require( '@stdlib/blas/base/dger' );

var x = new Float64Array( [ 1.0, 2.0 ] );
var y = new Float64Array( [ 3.0, 4.0 ] );
var A = new Float64Array( [ 0.0, 0.0, 0.0, 0.0 ] );

dger.ndarray( 2, 2, 1.0, x, 1, 0, y, 1, 0, A, 2, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **M**: number of rows.
-   **N**: number of columns.
-   **alpha**: scalar constant.
-   **x**: `x`.
-   **strideX**: stride length for `X`.
-   **y**: `y`.
-   **strideY**: stride length for `Y`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### dger.ndarray( M, N, alpha, x, strideX, offsetX, y, strideY, offsetY, A, strideA1, strideA2, offsetA )

Performs the rank 1 operation A := alpha_x_y**T + A, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dger = require( '@stdlib/blas/base/dger' );

var x = new Float64Array( [ 1.0, 2.0 ] );
var y = new Float64Array( [ 3.0, 4.0 ] );
var A = new Float64Array( [ 0.0, 0.0, 0.0, 0.0 ] );

dger.ndarray( 2, 2, 1.0, x, 1, 0, y, 1, 0, A, 2, 1, 0 );
```

The function has the following additional parameters:

-   **offsetX**: starting index for `X`.
-   **offsetY**: starting index for `Y`.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

</section>

## Reference notes

The mathematical description from the reference BLAS 3.12.0 source of `DGER`. Indices are the 1-based Fortran indices of the source.

### Purpose

DGER performs the rank 1 operation

$$
A := \alpha \, x \, y^T + A
$$

where $\alpha$ is a scalar, x is an m element vector, y is an n element vector and A is an m by n matrix.

### Further Details

Level 2 Blas routine.
