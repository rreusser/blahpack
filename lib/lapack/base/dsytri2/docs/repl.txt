
{{alias}}( order, uplo, N, A, LDA, IPIV, strideIPIV, WORK )
    Computes the inverse of a real symmetric indefinite matrix using the factorization produced by dsytrf, dispatching to dsytri (unblocked) or dsytri2x (blocked)

    Parameters
    ----------
    order: string
        Storage layout (`'row-major'` or `'column-major'`).

    uplo: string
        Specifies whether the upper or lower triangle of `A` is stored (`'upper'` or `'lower'`).

    N: integer
        Order of the matrix `A`.

    A: Float64Array
        Input/output matrix `A`.

    LDA: integer
        Leading dimension of `A`.

    IPIV: Int32Array
        Pivot indices from the factorization.

    strideIPIV: integer
        Stride length for `IPIV`.

    WORK: Float64Array|null
        Workspace of length at least `max(1,N)` when `N <= NBMAX`, else `(N+NBMAX+1)*(NBMAX+3)`, where `NBMAX = ILAENV( 1, 'DSYTRI2', ... ) = 1`; if `null`, a workspace is allocated internally.

    Returns
    -------
    out: integer
        Result.
