# zlags2

> Computes 2-by-2 unitary matrices U, V, and Q for the generalized upper (lower) triangular form.

<section class="usage">

## Usage

```javascript
var zlags2 = require( '@stdlib/lapack/base/zlags2' );
```

#### zlags2( upper, a1, a2, a3, b1, b2, b3, csu, snu, csv, snv, csq, snq )

Computes 2-by-2 unitary matrices U, V, and Q for the generalized upper (lower) triangular form.

```javascript
var zlags2 = require( '@stdlib/lapack/base/zlags2' );

zlags2( true, 4.0, new Complex128( 2.0, 1.0 ), 3.0, 1.0, new Complex128( 0.5, 0.25 ), 2.0 );
```

The function has the following parameters:

-   **upper**: `upper`.
-   **a1**: `a1`.
-   **a2**: `a2`.
-   **a3**: `a3`.
-   **b1**: `b1`.
-   **b2**: `b2`.
-   **b3**: `b3`.

#### zlags2.ndarray( upper, a1, a2, a3, b1, b2, b3, csu, snu, csv, snv, csq, snq )

Computes 2-by-2 unitary matrices U, V, and Q for the generalized upper (lower) triangular form, using alternative indexing semantics.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZLAGS2`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZLAGS2 computes 2-by-2 unitary matrices U, V and Q, such that if ( `UPPER` ) then

```text
          U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
                            ( 0  A3 )     ( x  x  )
and
          V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
                           ( 0  B3 )     ( x  x  )
```

or if ( .NOT.`UPPER` ) then

```text
          U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
                            ( A2 A3 )     ( 0  x  )
and
          V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
                            ( B2 B3 )     ( 0  x  )
```

where

$$
U = \begin{pmatrix} \mathrm{CSU} & \mathrm{SNU} \\ -\mathrm{SNU}^H & \mathrm{CSU} \end{pmatrix} , V = \begin{pmatrix} \mathrm{CSV} & \mathrm{SNV} \\ -\mathrm{SNV}^H & \mathrm{CSV} \end{pmatrix}
$$

$$
Q = \begin{pmatrix} \mathrm{CSQ} & \mathrm{SNQ} \\ -\mathrm{SNQ}^H & \mathrm{CSQ} \end{pmatrix}
$$

The rows of the transformed A and B are parallel. Moreover, if the input 2-by-2 matrix A is not zero, then the transformed (1,1) entry of A is not zero. If the input matrices A and B are both not zero, then the transformed (2,2) element of B is not zero, except when the first rows of input A and B are parallel and the second rows are zero.
