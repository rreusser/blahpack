    Bunch-Kaufman diagonal pivoting method.

    Parameters
    ----------
    uplo: string
        specifies whether the upper or lower triangular part is referenced.

    N: integer
        number of columns.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    IPIV: Int32Array
        `IPIV`.

    strideIPIV: integer
