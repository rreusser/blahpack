# zlacp2

> @license Apache-2.0.

<section class="usage">

## Usage

```javascript
var zlacp2 = require( '@stdlib/lapack/base/zlacp2' );
```

#### zlacp2( order, uplo, M, N, A, LDA, B, LDB )

@license Apache-2.0.

```javascript
var zlacp2 = require( '@stdlib/lapack/base/zlacp2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );

zlacp2.ndarray( 'upper', N, N, A, N, 1, 0, B, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### zlacp2.ndarray( uplo, M, N, A, strideA1, strideA2, offsetA, B, strideB1, strideB2, offsetB )

@license Apache-2.0, using alternative indexing semantics.

```javascript
var zlacp2 = require( '@stdlib/lapack/base/zlacp2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );

zlacp2.ndarray( 'upper', N, N, A, N, 1, 0, B, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLACP2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Copies all or part of a real two-dimensional array to a complex array.

### Purpose

ZLACP2 copies all or part of a real two-dimensional matrix A to a complex matrix B.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies the part of the matrix A to be copied to B.

-   `= 'U'`: Upper triangular part
-   `= 'L'`: Lower triangular part Otherwise:  All of the matrix A

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### A `[in]`

_DOUBLE PRECISION array, dimension (LDA,N)_

The m by n matrix A. If `UPLO = 'U'`, only the upper trapezium is accessed; if `UPLO = 'L'`, only the lower trapezium is accessed.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,M)$.

#### B `[out]`

_COMPLEX\*16 array, dimension (LDB,N)_

On exit, $B = A$ in the locations specified by `UPLO`.

#### LDB `[in]`

_INTEGER_

The leading dimension of the array B. $\mathrm{LDB} \ge \max (1,M)$.
