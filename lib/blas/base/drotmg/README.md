# drotmg

> Constructs a modified Givens plane rotation.

<section class="usage">

## Usage

```javascript
var drotmg = require( '@stdlib/blas/base/drotmg' );
```

#### drotmg( D, x1, dy1, param )

Constructs a modified Givens plane rotation.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var drotmg = require( '@stdlib/blas/base/drotmg' );

var D = new Float64Array( [ 1.0, 1.0 ] );
var x1 = new Float64Array( [ 3.0 ] );
var param = new Float64Array( 5 );

drotmg.ndarray( D, 1, 0, x1, 1, 0, 4.0, param, 1, 0 );
```

The function has the following parameters:

-   **D**: input array `D`.
-   **x1**: `x1`.
-   **dy1**: `dy1`.
-   **param**: `param`.

#### drotmg.ndarray( dd1, dd2, dx1, dy1, param, strideParam, offsetParam )

Constructs a modified Givens plane rotation, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var drotmg = require( '@stdlib/blas/base/drotmg' );

var D = new Float64Array( [ 1.0, 1.0 ] );
var x1 = new Float64Array( [ 3.0 ] );
var param = new Float64Array( 5 );

drotmg.ndarray( D, 1, 0, x1, 1, 0, 4.0, param, 1, 0 );
```

The function has the following additional parameters:

-   **strideD**: stride length for `D`.
-   **offsetD**: starting index for `D`.
-   **strideX1**: stride of dimension 1 of `X`.
-   **offsetX1**: starting index for `X1`.
-   **strideParam**: stride length for `Param`.
-   **offsetParam**: starting index for `Param`.

## Reference notes

The mathematical description from the reference BLAS 3.12.0 source of `DROTMG`. Indices are the 1-based Fortran indices of the source.

### Purpose

CONSTRUCT THE MODIFIED GIVENS TRANSFORMATION MATRIX H WHICH ZEROS THE SECOND COMPONENT OF THE 2-VECTOR $(\mathrm{DSQRT}(\mathrm{DD1}) \, \mathrm{DX1},\mathrm{DSQRT}(\mathrm{DD2}) \, > \mathrm{DY2})^T$. WITH `DPARAM(1)=DFLAG`, H HAS ONE OF THE FOLLOWING FORMS..

$\mathrm{DFLAG}=-1$.D0 $\mathrm{DFLAG}=0$.D0 $\mathrm{DFLAG}=1$.D0 $\mathrm{DFLAG}=-2$.D0

$$
H= \begin{pmatrix} \mathrm{DH11} & \mathrm{DH12} \\  &  \\ \mathrm{DH21} & \mathrm{DH22} \end{pmatrix} , \begin{pmatrix} 1.D_{0} & \mathrm{DH12} \\  &  \\ \mathrm{DH21} & 1.D_{0} \end{pmatrix} , \begin{pmatrix} \mathrm{DH11} & 1.D_{0} \\  &  \\ -1.D_{0} & \mathrm{DH22} \end{pmatrix} , \begin{pmatrix} 1.D_{0} & 0.D_{0} \\  &  \\ 0.D_{0} & 1.D_{0} \end{pmatrix}
$$

LOCATIONS 2-4 OF `DPARAM` CONTAIN DH11, DH21, DH12, AND DH22 RESPECTIVELY. (VALUES OF 1.D0, -1.D0, OR 0.D0 IMPLIED BY THE VALUE OF `DPARAM(1)` ARE NOT STORED IN `DPARAM`.)

THE VALUES OF GAMSQ AND RGAMSQ SET IN THE DATA STATEMENT MAY BE INEXACT. THIS IS OK AS THEY ARE ONLY USED FOR TESTING THE SIZE OF `DD1` AND `DD2`. ALL ACTUAL SCALING OF DATA IS DONE USING GAM.
