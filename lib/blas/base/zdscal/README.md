# zdscal

> Scale a complex double-precision vector by a double-precision constant.

<section class="usage">

## Usage

```javascript
var zdscal = require( '@stdlib/blas/base/zdscal' );
```

#### zdscal( N, da, zx, strideX )

Scale a complex double-precision vector by a double-precision constant.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var zdscal = require( '@stdlib/blas/base/zdscal' );

var zx = new Float64Array( [ 1.0, 2.0, 3.0, 4.0 ] );

zdscal.ndarray( 2, 2.0, zx, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **da**: `da`.
-   **zx**: `zx`.
-   **strideX**: stride length for `X`.

#### zdscal.ndarray( N, da, zx, strideX, offsetX )

Scale a complex double-precision vector by a double-precision constant, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var zdscal = require( '@stdlib/blas/base/zdscal' );

var zx = new Float64Array( [ 1.0, 2.0, 3.0, 4.0 ] );

zdscal.ndarray( 2, 2.0, zx, 1, 0 );
```

The function has the following additional parameters:

-   **offsetX**: starting index for `X`.

## Reference documentation

### Purpose

ZDSCAL scales a vector by a constant.

### Arguments

#### N `[in]`

_INTEGER_

number of elements in input vector(s)

#### DA `[in]`

_DOUBLE PRECISION_

On entry, `DA` specifies the scalar $\alpha$.

#### ZX `[in,out]`

_COMPLEX\*16 array, dimension ( 1 + ( N - 1 )\*abs( INCX ) )_

#### INCX `[in]`

_INTEGER_

storage spacing between elements of `ZX`
