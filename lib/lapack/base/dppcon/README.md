# dppcon

> @license Apache-2.0.

<section class="usage">

## Usage

```javascript
var dppcon = require( '@stdlib/lapack/base/dppcon' );
```

#### dppcon( uplo, N, AP, anorm, rcond, WORK, IWORK )

@license Apache-2.0.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Int32Array = require( '@stdlib/array/int32' );
var dppcon = require( '@stdlib/lapack/base/dppcon' );

var AP = new Float64Array( [ 4.0, 1.0, 3.0, 1.0, 1.0, 2.0 ] );
var rcond = new Float64Array( 1 );
var WORK = new Float64Array( 9 );
var IWORK = new Int32Array( 3 );

dppcon.ndarray( 'upper', 3, AP, 1, 0, 6.0, rcond, WORK, 1, 0, IWORK, 1, 0 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **anorm**: `anorm`.
-   **rcond**: `rcond`.
-   **WORK**: input array `WORK`.
-   **IWORK**: input array `IWORK`.

#### dppcon.ndarray( uplo, N, AP, strideAP, offsetAP, anorm, rcond, WORK, strideWORK, offsetWORK, IWORK, strideIWORK, offsetIWORK )

@license Apache-2.0, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Int32Array = require( '@stdlib/array/int32' );
var dppcon = require( '@stdlib/lapack/base/dppcon' );

var AP = new Float64Array( [ 4.0, 1.0, 3.0, 1.0, 1.0, 2.0 ] );
var rcond = new Float64Array( 1 );
var WORK = new Float64Array( 9 );
var IWORK = new Int32Array( 3 );

dppcon.ndarray( 'upper', 3, AP, 1, 0, 6.0, rcond, WORK, 1, 0, IWORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.
-   **strideIWORK**: stride length for `IWORK`.
-   **offsetIWORK**: starting index for `IWORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DPPCON`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DPPCON estimates the reciprocal of the condition number (in the 1-norm) of a real symmetric positive definite packed matrix using the Cholesky factorization $A = U^T \, U$ or $A = L \, L^T$ computed by DPPTRF.

An estimate is obtained for norm(inv(A)), and the reciprocal of the condition number is computed as $\mathrm{RCOND} = 1 / (\mathrm{ANORM} \, \operatorname{norm}(\operatorname{inv}(A)))$.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A is stored;
-   `= 'L'`: Lower triangle of A is stored.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### AP `[in]`

_DOUBLE PRECISION array, dimension (N\*(N+1)/2)_

The triangular factor U or L from the Cholesky factorization $A = U^T \, U$ or $A = L \, L^T$, packed columnwise in a linear array. The j-th column of U or L is stored in the array `AP` as follows: if `UPLO = 'U'`, `AP(i + (j-1)*j/2) = U(i,j)` for $1 \le i \le j$; if `UPLO = 'L'`, `AP(i + (j-1)*(2n-j)/2) = L(i,j)` for $j \le i \le n$.

#### ANORM `[in]`

_DOUBLE PRECISION_

The 1-norm (or infinity-norm) of the symmetric matrix A.

#### RCOND `[out]`

_DOUBLE PRECISION_

The reciprocal of the condition number of the matrix A, computed as $\mathrm{RCOND} = 1/(\mathrm{ANORM} \, \mathrm{AINVNM})$, where AINVNM is an estimate of the 1-norm of inv(A) computed in this routine.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (3\*N)_

#### IWORK `[out]`

_INTEGER array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
