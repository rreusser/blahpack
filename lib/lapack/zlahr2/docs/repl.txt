{{alias}}( order, N, K, nb, A, LDA, tau, strideTAU, T, LDT, Y, LDY )
    Reduces the first nb columns of a complex general rectangular matrix to
    upper trapezoidal form.

    Parameters
    ----------
    order: string
        storage layout (`'row-major'` or `'column-major'`).

    N: integer
        number of rows of `A`.

    K: integer
        offset for the reduction.

    nb: integer
        number of columns to reduce.

    A: Complex128Array
        input/output `N`-by-`(N-K+1)` matrix.

    LDA: integer
        leading dimension of `A`.

    tau: Complex128Array
        output array of scalar factors (length `nb`).

    strideTAU: integer
        stride length for `tau`.

    T: Complex128Array
        output `nb`-by-`nb` upper triangular matrix.

    LDT: integer
        leading dimension of `T`.

    Y: Complex128Array
        output `N`-by-`nb` matrix.

    LDY: integer
        leading dimension of `Y`.

    Returns
    -------
    undefined

    Examples
    --------
    > var N = 3;
    > var A = new {{alias:@stdlib/array/complex128}}( N * N );
    > var tau = new {{alias:@stdlib/array/complex128}}( 2 );
    > var T = new {{alias:@stdlib/array/complex128}}( 4 );
    > var Y = new {{alias:@stdlib/array/complex128}}( N * 2 );

    > {{alias}}( 'column-major', N, 1, 2, A, N, tau, 1, T, 2, Y, N );
