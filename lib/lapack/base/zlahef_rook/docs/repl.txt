
{{alias}}( order, uplo, N, nb, kb, A, LDA, IPIV, strideIPIV, offsetIPIV, W, LDW )
    Computes a partial factorization of a complex Hermitian indefinite
    matrix using the bounded Bunch-Kaufman ("rook") diagonal pivoting method
    (blocked algorithm, calling Level 3 BLAS).

    Parameters
    ----------
        order: string
            Row-major (C-style) or column-major (Fortran-style) order.

        uplo: string
            specifies the operation type.

        N: integer
            number of columns.

        nb: integer
            nb.

        kb: integer
            kb.

        A: Float64Array
            input matrix.

        LDA: integer
            leading dimension of `A`.

        IPIV: Int32Array
            input array.

        strideIPIV: integer
            stride length for `IPIV`.

        offsetIPIV: integer
            starting index for `IPIV`.

        W: Float64Array
            output matrix.

        LDW: integer
            leading dimension of `W`.

    Returns
    -------
    out: integer
        Result.
