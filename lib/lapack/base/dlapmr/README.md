# dlapmr

> Rearranges the rows of an M-by-N matrix X as specified by a permutation vector.

<section class="usage">

## Usage

```javascript
var dlapmr = require( '@stdlib/lapack/base/dlapmr' );
```

#### dlapmr( forwrd, M, N, X, LDX, k, strideK )

Rearranges the rows of an M-by-N matrix X as specified by a permutation vector.

```javascript
var dlapmr = require( '@stdlib/lapack/base/dlapmr' );

var N = 3;
var X = discreteUniform( N * N, -10, 10, opts );
var k = discreteUniform( N, -10, 10, opts );

dlapmr.ndarray( 1, N, N, X, N, 1, 0, k, 1, 0 );
```

The function has the following parameters:

-   **forwrd**: `forwrd`.
-   **M**: number of rows.
-   **N**: number of columns.
-   **X**: input array `X`.
-   **LDX**: leading dimension of `X`.
-   **k**: `k`.
-   **strideK**: stride length for `K`.

#### dlapmr.ndarray( forwrd, M, N, X, strideX1, strideX2, offsetX, k, strideK, offsetK )

Rearranges the rows of an M-by-N matrix X as specified by a permutation vector, using alternative indexing semantics.

```javascript
var dlapmr = require( '@stdlib/lapack/base/dlapmr' );

var N = 3;
var X = discreteUniform( N * N, -10, 10, opts );
var k = discreteUniform( N, -10, 10, opts );

dlapmr.ndarray( 1, N, N, X, N, 1, 0, k, 1, 0 );
```

The function has the following additional parameters:

-   **strideX1**: stride of dimension 1 of `X`.
-   **strideX2**: stride of dimension 2 of `X`.
-   **offsetX**: starting index for `X`.
-   **offsetK**: starting index for `K`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLAPMR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Rearranges rows of a matrix as specified by a permutation vector.

### Purpose

DLAPMR rearranges the rows of the M by N matrix X as specified by the permutation `K(1)`,`K(2)`,...,`K(M)` of the integers 1,...,M. If `FORWRD` = .TRUE., forward permutation:

`X(K(I),*)` is moved `X(I,*)` for $I = 1$,2,...,M.

If `FORWRD` = .FALSE., backward permutation:

`X(I,*)` is moved to `X(K(I),*)` for $I = 1$,2,...,M.

### Arguments

#### FORWRD `[in]`

_LOGICAL_

= .TRUE., forward permutation = .FALSE., backward permutation

#### M `[in]`

_INTEGER_

The number of rows of the matrix X. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix X. $N \ge 0$.

#### X `[in,out]`

_DOUBLE PRECISION array, dimension (LDX,N)_

On entry, the M by N matrix X. On exit, X contains the permuted matrix X.

#### LDX `[in]`

_INTEGER_

The leading dimension of the array X, $\mathrm{LDX} \ge \max (1,M)$.

#### K `[in,out]`

_INTEGER array, dimension (M)_

On entry, K contains the permutation vector. K is used as internal workspace, but reset to its original value on output.
