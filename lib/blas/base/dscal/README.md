# dscal

> @license Apache-2.0.

<section class="usage">

## Usage

```javascript
var dscal = require( '@stdlib/blas/base/dscal' );
```

#### dscal( N, da, x, strideX, offsetX )

@license Apache-2.0.

```javascript
var dscal = require( '@stdlib/blas/base/dscal' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );

dscal( N, 1.0, x, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **da**: `da`.
-   **x**: `x`.
-   **strideX**: stride length for `X`.
-   **offsetX**: starting index for `X`.

</section>

## Reference documentation

From the reference BLAS 3.12.0 source of `DSCAL`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DSCAL scales a vector by a constant. uses unrolled loops for increment equal to 1.

### Arguments

#### N `[in]`

_INTEGER_

number of elements in input vector(s)

#### DA `[in]`

_DOUBLE PRECISION_

On entry, `DA` specifies the scalar $\alpha$.

#### DX `[in,out]`

_DOUBLE PRECISION array, dimension ( 1 + ( N - 1 )\*abs( INCX ) )_

#### INCX `[in]`

_INTEGER_

storage spacing between elements of `DX`

### Further Details

jack dongarra, linpack, 3/11/78. modified 3/93 to return if incx .le. 0. modified 12/3/93, array(1) declarations changed to array(\*)
