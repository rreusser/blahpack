# zlascl

> Multiplies a general rectangular matrix by a real scalar defined as cto/cfrom.

<section class="usage">

## Usage

```javascript
var zlascl = require( '@stdlib/lapack/base/zlascl' );
```

#### zlascl( order, type, kl, ku, cfrom, cto, M, N, A, LDA )

Multiplies a general rectangular matrix by a real scalar defined as cto/cfrom.

```javascript
var zlascl = require( '@stdlib/lapack/base/zlascl' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

zlascl.ndarray( 1, N, N, 1, 1, N, N, A, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **type**: `type`.
-   **kl**: number of subdiagonals.
-   **ku**: number of superdiagonals.
-   **cfrom**: `cfrom`.
-   **cto**: `cto`.
-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### zlascl.ndarray( type, kl, ku, cfrom, cto, M, N, A, strideA1, strideA2, offsetA )

Multiplies a general rectangular matrix by a real scalar defined as cto/cfrom, using alternative indexing semantics.

```javascript
var zlascl = require( '@stdlib/lapack/base/zlascl' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

zlascl.ndarray( 1, N, N, 1, 1, N, N, A, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLASCL`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Multiplies a general rectangular matrix by a real scalar defined as cto/cfrom.

### Purpose

ZLASCL multiplies the M by N complex matrix A by the real scalar `CTO`/`CFROM`. This is done without over/underflow as long as the final result $\mathrm{CTO} \, A(I,J)/\mathrm{CFROM}$ does not over/underflow. `TYPE` specifies that A may be full, upper triangular, lower triangular, upper Hessenberg, or banded.

### Arguments

#### TYPE `[in]`

_CHARACTER\*1_

`TYPE` indices the storage type of the input matrix.

-   `= 'G'`: A is a full matrix.
-   `= 'L'`: A is a lower triangular matrix.
-   `= 'U'`: A is an upper triangular matrix.
-   `= 'H'`: A is an upper Hessenberg matrix.
-   `= 'B'`: A is a symmetric band matrix with lower bandwidth `KL` and upper bandwidth `KU` and with the only the lower half stored.
-   `= 'Q'`: A is a symmetric band matrix with lower bandwidth `KL` and upper bandwidth `KU` and with the only the upper half stored.
-   `= 'Z'`: A is a band matrix with lower bandwidth `KL` and upper bandwidth `KU`. See ZGBTRF for storage details.

#### KL `[in]`

_INTEGER_

The lower bandwidth of A. Referenced only if `TYPE = 'B'`, 'Q' or 'Z'.

#### KU `[in]`

_INTEGER_

The upper bandwidth of A. Referenced only if `TYPE = 'B'`, 'Q' or 'Z'.

#### CFROM `[in]`

_DOUBLE PRECISION_

#### CTO `[in]`

_DOUBLE PRECISION_

The matrix A is multiplied by `CTO`/`CFROM`. `A(I,J)` is computed without over/underflow if the final result $\mathrm{CTO} \, A(I,J)/\mathrm{CFROM}$ can be represented without over/underflow. `CFROM` must be nonzero.

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### A `[in,out]`

_COMPLEX\*16 array, dimension (LDA,N)_

The matrix to be multiplied by `CTO`/`CFROM`. See `TYPE` for the storage type.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. If `TYPE = 'G'`, 'L', 'U', 'H', $\mathrm{LDA} \ge \max (1,M)$;

$$
\mathrm{TYPE} = \text{'B'}, \mathrm{LDA} \ge \mathrm{KL}+1
$$

$$
\mathrm{TYPE} = \text{'Q'}, \mathrm{LDA} \ge \mathrm{KU}+1
$$

$$
\mathrm{TYPE} = \text{'Z'}, \mathrm{LDA} \ge 2 \, \mathrm{KL}+\mathrm{KU}+1
$$

#### INFO `[out]`

_INTEGER_

0 - successful exit \<0 - if `INFO = -i`, the i-th argument had an illegal value.
