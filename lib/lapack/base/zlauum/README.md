# zlauum

> Computes the product U·Uᴴ or Lᴴ·L, where U and L are upper or lower triangular matrices.

<section class="usage">

## Usage

```javascript
var zlauum = require( '@stdlib/lapack/base/zlauum' );
```

#### zlauum( order, uplo, N, A, LDA )

Computes the product U·Uᴴ or Lᴴ·L, where U and L are upper or lower triangular matrices.

```javascript
var zlauum = require( '@stdlib/lapack/base/zlauum' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

zlauum.ndarray( 'upper', N, A, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### zlauum.ndarray( uplo, N, A, strideA1, strideA2, offsetA )

Computes the product U·Uᴴ or Lᴴ·L, where U and L are upper or lower triangular matrices, using alternative indexing semantics.

```javascript
var zlauum = require( '@stdlib/lapack/base/zlauum' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

zlauum.ndarray( 'upper', N, A, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAUUM`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the product UUH or LHL, where U and L are upper or lower triangular matrices (blocked algorithm).

### Purpose

ZLAUUM computes the product $U \, U^H$ or $L^H \, L$, where the triangular factor U or L is stored in the upper or lower triangular part of the array A.

If `UPLO = 'U'` or 'u' then the upper triangle of the result is stored, overwriting the factor U in A. If `UPLO = 'L'` or 'l' then the lower triangle of the result is stored, overwriting the factor L in A.

This is the blocked form of the algorithm, calling Level 3 BLAS.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies whether the triangular factor stored in the array A is upper or lower triangular:

-   `= 'U'`: Upper triangular
-   `= 'L'`: Lower triangular

#### N `[in]`

_INTEGER_

The order of the triangular factor U or L. $N \ge 0$.

#### A `[in,out]`

_COMPLEX\*16 array, dimension (LDA,N)_

On entry, the triangular factor U or L. On exit, if `UPLO = 'U'`, the upper triangle of A is overwritten with the upper triangle of the product $U \, U^H$; if `UPLO = 'L'`, the lower triangle of A is overwritten with the lower triangle of the product $L^H \, L$.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -k`, the k-th argument had an illegal value
