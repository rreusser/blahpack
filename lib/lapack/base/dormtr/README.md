# dormtr

> Multiplies a general real matrix by the orthogonal matrix Q (or its transpose) from a symmetric tridiagonal reduction.

<section class="usage">

## Usage

```javascript
var dormtr = require( '@stdlib/lapack/base/dormtr' );
```

#### dormtr( side, uplo, trans, M, N, A, LDA, TAU, strideTAU, C, LDC, WORK, strideWORK, lwork )

Multiplies a general real matrix by the orthogonal matrix Q (or its transpose) from a symmetric tridiagonal reduction.

```javascript
var dormtr = require( '@stdlib/lapack/base/dormtr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormtr.ndarray( 'left', 'upper', 'no-transpose', N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0, N );
```

The function has the following parameters:

-   **side**: specifies the side of the operation.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array `TAU`.
-   **strideTAU**: stride length for `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.
-   **lwork**: `lwork`.

#### dormtr.ndarray( side, uplo, trans, M, N, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK, lwork )

Multiplies a general real matrix by the orthogonal matrix Q (or its transpose) from a symmetric tridiagonal reduction,, using alternative indexing semantics.

```javascript
var dormtr = require( '@stdlib/lapack/base/dormtr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormtr.ndarray( 'left', 'upper', 'no-transpose', N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0, N );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DORMTR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DORMTR overwrites the general real M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $Q \, C$ | $C \, Q$ |
| `TRANS = 'T'`: | $Q^T \, C$ | $C \, Q^T$ |

where Q is a real orthogonal matrix of order nq, with $\mathrm{nq} = m$ if `SIDE = 'L'` and $\mathrm{nq} = n$ if `SIDE = 'R'`. Q is defined as the product of nq-1 elementary reflectors, as returned by DSYTRD:

if `UPLO = 'U'`, $Q = H(\mathrm{nq}-1)$ . . . H(2) H(1);

if `UPLO = 'L'`, $Q = H(1)$ H(2) . . . H(nq-1).

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^T$ from the Left;
-   `= 'R'`: apply Q or $Q^T$ from the Right.

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A contains elementary reflectors from DSYTRD;
-   `= 'L'`: Lower triangle of A contains elementary reflectors from DSYTRD.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: No transpose, apply Q;
-   `= 'T'`: Transpose, apply $Q^T$.

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### A `[in]`

_DOUBLE PRECISION array, dimension (LDA,M) if SIDE = 'L'_

(`LDA`,N) if `SIDE = 'R'` The vectors which define the elementary reflectors, as returned by DSYTRD.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,M)$ if `SIDE = 'L'`; $\mathrm{LDA} \ge \max (1,N)$ if `SIDE = 'R'`.

#### TAU `[in]`

_DOUBLE PRECISION array, dimension (M-1) if SIDE = 'L'_

(N-1) if `SIDE = 'R'` `TAU(i)` must contain the scalar factor of the elementary reflector H(i), as returned by DSYTRD.

#### C `[in,out]`

_DOUBLE PRECISION array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by $Q \, C$ or $Q^T \, C$ or $C \, Q^T$ or $C \, Q$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (MAX(1,LWORK))_

On exit, if `INFO = 0`, `WORK(1)` returns the optimal `LWORK`.

#### LWORK `[in]`

_INTEGER_

The dimension of the array `WORK`. If `SIDE = 'L'`, $\mathrm{LWORK} \ge \max (1,N)$; if `SIDE = 'R'`, $\mathrm{LWORK} \ge \max (1,M)$. For optimum performance $\mathrm{LWORK} \ge N \, \mathrm{NB}$ if `SIDE = 'L'`, and $\mathrm{LWORK} \ge M \, \mathrm{NB}$ if `SIDE = 'R'`, where NB is the optimal blocksize.

If `LWORK = -1`, then a workspace query is assumed; the routine only calculates the optimal size of the `WORK` array, returns this value as the first entry of the `WORK` array, and no error message related to `LWORK` is issued by XERBLA.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
