# dtrti2

> Computes the inverse of a triangular matrix (unblocked algorithm).

<section class="usage">

## Usage

```javascript
var dtrti2 = require( '@stdlib/lapack/base/dtrti2' );
```

#### dtrti2( order, uplo, diag, N, A, LDA )

Computes the inverse of a triangular matrix (unblocked algorithm).

```javascript
var dtrti2 = require( '@stdlib/lapack/base/dtrti2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

dtrti2.ndarray( 'upper', 'non-unit', N, A, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **diag**: specifies whether the matrix is unit triangular.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### dtrti2.ndarray( uplo, diag, N, A, strideA1, strideA2, offsetA )

Computes the inverse of a triangular matrix (unblocked algorithm), using alternative indexing semantics.

```javascript
var dtrti2 = require( '@stdlib/lapack/base/dtrti2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

dtrti2.ndarray( 'upper', 'non-unit', N, A, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DTRTI2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the inverse of a triangular matrix (unblocked algorithm).

### Purpose

DTRTI2 computes the inverse of a real upper or lower triangular matrix.

This is the Level 2 BLAS version of the algorithm.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies whether the matrix A is upper or lower triangular.

-   `= 'U'`: Upper triangular
-   `= 'L'`: Lower triangular

#### DIAG `[in]`

_CHARACTER\*1_

Specifies whether or not the matrix A is unit triangular.

-   `= 'N'`: Non-unit triangular
-   `= 'U'`: Unit triangular

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### A `[in,out]`

_DOUBLE PRECISION array, dimension (LDA,N)_

On entry, the triangular matrix A. If `UPLO = 'U'`, the leading n by n upper triangular part of the array A contains the upper triangular matrix, and the strictly lower triangular part of A is not referenced. If `UPLO = 'L'`, the leading n by n lower triangular part of the array A contains the lower triangular matrix, and the strictly upper triangular part of A is not referenced. If `DIAG = 'U'`, the diagonal elements of A are also not referenced and are assumed to be 1.

On exit, the (triangular) inverse of the original matrix, in the same storage format.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -k`, the k-th argument had an illegal value
