# zgbtrf

> Computes an LU factorization of a complex m-by-n band matrix A using partial pivoting with row interchanges.

<section class="usage">

## Usage

```javascript
var zgbtrf = require( '@stdlib/lapack/base/zgbtrf' );
```

#### zgbtrf( order, M, N, kl, ku, AB, LDAB, IPIV, strideIPIV )

Computes an LU factorization of a complex m-by-n band matrix A using partial pivoting with row interchanges.

```javascript
var zgbtrf = require( '@stdlib/lapack/base/zgbtrf' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zgbtrf.ndarray( N, N, N, N, AB, N, 1, 0, IPIV, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **M**: number of rows.
-   **N**: number of columns.
-   **kl**: number of subdiagonals.
-   **ku**: number of superdiagonals.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.

#### zgbtrf.ndarray( M, N, kl, ku, AB, strideAB1, strideAB2, offsetAB, IPIV, strideIPIV, offsetIPIV )

Computes an LU factorization of a complex m-by-n band matrix A using partial pivoting with row interchanges, using alternative indexing semantics.

```javascript
var zgbtrf = require( '@stdlib/lapack/base/zgbtrf' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zgbtrf.ndarray( N, N, N, N, AB, N, 1, 0, IPIV, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **offsetIPIV**: starting index for `IPIV`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZGBTRF`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZGBTRF computes an LU factorization of a complex m-by-n band matrix A using partial pivoting with row interchanges.

This is the blocked version of the algorithm, calling Level 3 BLAS.

### Arguments

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### KL `[in]`

_INTEGER_

The number of subdiagonals within the band of A. $\mathrm{KL} \ge 0$.

#### KU `[in]`

_INTEGER_

The number of superdiagonals within the band of A. $\mathrm{KU} \ge 0$.

#### AB `[in,out]`

_COMPLEX\*16 array, dimension (LDAB,N)_

On entry, the matrix A in band storage, in rows `KL`+1 to $2 \, \mathrm{KL}+\mathrm{KU}+1$; rows 1 to `KL` of the array need not be set. The j-th column of A is stored in the j-th column of the array `AB` as follows: `AB(kl+ku+1+i-j,j) = A(i,j)` for $\max (1,j-\mathrm{ku}) \le i \le \min (m,j+\mathrm{kl})$

On exit, details of the factorization: U is stored as an upper triangular band matrix with `KL`+`KU` superdiagonals in rows 1 to `KL`+`KU`+1, and the multipliers used during the factorization are stored in rows `KL`+`KU`+2 to $2 \, \mathrm{KL}+\mathrm{KU}+1$. See below for further details.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge 2 \, \mathrm{KL}+\mathrm{KU}+1$.

#### IPIV `[out]`

_INTEGER array, dimension (min(M,N))_

The pivot indices; for $1 \le i \le \min (M,N)$, row i of the matrix was interchanged with row `IPIV(i)`.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `> 0`: if `INFO` = +i, U(i,i) is exactly zero. The factorization has been completed, but the factor U is exactly singular, and division by zero will occur if it is used to solve a system of equations.

### Further Details

The band storage scheme is illustrated by the following example, when $M = N = 6$, `KL = 2`, `KU = 1`:

```text
On entry:                       On exit:
```

```text
 *    *    *    +    +    +       *    *    *   u14  u25  u36
 *    *    +    +    +    +       *    *   u13  u24  u35  u46
 *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
a21  a32  a43  a54  a65   *      m21  m32  m43  m54  m65   *
a31  a42  a53  a64   *    *      m31  m42  m53  m64   *    *
```

Array elements marked \* are not used by the routine; elements marked + need not be set on entry, but are required by the routine to store elements of U because of fill-in resulting from the row interchanges.
