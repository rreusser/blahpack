# dlagv2

> Computes the Generalized Schur factorization of a real 2-by-2 matrix pencil (A,B) where B is upper triangular.

<section class="usage">

## Usage

```javascript
var dlagv2 = require( '@stdlib/lapack/base/dlagv2' );
```

#### dlagv2( A, LDA, B, LDB, alphar, alphai, beta )

Computes the Generalized Schur factorization of a real 2-by-2 matrix pencil (A,B) where B is upper triangular.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dlagv2 = require( '@stdlib/lapack/base/dlagv2' );

var A = new Float64Array( [ 4.0, 2.0, 1.0, 3.0 ] );
var B = new Float64Array( [ 2.0, 0.0, 1.0, 1.0 ] );
var alphar = new Float64Array( 2 );
var alphai = new Float64Array( 2 );
var beta = new Float64Array( 2 );

dlagv2.ndarray( A, 1, 2, 0, B, 1, 2, 0, alphar, 1, 0, alphai, 1, 0, beta, 1, 0 );
```

The function has the following parameters:

-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.
-   **alphar**: `alphar`.
-   **alphai**: `alphai`.
-   **beta**: scalar constant.

#### dlagv2.ndarray( A, strideA1, strideA2, offsetA, B, strideB1, strideB2, offsetB, alphar, strideALPHAR, offsetALPHAR, alphai, strideALPHAI, offsetALPHAI, beta, strideBETA, offsetBETA, csl, snl, csr, snr )

Computes the Generalized Schur factorization of a real 2-by-2 matrix pencil (A,B) where B is upper triangular, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dlagv2 = require( '@stdlib/lapack/base/dlagv2' );

var A = new Float64Array( [ 4.0, 2.0, 1.0, 3.0 ] );
var B = new Float64Array( [ 2.0, 0.0, 1.0, 1.0 ] );
var alphar = new Float64Array( 2 );
var alphai = new Float64Array( 2 );
var beta = new Float64Array( 2 );

dlagv2.ndarray( A, 1, 2, 0, B, 1, 2, 0, alphar, 1, 0, alphai, 1, 0, beta, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.
-   **strideALPHAR**: stride length for `ALPHAR`.
-   **offsetALPHAR**: starting index for `ALPHAR`.
-   **strideALPHAI**: stride length for `ALPHAI`.
-   **offsetALPHAI**: starting index for `ALPHAI`.
-   **strideBETA**: stride length for `BETA`.
-   **offsetBETA**: starting index for `BETA`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLAGV2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the Generalized Schur factorization of a real 2-by-2 matrix pencil (A,B) where B is upper triangular.

### Purpose

DLAGV2 computes the Generalized Schur factorization of a real 2-by-2 matrix pencil (A,B) where B is upper triangular. This routine computes orthogonal (rotation) matrices given by `CSL`, `SNL` and `CSR`, `SNR` such that

1) if the pencil (A,B) has two real eigenvalues (include 0/0 or 1/0

types), then

$$
\begin{bmatrix} a_{11} & a_{12} \\ 0 & a_{22} \end{bmatrix} := \begin{bmatrix} \mathrm{CSL} & \mathrm{SNL} \\ -\mathrm{SNL} & \mathrm{CSL} \end{bmatrix} \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} \mathrm{CSR} & -\mathrm{SNR} \\ \mathrm{SNR} & \mathrm{CSR} \end{bmatrix}
$$

$$
\begin{bmatrix} b_{11} & b_{12} \\ 0 & b_{22} \end{bmatrix} := \begin{bmatrix} \mathrm{CSL} & \mathrm{SNL} \\ -\mathrm{SNL} & \mathrm{CSL} \end{bmatrix} \begin{bmatrix} b_{11} & b_{12} \\ 0 & b_{22} \end{bmatrix} \begin{bmatrix} \mathrm{CSR} & -\mathrm{SNR} \\ \mathrm{SNR} & \mathrm{CSR} \end{bmatrix}
$$

2) if the pencil (A,B) has a pair of complex conjugate eigenvalues,

then

$$
\begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} := \begin{bmatrix} \mathrm{CSL} & \mathrm{SNL} \\ -\mathrm{SNL} & \mathrm{CSL} \end{bmatrix} \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} \mathrm{CSR} & -\mathrm{SNR} \\ \mathrm{SNR} & \mathrm{CSR} \end{bmatrix}
$$

$$
\begin{bmatrix} b_{11} & 0 \\ 0 & b_{22} \end{bmatrix} := \begin{bmatrix} \mathrm{CSL} & \mathrm{SNL} \\ -\mathrm{SNL} & \mathrm{CSL} \end{bmatrix} \begin{bmatrix} b_{11} & b_{12} \\ 0 & b_{22} \end{bmatrix} \begin{bmatrix} \mathrm{CSR} & -\mathrm{SNR} \\ \mathrm{SNR} & \mathrm{CSR} \end{bmatrix}
$$

$$
\quad\text{where}\quad b_{11} \ge b_{22} > 0
$$

### Arguments

#### A `[in,out]`

_DOUBLE PRECISION array, dimension (LDA, 2)_

On entry, the 2 x 2 matrix A. On exit, A is overwritten by the \`\`A-part'' of the generalized Schur form.

#### LDA `[in]`

_INTEGER_

THe leading dimension of the array A. $\mathrm{LDA} \ge 2$.

#### B `[in,out]`

_DOUBLE PRECISION array, dimension (LDB, 2)_

On entry, the upper triangular 2 x 2 matrix B. On exit, B is overwritten by the \`\`B-part'' of the generalized Schur form.

#### LDB `[in]`

_INTEGER_

THe leading dimension of the array B. $\mathrm{LDB} \ge 2$.

#### ALPHAR `[out]`

_DOUBLE PRECISION array, dimension (2)_

#### ALPHAI `[out]`

_DOUBLE PRECISION array, dimension (2)_

#### BETA `[out]`

_DOUBLE PRECISION array, dimension (2)_

(`ALPHAR(k)`+i\*`ALPHAI(k)`)/`BETA(k)` are the eigenvalues of the pencil (A,B), $k=1$,2, $i = \sqrt{-1}$. Note that `BETA(k)` may be zero.

#### CSL `[out]`

_DOUBLE PRECISION_

The cosine of the left rotation matrix.

#### SNL `[out]`

_DOUBLE PRECISION_

The sine of the left rotation matrix.

#### CSR `[out]`

_DOUBLE PRECISION_

The cosine of the right rotation matrix.

#### SNR `[out]`

_DOUBLE PRECISION_

The sine of the right rotation matrix.
