# zrotg

> Computes the parameters for a Givens rotation.

<section class="usage">

## Usage

```javascript
var zrotg = require( '@stdlib/blas/base/zrotg' );
```

#### zrotg( re, im )

Computes the parameters for a Givens rotation.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var zrotg = require( '@stdlib/blas/base/zrotg' );

var out = new Float64Array( 8 );

zrotg.ndarray( 3.0, 0.0, 4.0, 0.0, out, 1, 0 );
```

The function has the following parameters:

-   **re**: `re`.
-   **im**: `im`.

#### zrotg.ndarray( a, offsetA, b, offsetB, c, offsetC, s, offsetS )

Computes the parameters for a Givens rotation, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var zrotg = require( '@stdlib/blas/base/zrotg' );

var out = new Float64Array( 8 );

zrotg.ndarray( 3.0, 0.0, 4.0, 0.0, out, 1, 0 );
```

The function has the following additional parameters:

-   **a**: `a`.
-   **offsetA**: starting index for `A`.
-   **b**: `b`.
-   **offsetB**: starting index for `B`.
-   **c**: `c`.
-   **offsetC**: starting index for `C`.
-   **s**: `s`.
-   **offsetS**: starting index for `S`.

## Reference documentation

From the reference BLAS 3.12.0 source of `ZROTG`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Generates a Givens rotation with real cosine and complex sine.

### Purpose

ZROTG constructs a plane rotation

$$
\begin{bmatrix} c & s \\ -\overline{s} & c \end{bmatrix} \begin{bmatrix} a \\ b \end{bmatrix} = \begin{bmatrix} r \\ 0 \end{bmatrix}
$$

where c is real, s is complex, and $c^2 + \overline{s} \, s = 1$.

The computation uses the formulas

```text
   |x| = sqrt( Re(x)**2 + Im(x)**2 )
   sgn(x) = x / |x|  if x /= 0
          = 1        if x  = 0
   c = |a| / sqrt(|a|**2 + |b|**2)
   s = sgn(a) * conjg(b) / sqrt(|a|**2 + |b|**2)
   r = sgn(a)*sqrt(|a|**2 + |b|**2)
When a and b are real and r /= 0, the formulas simplify to
   c = a / r
   s = b / r
```

the same as in DROTG when \|a\| \> \|b\|. When \|b\| \>= \|a\|, the sign of c and s will be different from those computed by DROTG if the signs of a and b are not the same.

### Arguments

#### A `[in,out]`

_DOUBLE COMPLEX_

On entry, the scalar a. On exit, the scalar r.

#### B `[in]`

_DOUBLE COMPLEX_

The scalar b.

#### C `[out]`

_DOUBLE PRECISION_

The scalar c.

#### S `[out]`

_DOUBLE COMPLEX_

The scalar s.

### Further Details

Based on the algorithm from

Anderson E. (2017) Algorithm 978: Safe Scaling in the Level 1 BLAS ACM Trans Math Softw 44:1--28 https://doi.org/10.1145/3061665
