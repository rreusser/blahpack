    IHI-ILO elementary reflectors of order N, as returned by DGEHRD: Q =
    H(ilo) H(ilo+1).

    Parameters
    ----------
    N: integer
        number of columns.

    ilo: integer
        `ilo`.

    ihi: integer
        `ihi`.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    TAU: Float64Array
        `TAU`.

    strideTAU: integer
        stride length for `TAU`.

    WORK: Float64Array
        `WORK`.

    strideWORK: integer
        stride length for `WORK`.
