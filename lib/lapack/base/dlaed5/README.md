# dlaed5

> Solves the 2-by-2 secular equation.

<section class="usage">

## Usage

```javascript
var dlaed5 = require( '@stdlib/lapack/base/dlaed5' );
```

#### dlaed5( i, D, Z, DELTA, rho, dlam )

Solves the 2-by-2 secular equation.

```javascript
var dlaed5 = require( '@stdlib/lapack/base/dlaed5' );

var D = discreteUniform( N, -10, 10, opts );
var Z = discreteUniform( N, -10, 10, opts );
var DELTA = discreteUniform( N, -10, 10, opts );

dlaed5.ndarray( 1, D, 1, 0, Z, 1, 0, DELTA, 1, 0, 1.0, 1 );
```

The function has the following parameters:

-   **i**: `i`.
-   **D**: input array `D`.
-   **Z**: input array `Z`.
-   **DELTA**: input array `DELTA`.
-   **rho**: `rho`.
-   **dlam**: `dlam`.

#### dlaed5.ndarray( i, D, strideD, offsetD, Z, strideZ, offsetZ, DELTA, strideDELTA, offsetDELTA, rho, dlam )

Solves the 2-by-2 secular equation, using alternative indexing semantics.

```javascript
var dlaed5 = require( '@stdlib/lapack/base/dlaed5' );

var D = discreteUniform( N, -10, 10, opts );
var Z = discreteUniform( N, -10, 10, opts );
var DELTA = discreteUniform( N, -10, 10, opts );

dlaed5.ndarray( 1, D, 1, 0, Z, 1, 0, DELTA, 1, 0, 1.0, 1 );
```

The function has the following additional parameters:

-   **strideD**: stride length for `D`.
-   **offsetD**: starting index for `D`.
-   **strideZ**: stride length for `Z`.
-   **offsetZ**: starting index for `Z`.
-   **strideDELTA**: stride length for `DELTA`.
-   **offsetDELTA**: starting index for `DELTA`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLAED5`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Used by DSTEDC. Solves the 2-by-2 secular equation.

### Purpose

This subroutine computes the I-th eigenvalue of a symmetric rank-one modification of a 2-by-2 diagonal matrix

$\operatorname{diag}( D ) + \mathrm{RHO} \, Z$ \* transpose(Z) .

The diagonal elements in the array D are assumed to satisfy

$$
D(i) < D(j) \quad\text{for}\quad i < j
$$

We also assume $\mathrm{RHO} > 0$ and that the Euclidean norm of the vector Z is one.

### Arguments

#### I `[in]`

_INTEGER_

The index of the eigenvalue to be computed. $I = 1$ or $I = 2$.

#### D `[in]`

_DOUBLE PRECISION array, dimension (2)_

The original eigenvalues. We assume $D(1) < D(2)$.

#### Z `[in]`

_DOUBLE PRECISION array, dimension (2)_

The components of the updating vector.

#### DELTA `[out]`

_DOUBLE PRECISION array, dimension (2)_

The vector `DELTA` contains the information necessary to construct the eigenvectors.

#### RHO `[in]`

_DOUBLE PRECISION_

The scalar in the symmetric updating formula.

#### DLAM `[out]`

_DOUBLE PRECISION_

The computed lambda\_I, the I-th updated eigenvalue.
