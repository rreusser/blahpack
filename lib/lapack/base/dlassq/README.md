# dlassq

> Returns updated scale and sum-of-squares in scaled form.

<section class="usage">

## Usage

```javascript
var dlassq = require( '@stdlib/lapack/base/dlassq' );
```

#### dlassq( N, x, stride, scale, sumsq )

Returns updated scale and sum-of-squares in scaled form.

```javascript
var dlassq = require( '@stdlib/lapack/base/dlassq' );

dlassq.ndarray( N, 1, 1, 0, 1.0, 1 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **x**: `x`.
-   **stride**: `stride`.
-   **scale**: `scale`.
-   **sumsq**: `sumsq`.

#### dlassq.ndarray( N, x, stride, offset, scale, sumsq )

Returns updated scale and sum-of-squares in scaled form, using alternative indexing semantics.

```javascript
var dlassq = require( '@stdlib/lapack/base/dlassq' );

dlassq.ndarray( N, 1, 1, 0, 1.0, 1 );
```

The function has the following additional parameters:

-   **offset**: `offset`.

</section>

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DLASSQ`. Indices are the 1-based Fortran indices of the source.

### Purpose

DLASSQ returns the values scale\_out and sumsq\_out such that

(scale\_out\*\*2)\*sumsq\_out = $x( 1 )^2$ +...+ $x( n )^2$ + (scale\*\*2)\*sumsq,

where $x( i ) = X( 1 + ( i - 1 ) \, \mathrm{INCX} )$. The value of sumsq is assumed to be non-negative.

scale and sumsq must be supplied in `SCALE` and `SUMSQ` and scale\_out and sumsq\_out are overwritten on `SCALE` and `SUMSQ` respectively.

### Further Details

Anderson E. (2017) Algorithm 978: Safe Scaling in the Level 1 BLAS ACM Trans Math Softw 44:1--28 https://doi.org/10.1145/3061665

Blue, James L. (1978) A Portable Fortran Program to Find the Euclidean Norm of a Vector ACM Trans Math Softw 4:15--23 https://doi.org/10.1145/355769.355771
