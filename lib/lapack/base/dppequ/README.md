# dppequ

> Computes row and column scalings intended to equilibrate a symmetric positive definite matrix in packed storage and reduce its condition number.

<section class="usage">

## Usage

```javascript
var dppequ = require( '@stdlib/lapack/base/dppequ' );
```

#### dppequ( uplo, N, AP, s )

Computes row and column scalings intended to equilibrate a symmetric positive definite matrix in packed storage and reduce its condition number.

```javascript
var dppequ = require( '@stdlib/lapack/base/dppequ' );

var N = 3;
var AP = discreteUniform( N, -10, 10, opts );
var s = discreteUniform( N, -10, 10, opts );

dppequ.ndarray( 'upper', N, AP, 1, 0, s, 1, 0 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **s**: `s`.

#### dppequ.ndarray( uplo, N, AP, strideAP, offsetAP, s, strideS, offsetS, scond, amax )

Computes row and column scalings intended to equilibrate a symmetric positive definite matrix in packed storage and reduce its condition number, using alternative indexing semantics.

```javascript
var dppequ = require( '@stdlib/lapack/base/dppequ' );

var N = 3;
var AP = discreteUniform( N, -10, 10, opts );
var s = discreteUniform( N, -10, 10, opts );

dppequ.ndarray( 'upper', N, AP, 1, 0, s, 1, 0 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideS**: stride length for `S`.
-   **offsetS**: starting index for `S`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DPPEQU`. Indices are the 1-based Fortran indices of the source.

### Purpose

DPPEQU computes row and column scalings intended to equilibrate a symmetric positive definite matrix A in packed storage and reduce its condition number (with respect to the two-norm). S contains the scale factors, $S(i)=1/\sqrt{A(i,i)}$, chosen so that the scaled matrix B with elements $B(i,j)=S(i) \, A(i,j) \, S(j)$ has ones on the diagonal. This choice of S puts the condition number of B within a factor N of the smallest possible condition number over all possible diagonal scalings.
