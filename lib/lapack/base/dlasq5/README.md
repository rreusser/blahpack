# dlasq5

> Computes one dqds transform in ping-pong form with a shift.

<section class="usage">

## Usage

```javascript
var dlasq5 = require( '@stdlib/lapack/base/dlasq5' );
```

#### dlasq5( i0, n0, z, stride, pp, tau, sigma, dmin, dmin1, dmin2, dn, dnm1, dnm2, ieee, eps )

Computes one dqds transform in ping-pong form with a shift.

```javascript
var dlasq5 = require( '@stdlib/lapack/base/dlasq5' );

dlasq5.ndarray( 1, 1, 1, 1, 0, 1, 1.0, 1.0, 1, 1 );
```

The function has the following parameters:

-   **i0**: `i0`.
-   **n0**: `n0`.
-   **z**: `z`.
-   **stride**: `stride`.
-   **pp**: `pp`.
-   **tau**: `tau`.
-   **sigma**: `sigma`.
-   **ieee**: `ieee`.
-   **eps**: `eps`.

#### dlasq5.ndarray( i0, n0, z, stride, offset, pp, tau, sigma, dmin, dmin1, dmin2, dn, dnm1, dnm2, ieee, eps )

Computes one dqds transform in ping-pong form with a shift, using alternative indexing semantics.

```javascript
var dlasq5 = require( '@stdlib/lapack/base/dlasq5' );

dlasq5.ndarray( 1, 1, 1, 1, 0, 1, 1.0, 1.0, 1, 1 );
```

The function has the following additional parameters:

-   **offset**: `offset`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLASQ5`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes one dqds transform in ping-pong form. Used by sbdsqr and sstegr.

### Purpose

DLASQ5 computes one dqds transform in ping-pong form, one version for `IEEE` machines another for non `IEEE` machines.

### Arguments

#### I0 `[in]`

_INTEGER_

First index.

#### N0 `[in]`

_INTEGER_

Last index.

#### Z `[in]`

_DOUBLE PRECISION array, dimension ( 4\*N )_

Z holds the qd array. EMIN is stored in `Z(4*N0)` to avoid an extra argument.

#### PP `[in]`

_INTEGER_

`PP=0` for ping, `PP=1` for pong.

#### TAU `[in]`

_DOUBLE PRECISION_

This is the shift.

#### SIGMA `[in]`

_DOUBLE PRECISION_

This is the accumulated shift up to this step.

#### DMIN `[out]`

_DOUBLE PRECISION_

Minimum value of d.

#### DMIN1 `[out]`

_DOUBLE PRECISION_

Minimum value of d, excluding D( `N0` ).

#### DMIN2 `[out]`

_DOUBLE PRECISION_

Minimum value of d, excluding D( `N0` ) and D( `N0`-1 ).

#### DN `[out]`

_DOUBLE PRECISION_

d(`N0`), the last value of d.

#### DNM1 `[out]`

_DOUBLE PRECISION_

d(`N0`-1).

#### DNM2 `[out]`

_DOUBLE PRECISION_

d(`N0`-2).

#### IEEE `[in]`

_LOGICAL_

Flag for `IEEE` or non `IEEE` arithmetic.

#### EPS `[in]`

_DOUBLE PRECISION_

This is the value of $\epsilon$ used.
