# zgecon

> CABS1: |re(z)| + |im(z)|.

<section class="usage">

## Usage

```javascript
var zgecon = require( '@stdlib/lapack/base/zgecon' );
```

#### zgecon( v, idx )

CABS1: |re(z)| + |im(z)|.

```javascript
var zgecon = require( '@stdlib/lapack/base/zgecon' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );
var RWORK = discreteUniform( N, -10, 10, opts );

zgecon.ndarray( '1', N, A, N, 1, 0, 1.0, 1.0, WORK, 1, 0, RWORK, 1, 0 );
```

The function has the following parameters:

-   **v**: `v`.
-   **idx**: `idx`.

#### zgecon.ndarray( norm, N, A, strideA1, strideA2, offsetA, anorm, rcond, WORK, strideWORK, offsetWORK, RWORK, strideRWORK, offsetRWORK )

CABS1: |re(z)| + |im(z)|, using alternative indexing semantics.

```javascript
var zgecon = require( '@stdlib/lapack/base/zgecon' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

var RWORK = discreteUniform( N, -10, 10, opts );

zgecon.ndarray( '1', N, A, N, 1, 0, 1.0, 1.0, WORK, 1, 0, RWORK, 1, 0 );
```

The function has the following additional parameters:

-   **norm**: `norm`.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **anorm**: `anorm`.
-   **rcond**: `rcond`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.
-   **RWORK**: input array `RWORK`.
-   **strideRWORK**: stride length for `RWORK`.
-   **offsetRWORK**: starting index for `RWORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZGECON`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZGECON estimates the reciprocal of the condition number of a general complex matrix A, in either the 1-norm or the infinity-norm, using the LU factorization computed by ZGETRF.

An estimate is obtained for norm(inv(A)), and the reciprocal of the condition number is computed as

$$
\mathrm{RCOND} = 1 / ( \operatorname{norm}(A) \, \operatorname{norm}(\operatorname{inv}(A)) )
$$

### Arguments

#### NORM `[in]`

_CHARACTER\*1_

Specifies whether the 1-norm condition number or the infinity-norm condition number is required: = '1' or 'O': 1-norm;

-   `= 'I'`: Infinity-norm.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### A `[in]`

_COMPLEX\*16 array, dimension (LDA,N)_

The factors L and U from the factorization $A = P \, L \, U$ as computed by ZGETRF.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### ANORM `[in]`

_DOUBLE PRECISION_

If `NORM = '1'` or 'O', the 1-norm of the original matrix A. If `NORM = 'I'`, the infinity-norm of the original matrix A.

#### RCOND `[out]`

_DOUBLE PRECISION_

The reciprocal of the condition number of the matrix A, computed as $\mathrm{RCOND} = 1/(\operatorname{norm}(A) \, \operatorname{norm}(\operatorname{inv}(A)))$.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (2\*N)_

#### RWORK `[out]`

_DOUBLE PRECISION array, dimension (2\*N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value. NaNs are illegal values for `ANORM`, and they propagate to the output parameter `RCOND`. Infinity is illegal for `ANORM`, and it propagates to the output parameter `RCOND` as 0.
-   `= 1`: if `RCOND` = NaN, or `RCOND` = Inf, or the computed norm of the inverse of A is 0. In the latter, `RCOND = 0` is returned.
