# zhetri_rook

> Compute inverse of complex Hermitian matrix using factorization from zhetrf_rook

<section class="usage">

## Usage

```javascript
var zhetri_rook = require( '@stdlib/lapack/base/zhetri_rook' );
```

#### zhetri_rook( order, uplo, N, A, LDA, IPIV, strideIPIV, offsetIPIV, WORK, strideWORK )

Compute inverse of complex Hermitian matrix using factorization from zhetrf_rook

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var Int32Array = require( '@stdlib/array/int32' );

var A = new Complex128Array( [ 4.0, 0.0 ] );
var IPIV = new Int32Array( [ 0 ] );
var WORK = new Complex128Array( 1 );

zhetriRook( 'column-major', 'upper', 1, A, 1, IPIV, 1, WORK );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies the operation type.
-   **N**: number of columns.
-   **A**: input matrix.
-   **LDA**: leading dimension of `A`.
-   **IPIV**: input array.
-   **strideIPIV**: stride length for `IPIV`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **WORK**: output array.
-   **strideWORK**: stride length for `WORK`.

#### zhetri_rook.ndarray( uplo, N, A, strideA1, strideA2, offsetA, IPIV, strideIPIV, offsetIPIV, WORK, strideWORK, offsetWORK )

Compute inverse of complex Hermitian matrix using factorization from zhetrf_rook, using alternative indexing semantics.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var Int32Array = require( '@stdlib/array/int32' );

var A = new Complex128Array( [ 4.0, 0.0 ] );
var IPIV = new Int32Array( [ 0 ] );
var WORK = new Complex128Array( 1 );

zhetriRook.ndarray( 'upper', 1, A, 1, 1, 0, IPIV, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **uplo**: specifies the operation type.
-   **N**: number of columns.
-   **A**: input matrix.
-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **IPIV**: input array.
-   **strideIPIV**: stride length for `IPIV`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **WORK**: output array.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

<section class="notes">

## Notes

-   The matrix `A` must be the output of `zhetrf_rook` (or `zhetf2_rook`): it stores the block diagonal `D` and the multipliers used to obtain the factor `U` (upper) or `L` (lower).
-   On exit (when `info === 0`), `A` is overwritten with the upper (or lower) triangular part of `inv(A)`. The opposite triangle is not referenced. Diagonal elements of the Hermitian inverse are real (imaginary part is forced to zero).
-   `IPIV` uses the 0-based pivot convention from `zhetrf_rook`: a non-negative entry indicates a 1x1 pivot; a negative entry encodes a 2x2 pivot via bitwise NOT of the 0-based row/column that was interchanged. Both entries of a 2x2 block are stored independently.
-   `WORK` is an internal workspace of length at least `N`.

</section>

## Examples

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var Int32Array = require( '@stdlib/array/int32' );
var zhetriRook = require( '@stdlib/lapack/base/zhetri-rook' );

// 1x1 Hermitian factorization (already factored): A = [4 + 0i].
var A = new Complex128Array( [ 4.0, 0.0 ] );
var IPIV = new Int32Array( [ 0 ] );
var WORK = new Complex128Array( 1 );

var info = zhetriRook( 'column-major', 'upper', 1, A, 1, IPIV, 1, WORK );
console.log( info );
console.log( A );
```

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZHETRI_ROOK`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the inverse of HE matrix using the factorization obtained with the bounded Bunch-Kaufman ("rook") diagonal pivoting method.

### Purpose

ZHETRI\_ROOK computes the inverse of a complex Hermitian indefinite matrix A using the factorization $A = U \, D \, U^H$ or $A = L \, D \, L^H$ computed by ZHETRF\_ROOK.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies whether the details of the factorization are stored as an upper or lower triangular matrix.

-   `= 'U'`: Upper triangular, form is $A = U \, D \, U^H$;
-   `= 'L'`: Lower triangular, form is $A = L \, D \, L^H$.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### A `[in,out]`

_COMPLEX\*16 array, dimension (LDA,N)_

On entry, the block diagonal matrix D and the multipliers used to obtain the factor U or L as computed by ZHETRF\_ROOK.

On exit, if `INFO = 0`, the (Hermitian) inverse of the original matrix. If `UPLO = 'U'`, the upper triangular part of the inverse is formed and the part of A below the diagonal is not referenced; if `UPLO = 'L'` the lower triangular part of the inverse is formed and the part of A above the diagonal is not referenced.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### IPIV `[in]`

_INTEGER array, dimension (N)_

Details of the interchanges and the block structure of D as determined by ZHETRF\_ROOK.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `> 0`: if `INFO = i`, $D(i,i) = 0$; the matrix is singular and its inverse could not be computed.
