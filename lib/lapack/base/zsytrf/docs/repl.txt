{{alias}}( order, uplo, N, A, LDA, IPIV, strideIPIV, WORK )
    Computes the factorization of a complex symmetric matrix using Bunch-Kaufman
    diagonal pivoting.

    Parameters
    ----------
    order: string
        Storage layout (`'row-major'` or `'column-major'`).

    uplo: string
        Specifies whether the upper or lower triangle of `A` is stored (`'upper'` or `'lower'`).

    N: integer
        Order of the matrix `A`.

    A: Complex128Array
        Input/output matrix `A`; overwritten with the block diagonal factor and multipliers.

    LDA: integer
        Leading dimension of `A`.

    IPIV: Int32Array
        Output pivot indices.

    strideIPIV: integer
        Stride length for `IPIV`.

    WORK: Complex128Array|null
        Workspace (length >= 1; `N*32` enables the blocked algorithm); if `null`, a workspace is allocated internally.

    Returns
    -------
    info: integer
        Status code.
