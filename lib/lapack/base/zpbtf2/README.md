# zpbtf2

> Computes the Cholesky factorization of a symmetric/Hermitian positive definite band matrix (unblocked algorithm).

<section class="usage">

## Usage

```javascript
var zpbtf2 = require( '@stdlib/lapack/base/zpbtf2' );
```

#### zpbtf2( order, uplo, N, kd, AB, LDAB )

Computes the Cholesky factorization of a symmetric/Hermitian positive definite band matrix (unblocked algorithm).

```javascript
var zpbtf2 = require( '@stdlib/lapack/base/zpbtf2' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );

zpbtf2.ndarray( 'upper', N, 1, AB, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **kd**: `kd`.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.

#### zpbtf2.ndarray( uplo, N, kd, AB, strideAB1, strideAB2, offsetAB )

Computes the Cholesky factorization of a symmetric/Hermitian positive definite band matrix (unblocked algorithm), using alternative indexing semantics.

```javascript
var zpbtf2 = require( '@stdlib/lapack/base/zpbtf2' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );

zpbtf2.ndarray( 'upper', N, 1, AB, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZPBTF2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes the Cholesky factorization of a symmetric/Hermitian positive definite band matrix (unblocked algorithm).

### Purpose

ZPBTF2 computes the Cholesky factorization of a complex Hermitian positive definite band matrix A.

The factorization has the form

$$
A = U^H \, U , \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$$
A = L \, L^H, \quad\text{if}\quad \mathrm{UPLO} = \text{'L'}
$$

where U is an upper triangular matrix, $U^H$ is the conjugate transpose of U, and L is lower triangular.

This is the unblocked version of the algorithm, calling Level 2 BLAS.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies whether the upper or lower triangular part of the Hermitian matrix A is stored:

-   `= 'U'`: Upper triangular
-   `= 'L'`: Lower triangular

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### KD `[in]`

_INTEGER_

The number of super-diagonals of the matrix A if `UPLO = 'U'`, or the number of sub-diagonals if `UPLO = 'L'`. $\mathrm{KD} \ge 0$.

#### AB `[in,out]`

_COMPLEX\*16 array, dimension (LDAB,N)_

On entry, the upper or lower triangle of the Hermitian band matrix A, stored in the first `KD`+1 rows of the array. The j-th column of A is stored in the j-th column of the array `AB` as follows: if `UPLO = 'U'`, `AB(kd+1+i-j,j) = A(i,j)` for $\max (1,j-\mathrm{kd}) \le i \le j$; if `UPLO = 'L'`, `AB(1+i-j,j) = A(i,j)` for $j \le i \le \min (n,j+\mathrm{kd})$.

On exit, if `INFO = 0`, the triangular factor U or L from the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$ of the band matrix A, in the same storage format as A.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge \mathrm{KD}+1$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -k`, the k-th argument had an illegal value
-   `> 0`: if `INFO = k`, the leading principal minor of order k is not positive, and the factorization could not be completed.

### Further Details

The band storage scheme is illustrated by the following example, when $N = 6$, `KD = 2`, and `UPLO = 'U'`:

```text
On entry:                       On exit:
```

```text
 *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
 *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
```

Similarly, if `UPLO = 'L'` the format of A is as follows:

```text
On entry:                       On exit:
```

```text
a11  a22  a33  a44  a55  a66     l11  l22  l33  l44  l55  l66
a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *
```

Array elements marked \* are not used by the routine.
