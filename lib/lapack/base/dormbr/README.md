# dormbr

> Multiplies a general matrix by the orthogonal matrix Q or P from a bidiagonal reduction.

<section class="usage">

## Usage

```javascript
var dormbr = require( '@stdlib/lapack/base/dormbr' );
```

#### dormbr( order, vect, side, trans, M, N, K, A, LDA, TAU, strideTAU, C, LDC, WORK, strideWORK )

Multiplies a general matrix by the orthogonal matrix Q or P from a bidiagonal reduction.

```javascript
var dormbr = require( '@stdlib/lapack/base/dormbr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormbr.ndarray( 'apply-Q', 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **vect**: `'apply-Q'` to apply Q, `'apply-P'` to apply P^T.
-   **side**: specifies the side of the operation.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **K**: inner dimension.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array `TAU`.
-   **strideTAU**: stride length for `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### dormbr.ndarray( vect, side, trans, M, N, K, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Multiplies a general matrix by the orthogonal matrix Q or P from a bidiagonal reduction, using alternative indexing semantics.

```javascript
var dormbr = require( '@stdlib/lapack/base/dormbr' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormbr.ndarray( 'apply-Q', 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DORMBR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

If `VECT = 'Q'`, DORMBR overwrites the general real M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $Q \, C$ | $C \, Q$ |
| `TRANS = 'T'`: | $Q^T \, C$ | $C \, Q^T$ |

If `VECT = 'P'`, DORMBR overwrites the general real M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $P \, C$ | $C \, P$ |
| `TRANS = 'T'`: | $P^T \, C$ | $C \, P^T$ |

Here Q and $P^T$ are the orthogonal matrices determined by DGEBRD when reducing a real matrix A to bidiagonal form: $A = Q \, B \, P^T$. Q and $P^T$ are defined as products of elementary reflectors H(i) and G(i) respectively.

Let $\mathrm{nq} = m$ if `SIDE = 'L'` and $\mathrm{nq} = n$ if `SIDE = 'R'`. Thus nq is the order of the orthogonal matrix Q or $P^T$ that is applied.

If `VECT = 'Q'`, A is assumed to have been an NQ-by-K matrix: if $\mathrm{nq} \ge k$, $Q = H(1)$ H(2) . . . H(k); if $\mathrm{nq} < k$, $Q = H(1)$ H(2) . . . H(nq-1).

If `VECT = 'P'`, A is assumed to have been a K-by-NQ matrix: if $k < \mathrm{nq}$, $P = G(1)$ G(2) . . . G(k); if $k \ge \mathrm{nq}$, $P = G(1)$ G(2) . . . G(nq-1).

### Arguments

#### VECT `[in]`

_CHARACTER\*1_

-   `= 'Q'`: apply Q or $Q^T$;
-   `= 'P'`: apply P or $P^T$.

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q, $Q^T$, P or $P^T$ from the Left;
-   `= 'R'`: apply Q, $Q^T$, P or $P^T$ from the Right.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: No transpose, apply Q  or P;
-   `= 'T'`: Transpose, apply $Q^T$ or $P^T$.

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### K `[in]`

_INTEGER_

If `VECT = 'Q'`, the number of columns in the original matrix reduced by DGEBRD. If `VECT = 'P'`, the number of rows in the original matrix reduced by DGEBRD. $K \ge 0$.

#### A `[in]`

_DOUBLE PRECISION array, dimension (LDA,min(nq,K)) if VECT = 'Q'_

(`LDA`,nq) if `VECT = 'P'` The vectors which define the elementary reflectors H(i) and G(i), whose products determine the matrices Q and P, as returned by DGEBRD.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. If `VECT = 'Q'`, $\mathrm{LDA} \ge \max (1,\mathrm{nq})$; if `VECT = 'P'`, $\mathrm{LDA} \ge \max (1,\min (\mathrm{nq},K))$.

#### TAU `[in]`

_DOUBLE PRECISION array, dimension (min(nq,K))_

`TAU(i)` must contain the scalar factor of the elementary reflector H(i) or G(i) which determines Q or P, as returned by DGEBRD in the array argument TAUQ or TAUP.

#### C `[in,out]`

_DOUBLE PRECISION array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by $Q \, C$ or $Q^T \, C$ or $C \, Q^T$ or $C \, Q$ or $P \, C$ or $P^T \, C$ or $C \, P$ or $C \, P^T$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (MAX(1,LWORK))_

On exit, if `INFO = 0`, `WORK(1)` returns the optimal `LWORK`.

#### LWORK `[in]`

_INTEGER_

The dimension of the array `WORK`. If `SIDE = 'L'`, $\mathrm{LWORK} \ge \max (1,N)$; if `SIDE = 'R'`, $\mathrm{LWORK} \ge \max (1,M)$. For optimum performance $\mathrm{LWORK} \ge N \, \mathrm{NB}$ if `SIDE = 'L'`, and $\mathrm{LWORK} \ge M \, \mathrm{NB}$ if `SIDE = 'R'`, where NB is the optimal blocksize.

If `LWORK = -1`, then a workspace query is assumed; the routine only calculates the optimal size of the `WORK` array, returns this value as the first entry of the `WORK` array, and no error message related to `LWORK` is issued by XERBLA.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
