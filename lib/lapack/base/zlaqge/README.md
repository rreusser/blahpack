# zlaqge

> Scales a general rectangular matrix, using row and column scaling factors computed by sgeequ.

<section class="usage">

## Usage

```javascript
var zlaqge = require( '@stdlib/lapack/base/zlaqge' );
```

#### zlaqge( M, N, A, LDA, r, strideR, c, strideC, rowcnd, colcnd, amax )

Scales a general rectangular matrix, using row and column scaling factors computed by sgeequ.

```javascript
var zlaqge = require( '@stdlib/lapack/base/zlaqge' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var r = discreteUniform( N, -10, 10, opts );
var c = discreteUniform( N, -10, 10, opts );

zlaqge.ndarray( N, N, A, N, 1, 0, r, 1, 0, c, 1, 0, 1, 1, 1, 'none' );
```

The function has the following parameters:

-   **M**: number of rows.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **r**: `r`.
-   **strideR**: stride length for `R`.
-   **c**: `c`.
-   **strideC**: stride length for `C`.
-   **rowcnd**: `rowcnd`.
-   **colcnd**: `colcnd`.
-   **amax**: `amax`.

#### zlaqge.ndarray( M, N, A, strideA1, strideA2, offsetA, r, strideR, offsetR, c, strideC, offsetC, rowcnd, colcnd, amax, equed )

Scales a general rectangular matrix, using row and column scaling factors computed by sgeequ, using alternative indexing semantics.

```javascript
var zlaqge = require( '@stdlib/lapack/base/zlaqge' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var r = discreteUniform( N, -10, 10, opts );
var c = discreteUniform( N, -10, 10, opts );

zlaqge.ndarray( N, N, A, N, 1, 0, r, 1, 0, c, 1, 0, 1, 1, 1, 'none' );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetR**: starting index for `R`.
-   **offsetC**: starting index for `C`.
-   **equed**: `equed`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAQGE`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Scales a general rectangular matrix, using row and column scaling factors computed by sgeequ.

### Purpose

ZLAQGE equilibrates a general M by N matrix A using the row and column scaling factors in the vectors R and C.

### Arguments

#### M `[in]`

_INTEGER_

The number of rows of the matrix A. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix A. $N \ge 0$.

#### A `[in,out]`

_COMPLEX\*16 array, dimension (LDA,N)_

On entry, the M by N matrix A. On exit, the equilibrated matrix. See `EQUED` for the form of the equilibrated matrix.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (M,1)$.

#### R `[in]`

_DOUBLE PRECISION array, dimension (M)_

The row scale factors for A.

#### C `[in]`

_DOUBLE PRECISION array, dimension (N)_

The column scale factors for A.

#### ROWCND `[in]`

_DOUBLE PRECISION_

Ratio of the smallest `R(i)` to the largest `R(i)`.

#### COLCND `[in]`

_DOUBLE PRECISION_

Ratio of the smallest `C(i)` to the largest `C(i)`.

#### AMAX `[in]`

_DOUBLE PRECISION_

Absolute value of largest matrix entry.

#### EQUED `[out]`

_CHARACTER\*1_

Specifies the form of equilibration that was done.

-   `= 'N'`: No equilibration
-   `= 'R'`: Row equilibration, i.e., A has been premultiplied by diag(R).
-   `= 'C'`: Column equilibration, i.e., A has been postmultiplied by diag(C).
-   `= 'B'`: Both row and column equilibration, i.e., A has been replaced by $\operatorname{diag}(R) \, A \, \operatorname{diag}(C)$.
