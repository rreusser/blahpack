
{{alias}}( f, g, c, s, r )
    Generates a plane rotation with real cosine and real sine.

    Parameters
    ----------
    f: number
        First component of the vector to be rotated.

    g: number
        Second component of the vector to be rotated.

    out: Float64Array
        Output array of length at least 3. On return, `out[0] = c`,
        `out[1] = s`, and `out[2] = r`.

    Returns
    -------
    out: Float64Array
        Output array.

    Examples
    --------
    > var out = new {{alias:@stdlib/array/float64}}( 3 );
    > {{alias}}( 3.0, 4.0, out )
    <Float64Array>[ 0.6, 0.8, 5.0 ]
