# dsptrs

> Solves a system of linear equations with a real symmetric matrix in packed storage using the factorization computed by dsptrf.

<section class="usage">

## Usage

```javascript
var dsptrs = require( '@stdlib/lapack/base/dsptrs' );
```

#### dsptrs( uplo, N, nrhs, AP, IPIV, B, LDB )

Solves a system of linear equations with a real symmetric matrix in packed storage using the factorization computed by dsptrf.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Int32Array = require( '@stdlib/array/int32' );
var dsptrs = require( '@stdlib/lapack/base/dsptrs' );

var AP = new Float64Array( [ 4.0, 2.0, 1.0, 5.0, 3.0, 6.0 ] );
var IPIV = new Int32Array( 3 );
var B = new Float64Array( [ 7.0, 10.0, 10.0 ] );

dsptrs( 'lower', 3, 1, AP, IPIV, B, 3 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **nrhs**: number of right-hand sides.
-   **AP**: input array `AP`.
-   **IPIV**: input array `IPIV`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### dsptrs.ndarray( uplo, N, nrhs, AP, strideAP, offsetAP, IPIV, strideIPIV, offsetIPIV, B, strideB1, strideB2, offsetB )

Solves a system of linear equations with a real symmetric matrix in packed storage using the factorization computed by dsptrf, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Int32Array = require( '@stdlib/array/int32' );
var dsptrs = require( '@stdlib/lapack/base/dsptrs' );

var AP = new Float64Array( [ 4.0, 2.0, 1.0, 5.0, 3.0, 6.0 ] );
var IPIV = new Int32Array( 3 );
var B = new Float64Array( [ 7.0, 10.0, 10.0 ] );

dsptrs( 'lower', 3, 1, AP, IPIV, B, 3 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideIPIV**: stride length for `IPIV`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DSPTRS`. Indices are the 1-based Fortran indices of the source.

### Purpose

DSPTRS solves a system of linear equations $A \, X = B$ with a real symmetric matrix A stored in packed format using the factorization $A = U \, D \, U^T$ or $A = L \, D \, L^T$ computed by DSPTRF.
