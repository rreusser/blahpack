# dormr2

> Multiplies a general matrix by the orthogonal matrix from a RQ factorization determined by sgerqf (unblocked algorithm).

<section class="usage">

## Usage

```javascript
var dormr2 = require( '@stdlib/lapack/base/dormr2' );
```

#### dormr2( side, trans, M, N, K, A, LDA, TAU, strideTAU, C, LDC, WORK, strideWORK )

Multiplies a general matrix by the orthogonal matrix from a RQ factorization determined by sgerqf (unblocked algorithm).

```javascript
var dormr2 = require( '@stdlib/lapack/base/dormr2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormr2.ndarray( 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **side**: specifies the side of the operation.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **K**: inner dimension.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array `TAU`.
-   **strideTAU**: stride length for `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### dormr2.ndarray( side, trans, M, N, K, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Multiplies a general matrix by the orthogonal matrix from a RQ factorization determined by sgerqf (unblocked algorithm),, using alternative indexing semantics.

```javascript
var dormr2 = require( '@stdlib/lapack/base/dormr2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormr2.ndarray( 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DORMR2`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Multiplies a general matrix by the orthogonal matrix from a RQ factorization determined by sgerqf (unblocked algorithm).

### Purpose

DORMR2 overwrites the general real m by n matrix C with

$$
Q \, C \quad\text{if}\quad \mathrm{SIDE} = \text{'L'} \quad\text{and}\quad \mathrm{TRANS} = \text{'N'}, \quad\text{or}\quad
$$

$$
Q^T \, C \quad\text{if}\quad \mathrm{SIDE} = \text{'L'} \quad\text{and}\quad \mathrm{TRANS} = \text{'T'}, \quad\text{or}\quad
$$

$$
C \, Q \quad\text{if}\quad \mathrm{SIDE} = \text{'R'} \quad\text{and}\quad \mathrm{TRANS} = \text{'N'}, \quad\text{or}\quad
$$

$$
C \, Q^T \quad\text{if}\quad \mathrm{SIDE} = \text{'R'} \quad\text{and}\quad \mathrm{TRANS} = \text{'T'}
$$

where Q is a real orthogonal matrix defined as the product of k elementary reflectors

$$
Q = H(1) H(2) \cdots H(k)
$$

as returned by DGERQF. Q is of order m if `SIDE = 'L'` and of order n if `SIDE = 'R'`.

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^T$ from the Left
-   `= 'R'`: apply Q or $Q^T$ from the Right

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: apply Q  (No transpose)
-   `= 'T'`: apply Q' (Transpose)

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### K `[in]`

_INTEGER_

The number of elementary reflectors whose product defines the matrix Q. If `SIDE = 'L'`, $M \ge K \ge 0$; if `SIDE = 'R'`, $N \ge K \ge 0$.

#### A `[in]`

_DOUBLE PRECISION array, dimension (LDA,M) if SIDE = 'L'_

(`LDA`,N) if `SIDE = 'R'` The i-th row must contain the vector which defines the elementary reflector H(i), for $i = 1$,2,...,k, as returned by DGERQF in the last k rows of its array argument A. A is modified by the routine but restored on exit.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,K)$.

#### TAU `[in]`

_DOUBLE PRECISION array, dimension (K)_

`TAU(i)` must contain the scalar factor of the elementary reflector H(i), as returned by DGERQF.

#### C `[in,out]`

_DOUBLE PRECISION array, dimension (LDC,N)_

On entry, the m by n matrix C. On exit, C is overwritten by $Q \, C$ or $Q^T \, C$ or $C \, Q^T$ or $C \, Q$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (N) if SIDE = 'L'_

(M) if `SIDE = 'R'`

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
