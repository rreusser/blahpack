# zppsv

> @license Apache-2.0.

<section class="usage">

## Usage

```javascript
var zppsv = require( '@stdlib/lapack/base/zppsv' );
```

#### zppsv( order, uplo, N, nrhs, AP, B, LDB )

@license Apache-2.0.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var zppsv = require( '@stdlib/lapack/base/zppsv' );

var B = new Complex128Array( [ 1.0, 1.0, 2.0, -1.0, 3.0, 0.5 ] );

zppsv.ndarray( 'upper', 3, 1, AP, 1, 0, B, 1, 3, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **nrhs**: number of right-hand sides.
-   **AP**: input array `AP`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### zppsv.ndarray( uplo, N, nrhs, AP, strideAP, offsetAP, B, strideB1, strideB2, offsetB )

@license Apache-2.0, using alternative indexing semantics.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var zppsv = require( '@stdlib/lapack/base/zppsv' );

var B = new Complex128Array( [ 1.0, 1.0, 2.0, -1.0, 3.0, 0.5 ] );

zppsv.ndarray( 'upper', 3, 1, AP, 1, 0, B, 1, 3, 0 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZPPSV`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZPPSV computes the solution to a complex system of linear equations

$$
A \, X = B
$$

where A is an N-by-N Hermitian positive definite matrix stored in packed format and X and B are N-by-`NRHS` matrices.

The Cholesky decomposition is used to factor A as

$$
A = U^H \, U, \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$$
A = L \, L^H, \quad\text{if}\quad \mathrm{UPLO} = \text{'L'}
$$

where U is an upper triangular matrix and L is a lower triangular matrix. The factored form of A is then used to solve the system of equations $A \, X = B$.

### Further Details

The packed storage scheme is illustrated by the following example when $N = 4$, `UPLO = 'U'`:

Two-dimensional storage of the Hermitian matrix A:

a11 a12 a13 a14

a22 a23 a24 a33 a34 (aij = conjg(aji)) a44

Packed storage of the upper triangle of A:

`AP` = \[ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 \]
