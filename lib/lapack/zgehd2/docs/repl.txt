{{alias}}( order, N, ilo, ihi, A, LDA, TAU, strideTAU, WORK )
    Reduces a complex general matrix to upper Hessenberg form using
    unblocked algorithm.

    Parameters
    ----------
    order: string
        storage layout (`'row-major'` or `'column-major'`).

    N: integer
        order of the matrix `A`.

    ilo: integer
        lower index of the balanced matrix (1-based).

    ihi: integer
        upper index of the balanced matrix (1-based).

    A: Complex128Array
        input/output matrix; on exit, the upper Hessenberg matrix and the reflectors.

    LDA: integer
        leading dimension of `A`.

    TAU: Complex128Array
        output array of scalar factors of the elementary reflectors (length `N-1`).

    strideTAU: integer
        stride length for `TAU`.

    WORK: Complex128Array|null
        workspace (or `null` to allocate one internally).

    Returns
    -------
    info: integer
        Status code (0 = success).

    Examples
    --------
    > var A = new {{alias:@stdlib/array/complex128}}( [ 1.0, 0.0, 2.0, 1.0, 3.0, -1.0, 4.0, 0.0 ] );
    > var TAU = new {{alias:@stdlib/array/complex128}}( 1 );

    > var info = {{alias}}( 'column-major', 2, 1, 2, A, 2, TAU, 1, null );
    // returns 0
