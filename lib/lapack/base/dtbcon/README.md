# dtbcon

> Estimates the reciprocal condition number of a real triangular band matrix.

<section class="usage">

## Usage

```javascript
var dtbcon = require( '@stdlib/lapack/base/dtbcon' );
```

#### dtbcon( norm, uplo, diag, N, kd, AB, LDAB, rcond, WORK, IWORK )

Estimates the reciprocal condition number of a real triangular band matrix.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Int32Array = require( '@stdlib/array/int32' );
var dtbcon = require( '@stdlib/lapack/base/dtbcon' );

var rcond = new Float64Array( 1 );
var WORK = new Float64Array( 12 );
var IWORK = new Int32Array( 4 );

dtbcon( 'inf-norm', 'upper', 'non-unit', 4, 2, AB, 3, rcond, WORK, IWORK );
```

The function has the following parameters:

-   **norm**: `norm`.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **diag**: specifies whether the matrix is unit triangular.
-   **N**: number of columns.
-   **kd**: `kd`.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **rcond**: `rcond`.
-   **WORK**: input array `WORK`.
-   **IWORK**: input array `IWORK`.

#### dtbcon.ndarray( norm, uplo, diag, N, kd, AB, strideAB1, strideAB2, offsetAB, rcond, WORK, strideWORK, offsetWORK, IWORK, strideIWORK, offsetIWORK )

Estimates the reciprocal condition number of a real triangular band matrix, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var Int32Array = require( '@stdlib/array/int32' );
var dtbcon = require( '@stdlib/lapack/base/dtbcon' );

var rcond = new Float64Array( 1 );
var WORK = new Float64Array( 12 );
var IWORK = new Int32Array( 4 );

dtbcon( 'inf-norm', 'upper', 'non-unit', 4, 2, AB, 3, rcond, WORK, IWORK );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.
-   **strideIWORK**: stride length for `IWORK`.
-   **offsetIWORK**: starting index for `IWORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DTBCON`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DTBCON estimates the reciprocal of the condition number of a triangular band matrix A, in either the 1-norm or the infinity-norm.

The norm of A is computed and an estimate is obtained for norm(inv(A)), then the reciprocal of the condition number is computed as

$$
\mathrm{RCOND} = 1 / ( \operatorname{norm}(A) \, \operatorname{norm}(\operatorname{inv}(A)) )
$$

### Arguments

#### NORM `[in]`

_CHARACTER\*1_

Specifies whether the 1-norm condition number or the infinity-norm condition number is required: = '1' or 'O': 1-norm;

-   `= 'I'`: Infinity-norm.

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: A is upper triangular;
-   `= 'L'`: A is lower triangular.

#### DIAG `[in]`

_CHARACTER\*1_

-   `= 'N'`: A is non-unit triangular;
-   `= 'U'`: A is unit triangular.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### KD `[in]`

_INTEGER_

The number of superdiagonals or subdiagonals of the triangular band matrix A. $\mathrm{KD} \ge 0$.

#### AB `[in]`

_DOUBLE PRECISION array, dimension (LDAB,N)_

The upper or lower triangular band matrix A, stored in the first kd+1 rows of the array. The j-th column of A is stored in the j-th column of the array `AB` as follows: if `UPLO = 'U'`, `AB(kd+1+i-j,j) = A(i,j)` for $\max (1,j-\mathrm{kd}) \le i \le j$; if `UPLO = 'L'`, `AB(1+i-j,j) = A(i,j)` for $j \le i \le \min (n,j+\mathrm{kd})$. If `DIAG = 'U'`, the diagonal elements of A are not referenced and are assumed to be 1.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge \mathrm{KD}+1$.

#### RCOND `[out]`

_DOUBLE PRECISION_

The reciprocal of the condition number of the matrix A, computed as $\mathrm{RCOND} = 1/(\operatorname{norm}(A) \, \operatorname{norm}(\operatorname{inv}(A)))$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (3\*N)_

#### IWORK `[out]`

_INTEGER array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
