# dormlq

> Multiplies a general real matrix by the orthogonal matrix Q (or its transpose) from an LQ factorization.

<section class="usage">

## Usage

```javascript
var dormlq = require( '@stdlib/lapack/base/dormlq' );
```

#### dormlq( order, side, trans, M, N, K, A, LDA, TAU, strideTAU, C, LDC, WORK, strideWORK )

Multiplies a general real matrix by the orthogonal matrix Q (or its transpose) from an LQ factorization.

```javascript
var dormlq = require( '@stdlib/lapack/base/dormlq' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormlq.ndarray( 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **side**: specifies the side of the operation.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **K**: inner dimension.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array `TAU`.
-   **strideTAU**: stride length for `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### dormlq.ndarray( side, trans, M, N, K, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Multiplies a general real matrix by the orthogonal matrix Q (or its transpose) from an LQ factorization,, using alternative indexing semantics.

```javascript
var dormlq = require( '@stdlib/lapack/base/dormlq' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

dormlq.ndarray( 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DORMLQ`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DORMLQ overwrites the general real M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $Q \, C$ | $C \, Q$ |
| `TRANS = 'T'`: | $Q^T \, C$ | $C \, Q^T$ |

where Q is a real orthogonal matrix defined as the product of k elementary reflectors

$$
Q = H(k) \cdots H(2) H(1)
$$

as returned by DGELQF. Q is of order M if `SIDE = 'L'` and of order N if `SIDE = 'R'`.

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^T$ from the Left;
-   `= 'R'`: apply Q or $Q^T$ from the Right.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: No transpose, apply Q;
-   `= 'T'`: Transpose, apply $Q^T$.

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### K `[in]`

_INTEGER_

The number of elementary reflectors whose product defines the matrix Q. If `SIDE = 'L'`, $M \ge K \ge 0$; if `SIDE = 'R'`, $N \ge K \ge 0$.

#### A `[in]`

_DOUBLE PRECISION array, dimension (LDA,M) if SIDE = 'L'_

(`LDA`,N) if `SIDE = 'R'` The i-th row must contain the vector which defines the elementary reflector H(i), for $i = 1$,2,...,k, as returned by DGELQF in the first k rows of its array argument A.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,K)$.

#### TAU `[in]`

_DOUBLE PRECISION array, dimension (K)_

`TAU(i)` must contain the scalar factor of the elementary reflector H(i), as returned by DGELQF.

#### C `[in,out]`

_DOUBLE PRECISION array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by $Q \, C$ or $Q^T \, C$ or $C \, Q^T$ or $C \, Q$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_DOUBLE PRECISION array, dimension (MAX(1,LWORK))_

On exit, if `INFO = 0`, `WORK(1)` returns the optimal `LWORK`.

#### LWORK `[in]`

_INTEGER_

The dimension of the array `WORK`. If `SIDE = 'L'`, $\mathrm{LWORK} \ge \max (1,N)$; if `SIDE = 'R'`, $\mathrm{LWORK} \ge \max (1,M)$. For good performance, `LWORK` should generally be larger.

If `LWORK = -1`, then a workspace query is assumed; the routine only calculates the optimal size of the `WORK` array, returns this value as the first entry of the `WORK` array, and no error message related to `LWORK` is issued by XERBLA.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
