{{alias}}( uplo, N, A, LDA, IPIV, strideIPIV, anorm, rcond, WORK, strideWORK )
    Estimates the reciprocal of the condition number (in the 1-norm) of a
    complex symmetric matrix A using the factorization A = U·D·Uᵀ or A =
    L·D·Lᵀ computed by ZSYTRF.

    Parameters
    ----------
    uplo: string
        specifies whether the upper or lower triangular part is referenced.

    N: integer
        number of columns.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    IPIV: Int32Array
        `IPIV`.

    strideIPIV: integer
        stride length for `IPIV`.

    anorm: number
        `anorm`.

    rcond: number
        `rcond`.

    WORK: Float64Array
        `WORK`.

    strideWORK: integer
        stride length for `WORK`.

    Returns

    out: Float64Array
