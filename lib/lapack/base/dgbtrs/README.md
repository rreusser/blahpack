# dgbtrs

> Solves a system of linear equations A·X = B or Aᵀ·X = B with a general band matrix A using the LU factorization computed by DGBTRF.

<section class="usage">

## Usage

```javascript
var dgbtrs = require( '@stdlib/lapack/base/dgbtrs' );
```

#### dgbtrs( order, trans, N, kl, ku, nrhs, AB, LDAB, IPIV, strideIPIV, B, LDB )

Solves a system of linear equations A·X = B or Aᵀ·X = B with a general band matrix A using the LU factorization computed by DGBTRF.

```javascript
var dgbtrs = require( '@stdlib/lapack/base/dgbtrs' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

dgbtrs.ndarray( 'no-transpose', N, N, N, N, AB, N, 1, 0, IPIV, 1, 0, B, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **trans**: specifies whether the matrix should be transposed.
-   **N**: number of columns.
-   **kl**: number of subdiagonals.
-   **ku**: number of superdiagonals.
-   **nrhs**: number of right-hand sides.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### dgbtrs.ndarray( trans, N, kl, ku, nrhs, AB, strideAB1, strideAB2, offsetAB, IPIV, strideIPIV, offsetIPIV, B, strideB1, strideB2, offsetB )

Solves a system of linear equations A·X = B or Aᵀ·X = B with a general band matrix A using the LU factorization computed by DGBTRF, using alternative indexing semantics.

```javascript
var dgbtrs = require( '@stdlib/lapack/base/dgbtrs' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

dgbtrs.ndarray( 'no-transpose', N, N, N, N, AB, N, 1, 0, IPIV, 1, 0, B, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DGBTRS`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

DGBTRS solves a system of linear equations

$$
A \, X = B \quad\text{or}\quad A^T \, X = B
$$

with a general band matrix A using the LU factorization computed by DGBTRF.

### Arguments

#### TRANS `[in]`

_CHARACTER\*1_

Specifies the form of the system of equations.

-   `= 'N'`: $A \, X = B$  (No transpose)
-   `= 'T'`: $A^T \, X = B$  (Transpose)
-   `= 'C'`: $A^T \, X = B$  (Conjugate transpose = Transpose)

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### KL `[in]`

_INTEGER_

The number of subdiagonals within the band of A. $\mathrm{KL} \ge 0$.

#### KU `[in]`

_INTEGER_

The number of superdiagonals within the band of A. $\mathrm{KU} \ge 0$.

#### NRHS `[in]`

_INTEGER_

The number of right hand sides, i.e., the number of columns of the matrix B. $\mathrm{NRHS} \ge 0$.

#### AB `[in]`

_DOUBLE PRECISION array, dimension (LDAB,N)_

Details of the LU factorization of the band matrix A, as computed by DGBTRF. U is stored as an upper triangular band matrix with `KL`+`KU` superdiagonals in rows 1 to `KL`+`KU`+1, and the multipliers used during the factorization are stored in rows `KL`+`KU`+2 to $2 \, \mathrm{KL}+\mathrm{KU}+1$.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge 2 \, \mathrm{KL}+\mathrm{KU}+1$.

#### IPIV `[in]`

_INTEGER array, dimension (N)_

The pivot indices; for $1 \le i \le N$, row i of the matrix was interchanged with row `IPIV(i)`.

#### B `[in,out]`

_DOUBLE PRECISION array, dimension (LDB,NRHS)_

On entry, the right hand side matrix B. On exit, the solution matrix X.

#### LDB `[in]`

_INTEGER_

The leading dimension of the array B. $\mathrm{LDB} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
