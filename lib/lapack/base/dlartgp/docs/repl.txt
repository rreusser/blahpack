
{{alias}}( f, g, out )
    Generates a plane rotation with non-negative diagonal.

    Parameters
    ----------
    f: number
        First component of the vector to be rotated.

    g: number
        Second component of the vector to be rotated.

    out: Float64Array
        Output array of length at least 3. On return, `out[0] = cs`,
        `out[1] = sn`, and `out[2] = r` (non-negative).

    Returns
    -------
    out: Float64Array
        Output array.

    Examples
    --------
    > var out = new {{alias:@stdlib/array/float64}}( 3 );
    > {{alias}}( 3.0, 4.0, out )
    <Float64Array>[ 0.6, 0.8, 5.0 ]
