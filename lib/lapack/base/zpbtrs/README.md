# zpbtrs

> Solves a system of linear equations A·X = B with a Hermitian positive definite band matrix A using the Cholesky factorization A = Uᴴ·U or A = L·Lᴴ computed by ZPBTRF.

<section class="usage">

## Usage

```javascript
var zpbtrs = require( '@stdlib/lapack/base/zpbtrs' );
```

#### zpbtrs( order, uplo, N, kd, nrhs, AB, LDAB, B, LDB )

Solves a system of linear equations A·X = B with a Hermitian positive definite band matrix A using the Cholesky factorization A = Uᴴ·U or A = L·Lᴴ computed by ZPBTRF.

```javascript
var zpbtrs = require( '@stdlib/lapack/base/zpbtrs' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );

zpbtrs.ndarray( 'upper', N, 1, N, AB, N, 1, 0, B, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **kd**: `kd`.
-   **nrhs**: number of right-hand sides.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### zpbtrs.ndarray( uplo, N, kd, nrhs, AB, strideAB1, strideAB2, offsetAB, B, strideB1, strideB2, offsetB )

Solves a system of linear equations A·X = B with a Hermitian positive definite band matrix A using the Cholesky factorization A = Uᴴ·U or A = L·Lᴴ computed by ZPBTRF, using alternative indexing semantics.

```javascript
var zpbtrs = require( '@stdlib/lapack/base/zpbtrs' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );

zpbtrs.ndarray( 'upper', N, 1, N, AB, N, 1, 0, B, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZPBTRS`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZPBTRS solves a system of linear equations $A \, X = B$ with a Hermitian positive definite band matrix A using the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$ computed by ZPBTRF.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangular factor stored in `AB`;
-   `= 'L'`: Lower triangular factor stored in `AB`.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### KD `[in]`

_INTEGER_

The number of superdiagonals of the matrix A if `UPLO = 'U'`, or the number of subdiagonals if `UPLO = 'L'`. $\mathrm{KD} \ge 0$.

#### NRHS `[in]`

_INTEGER_

The number of right hand sides, i.e., the number of columns of the matrix B. $\mathrm{NRHS} \ge 0$.

#### AB `[in]`

_COMPLEX\*16 array, dimension (LDAB,N)_

The triangular factor U or L from the Cholesky factorization $A = U^H \, U$ or $A = L \, L^H$ of the band matrix A, stored in the first `KD`+1 rows of the array. The j-th column of U or L is stored in the j-th column of the array `AB` as follows: if `UPLO ='U'`, `AB(kd+1+i-j,j) = U(i,j)` for $\max (1,j-\mathrm{kd}) \le i \le j$; if `UPLO ='L'`, `AB(1+i-j,j) = L(i,j)` for $j \le i \le \min (n,j+\mathrm{kd})$.

#### LDAB `[in]`

_INTEGER_

The leading dimension of the array `AB`. $\mathrm{LDAB} \ge \mathrm{KD}+1$.

#### B `[in,out]`

_COMPLEX\*16 array, dimension (LDB,NRHS)_

On entry, the right hand side matrix B. On exit, the solution matrix X.

#### LDB `[in]`

_INTEGER_

The leading dimension of the array B. $\mathrm{LDB} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
