# zlarnv

> Returns a vector of complex random numbers from a uniform or normal distribution.

<section class="usage">

## Usage

```javascript
var zlarnv = require( '@stdlib/lapack/base/zlarnv' );
```

#### zlarnv( idist, iseed, strideISEED, N, x, stride )

Returns a vector of complex random numbers from a uniform or normal distribution.

```javascript
var zlarnv = require( '@stdlib/lapack/base/zlarnv' );

zlarnv.ndarray( 1, iseed, 1, 0, 5, x, 1, 0 );
```

The function has the following parameters:

-   **idist**: `idist`.
-   **iseed**: `iseed`.
-   **strideISEED**: stride length for `ISEED`.
-   **N**: number of columns.
-   **x**: `x`.
-   **stride**: `stride`.

#### zlarnv.ndarray( idist, iseed, strideISEED, offsetISEED, N, x, stride, offset )

Returns a vector of complex random numbers from a uniform or normal distribution, using alternative indexing semantics.

```javascript
var zlarnv = require( '@stdlib/lapack/base/zlarnv' );

zlarnv.ndarray( 1, iseed, 1, 0, 5, x, 1, 0 );
```

The function has the following additional parameters:

-   **offsetISEED**: starting index for `ISEED`.
-   **offset**: `offset`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLARNV`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Returns a vector of random numbers from a uniform or normal distribution.

### Purpose

ZLARNV returns a vector of n random complex numbers from a uniform or normal distribution.

### Arguments

#### IDIST `[in]`

_INTEGER_

Specifies the distribution of the random numbers:

-   `= 1`: real and imaginary parts each uniform (0,1)
-   `= 2`: real and imaginary parts each uniform (-1,1)
-   `= 3`: real and imaginary parts each normal (0,1)
-   `= 4`: uniformly distributed on the disc $\lvert z \rvert < 1$
-   `= 5`: uniformly distributed on the circle $\lvert z \rvert = 1$

#### ISEED `[in,out]`

_INTEGER array, dimension (4)_

On entry, the seed of the random number generator; the array elements must be between 0 and 4095, and `ISEED(4)` must be odd. On exit, the seed is updated.

#### N `[in]`

_INTEGER_

The number of random numbers to be generated.

#### X `[out]`

_COMPLEX\*16 array, dimension (N)_

The generated random numbers.

### Further Details

This routine calls the auxiliary routine DLARUV to generate random real numbers from a uniform (0,1) distribution, in batches of up to 128 using vectorisable code. The Box-Muller method is used to transform numbers from a uniform to a normal distribution.
