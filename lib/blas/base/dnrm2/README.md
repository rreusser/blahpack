# dnrm2

> Computes the Euclidean norm of a real double-precision vector.

<section class="usage">

## Usage

```javascript
var dnrm2 = require( '@stdlib/blas/base/dnrm2' );
```

#### dnrm2( N, x, stride )

Computes the Euclidean norm of a real double-precision vector.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dnrm2 = require( '@stdlib/blas/base/dnrm2' );

var x = new Float64Array( [ 3.0, 4.0 ] );

dnrm2.ndarray( 2, x, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **x**: `x`.
-   **stride**: `stride`.

#### dnrm2.ndarray( N, x, stride, offset )

Computes the Euclidean norm of a real double-precision vector, using alternative indexing semantics.

```javascript
var Float64Array = require( '@stdlib/array/float64' );
var dnrm2 = require( '@stdlib/blas/base/dnrm2' );

var x = new Float64Array( [ 3.0, 4.0 ] );

dnrm2.ndarray( 2, x, 1, 0 );
```

The function has the following additional parameters:

-   **offset**: `offset`.

## Reference notes

The mathematical description from the reference BLAS 3.12.0 source of `DNRM2`. Indices are the 1-based Fortran indices of the source.

### Purpose

DNRM2 returns the euclidean norm of a vector via the function name, so that

$$
\mathrm{DNRM2} := \sqrt{ x' \, x }
$$

### Further Details
