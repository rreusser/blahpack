# dlasyf

> Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method.

<section class="usage">

## Usage

```javascript
var dlasyf = require( '@stdlib/lapack/base/dlasyf' );
```

#### dlasyf( order, uplo, N, nb, kb, A, LDA, IPIV, strideIPIV, W, LDW )

Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method.

```javascript
var dlasyf = require( '@stdlib/lapack/base/dlasyf' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

dlasyf.ndarray( 'upper', N, N, A, N, 1, 0, IPIV, 1, 0, W, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **nb**: `nb`.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.
-   **W**: input array `W`.
-   **LDW**: leading dimension of `W`.

#### dlasyf.ndarray( uplo, N, nb, kb, A, strideA1, strideA2, offsetA, IPIV, strideIPIV, offsetIPIV, W, strideW1, strideW2, offsetW )

Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method, using alternative indexing semantics.

```javascript
var dlasyf = require( '@stdlib/lapack/base/dlasyf' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var W = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

dlasyf.ndarray( 'upper', N, N, A, N, 1, 0, IPIV, 1, 0, W, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideW1**: stride of dimension 1 of `W`.
-   **strideW2**: stride of dimension 2 of `W`.
-   **offsetW**: starting index for `W`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLASYF`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Computes a partial factorization of a real symmetric matrix using the Bunch-Kaufman diagonal pivoting method.

### Purpose

DLASYF computes a partial factorization of a real symmetric matrix A using the Bunch-Kaufman diagonal pivoting method. The partial factorization has the form:

$$
A = \begin{pmatrix} I & U_{12} \\ 0 & U_{22} \end{pmatrix} \begin{pmatrix} A_{11} & 0 \\ 0 & D \end{pmatrix} \begin{pmatrix} I & 0 \\ U_{12}^T & U_{22}^T \end{pmatrix} \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$A = ( L_{11} 0 )$ ( D 0 ) $( L_{11}^T L_{21}^T )$ if `UPLO = 'L'`

( L21 I ) ( 0 A22 ) ( 0 I )

where the order of D is at most `NB`. The actual order is returned in the argument `KB`, and is either `NB` or `NB`-1, or N if $N \le \mathrm{NB}$.

DLASYF is an auxiliary routine called by DSYTRF. It uses blocked code (calling Level 3 BLAS) to update the submatrix A11 (if `UPLO = 'U'`) or A22 (if `UPLO = 'L'`).

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies whether the upper or lower triangular part of the symmetric matrix A is stored:

-   `= 'U'`: Upper triangular
-   `= 'L'`: Lower triangular

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### NB `[in]`

_INTEGER_

The maximum number of columns of the matrix A that should be factored. `NB` should be at least 2 to allow for 2-by-2 pivot blocks.

#### KB `[out]`

_INTEGER_

The number of columns of A that were actually factored. `KB` is either `NB`-1 or `NB`, or N if $N \le \mathrm{NB}$.

#### A `[in,out]`

_DOUBLE PRECISION array, dimension (LDA,N)_

On entry, the symmetric matrix A. If `UPLO = 'U'`, the leading n-by-n upper triangular part of A contains the upper triangular part of the matrix A, and the strictly lower triangular part of A is not referenced. If `UPLO = 'L'`, the leading n-by-n lower triangular part of A contains the lower triangular part of the matrix A, and the strictly upper triangular part of A is not referenced. On exit, A contains details of the partial factorization.

#### LDA `[in]`

_INTEGER_

The leading dimension of the array A. $\mathrm{LDA} \ge \max (1,N)$.

#### IPIV `[out]`

_INTEGER array, dimension (N)_

Details of the interchanges and the block structure of D.

If `UPLO = 'U'`:

Only the last `KB` elements of `IPIV` are set.

If $\mathrm{IPIV}(k) > 0$, then rows and columns k and `IPIV(k)` were interchanged and D(k,k) is a 1-by-1 diagonal block.

If $\mathrm{IPIV}(k) = \mathrm{IPIV}(k-1) < 0$, then rows and columns k-1 and -`IPIV(k)` were interchanged and D(k-1:k,k-1:k) is a 2-by-2 diagonal block.

If `UPLO = 'L'`:

Only the first `KB` elements of `IPIV` are set.

If $\mathrm{IPIV}(k) > 0$, then rows and columns k and `IPIV(k)` were interchanged and D(k,k) is a 1-by-1 diagonal block.

If $\mathrm{IPIV}(k) = \mathrm{IPIV}(k+1) < 0$, then rows and columns k+1 and -`IPIV(k)` were interchanged and D(k:k+1,k:k+1) is a 2-by-2 diagonal block.

#### W `[out]`

_DOUBLE PRECISION array, dimension (LDW,NB)_

#### LDW `[in]`

_INTEGER_

The leading dimension of the array W. $\mathrm{LDW} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `> 0`: if `INFO = k`, D(k,k) is exactly zero.  The factorization has been completed, but the block diagonal matrix D is exactly singular.
