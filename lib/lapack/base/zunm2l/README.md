# zunm2l

> Multiplies a general matrix by the unitary matrix from a QL factorization determined by cgeqlf (unblocked algorithm).

<section class="usage">

## Usage

```javascript
var zunm2l = require( '@stdlib/lapack/base/zunm2l' );
```

#### zunm2l( side, trans, M, N, K, A, LDA, TAU, strideTAU, C, LDC, WORK, strideWORK )

Multiplies a general matrix by the unitary matrix from a QL factorization determined by cgeqlf (unblocked algorithm).

```javascript
var zunm2l = require( '@stdlib/lapack/base/zunm2l' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zunm2l.ndarray( 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **side**: specifies the side of the operation.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **K**: inner dimension.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.
-   **TAU**: input array `TAU`.
-   **strideTAU**: stride length for `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.
-   **strideWORK**: stride length for `WORK`.

#### zunm2l.ndarray( side, trans, M, N, K, A, strideA1, strideA2, offsetA, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Multiplies a general matrix by the unitary matrix from a QL factorization determined by cgeqlf (unblocked algorithm),, using alternative indexing semantics.

```javascript
var zunm2l = require( '@stdlib/lapack/base/zunm2l' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );
var C = discreteUniform( N * N, -10, 10, opts );
var TAU = discreteUniform( N, -10, 10, opts );
var WORK = discreteUniform( N, -10, 10, opts );

zunm2l.ndarray( 'left', 'no-transpose', N, N, N, A, N, 1, 0, TAU, 1, 0, C, N, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **offsetWORK**: starting index for `WORK`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZUNM2L`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZUNM2L overwrites the general complex m-by-n matrix C with

$$
Q \, C \quad\text{if}\quad \mathrm{SIDE} = \text{'L'} \quad\text{and}\quad \mathrm{TRANS} = \text{'N'}, \quad\text{or}\quad
$$

$$
Q^H \, C \quad\text{if}\quad \mathrm{SIDE} = \text{'L'} \quad\text{and}\quad \mathrm{TRANS} = \text{'C'}, \quad\text{or}\quad
$$

$$
C \, Q \quad\text{if}\quad \mathrm{SIDE} = \text{'R'} \quad\text{and}\quad \mathrm{TRANS} = \text{'N'}, \quad\text{or}\quad
$$

$$
C \, Q^H \quad\text{if}\quad \mathrm{SIDE} = \text{'R'} \quad\text{and}\quad \mathrm{TRANS} = \text{'C'}
$$

where Q is a complex unitary matrix defined as the product of k elementary reflectors

$$
Q = H(k) \cdots H(2) H(1)
$$

as returned by ZGEQLF. Q is of order m if `SIDE = 'L'` and of order n if `SIDE = 'R'`.
