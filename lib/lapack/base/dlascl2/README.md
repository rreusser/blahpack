# dlascl2

> Perform diagonal scaling on a matrix.

<section class="usage">

## Usage

```javascript
var dlascl2 = require( '@stdlib/lapack/base/dlascl2' );
```

#### dlascl2( order, M, N, d, X, LDX )

Perform diagonal scaling on a matrix.

```javascript
var dlascl2 = require( '@stdlib/lapack/base/dlascl2' );

var N = 3;
var X = discreteUniform( N * N, -10, 10, opts );
var d = discreteUniform( N, -10, 10, opts );

dlascl2.ndarray( N, N, d, 1, 0, X, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **M**: number of rows.
-   **N**: number of columns.
-   **d**: `d`.
-   **X**: input array `X`.
-   **LDX**: leading dimension of `X`.

#### dlascl2.ndarray( M, N, d, strideD, offsetD, X, strideX1, strideX2, offsetX )

Perform diagonal scaling on a matrix, using alternative indexing semantics.

```javascript
var dlascl2 = require( '@stdlib/lapack/base/dlascl2' );

var N = 3;
var X = discreteUniform( N * N, -10, 10, opts );
var d = discreteUniform( N, -10, 10, opts );

dlascl2.ndarray( N, N, d, 1, 0, X, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideD**: stride length for `D`.
-   **offsetD**: starting index for `D`.
-   **strideX1**: stride of dimension 1 of `X`.
-   **strideX2**: stride of dimension 2 of `X`.
-   **offsetX**: starting index for `X`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DLASCL2`. Indices are the 1-based Fortran indices of the source.

### Purpose

DLASCL2 performs a diagonal scaling on a matrix:

$$
x <-- D \, x
$$

where the diagonal matrix D is stored as a vector.

Eventually to be replaced by BLAS\_dge\_diag\_scale in the new BLAS standard.
