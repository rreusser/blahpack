# dlartgs

> Generates a plane rotation designed to introduce a bulge in implicit QR iteration for the bidiagonal SVD problem.

<section class="usage">

## Usage

```javascript
var dlartgs = require( '@stdlib/lapack/base/dlartgs' );
```

#### dlartgs( x, y, sigma, cs, sn )

Generates a plane rotation designed to introduce a bulge in implicit QR iteration for the bidiagonal SVD problem.

```javascript
var Float64Array = require( '@stdlib/array/float64' );

var out = new Float64Array( 2 );
dlartgs( 3.0, 4.0, 1.5, out );
// out => <Float64Array>[ ~0.4903, ~0.8716 ]
```

The function has the following parameters:

-   **x**: `(1,1)` entry of an upper bidiagonal matrix.
-   **y**: `(1,2)` entry of an upper bidiagonal matrix.
-   **sigma**: shift.
-   **out**: output [`Float64Array`][mdn-float64array] of length at least `2`.

Returns `out`, with `out[0] = cs` and `out[1] = sn`, where `cs` and `sn` define a plane rotation satisfying `[ cs sn; -sn cs ] * [ x^2 - sigma^2; x*y ] = [ r; 0 ]` with `r >= 0`.

#### dlartgs.ndarray( x, y, sigma, cs, sn )

Generates a plane rotation and writes the result into a preallocated output array.

```javascript
var Float64Array = require( '@stdlib/array/float64' );

var out = new Float64Array( 2 );
dlartgs.ndarray( 3.0, 4.0, 1.5, out );
// out[0] = cs, out[1] = sn
```

The function has the following additional parameters:

-   **out**: output `Float64Array` of length `>= 2`; on return `out[0] = cs` and `out[1] = sn`.

</section>

<section class="notes">

## Notes

-   If `x^2 - sigma^2` and `x*y` are both zero, the rotation is by PI/2.
-   The routine is used as a shift-generation primitive inside Golub-Reinsch-style implicit QR iteration for the bidiagonal SVD.

</section>

## Reference documentation

From the reference LAPACK 3.12.0 source of `DLARTGS`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Generates a plane rotation designed to introduce a bulge in implicit QR iteration for the bidiagonal SVD problem.

### Purpose

DLARTGS generates a plane rotation designed to introduce a bulge in Golub-Reinsch-style implicit QR iteration for the bidiagonal SVD problem. X and Y are the top-row entries, and `SIGMA` is the shift. The computed `CS` and `SN` define a plane rotation satisfying

$$
\begin{bmatrix} \mathrm{CS} & \mathrm{SN} \\ -\mathrm{SN} & \mathrm{CS} \end{bmatrix} \cdot \begin{bmatrix} X^2 - \mathrm{SIGMA} \\ X \, Y \end{bmatrix} = \begin{bmatrix} R \\ 0 \end{bmatrix}
$$

with R nonnegative. If X^2 - `SIGMA` and $X \, Y$ are 0, then the rotation is by PI/2.

### Arguments

#### X `[in]`

_DOUBLE PRECISION_

The (1,1) entry of an upper bidiagonal matrix.

#### Y `[in]`

_DOUBLE PRECISION_

The (1,2) entry of an upper bidiagonal matrix.

#### SIGMA `[in]`

_DOUBLE PRECISION_

The shift.

#### CS `[out]`

_DOUBLE PRECISION_

The cosine of the rotation.

#### SN `[out]`

_DOUBLE PRECISION_

The sine of the rotation.
