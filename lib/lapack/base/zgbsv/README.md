# zgbsv

> Solves a complex system of linear equations `A * X = B` for a banded matrix.

<section class="usage">

## Usage

```javascript
var zgbsv = require( '@stdlib/lapack/base/zgbsv' );
```

#### zgbsv( N, kl, ku, nrhs, AB, LDAB, IPIV, strideIPIV, B, LDB )

Solves a complex system of linear equations `A * X = B` for a banded matrix.

```javascript
var zgbsv = require( '@stdlib/lapack/base/zgbsv' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zgbsv.ndarray( N, N, N, N, AB, N, 1, 0, IPIV, 1, 0, B, N, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **kl**: number of subdiagonals.
-   **ku**: number of superdiagonals.
-   **nrhs**: number of right-hand sides.
-   **AB**: input array `AB`.
-   **LDAB**: leading dimension of `AB`.
-   **IPIV**: input array `IPIV`.
-   **strideIPIV**: stride length for `IPIV`.
-   **B**: input array `B`.
-   **LDB**: leading dimension of `B`.

#### zgbsv.ndarray( N, kl, ku, nrhs, AB, strideAB1, strideAB2, offsetAB, IPIV, strideIPIV, offsetIPIV, B, strideB1, strideB2, offsetB )

Solves a complex system of linear equations `A * X = B` for a banded matrix, using alternative indexing semantics.

```javascript
var zgbsv = require( '@stdlib/lapack/base/zgbsv' );

var N = 3;
var AB = discreteUniform( N * N, -10, 10, opts );
var B = discreteUniform( N * N, -10, 10, opts );
var IPIV = discreteUniform( N, -10, 10, opts );

zgbsv.ndarray( N, N, N, N, AB, N, 1, 0, IPIV, 1, 0, B, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideAB1**: stride of dimension 1 of `AB`.
-   **strideAB2**: stride of dimension 2 of `AB`.
-   **offsetAB**: starting index for `AB`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideB1**: stride of dimension 1 of `B`.
-   **strideB2**: stride of dimension 2 of `B`.
-   **offsetB**: starting index for `B`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZGBSV`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZGBSV computes the solution to a complex system of linear equations $A \, X = B$, where A is a band matrix of order N with `KL` subdiagonals and `KU` superdiagonals, and X and B are N-by-`NRHS` matrices.

The LU decomposition with partial pivoting and row interchanges is used to factor A as $A = L \, U$, where L is a product of permutation and unit lower triangular matrices with `KL` subdiagonals, and U is upper triangular with `KL`+`KU` superdiagonals. The factored form of A is then used to solve the system of equations $A \, X = B$.

### Further Details

The band storage scheme is illustrated by the following example, when $M = N = 6$, `KL = 2`, `KU = 1`:

```text
On entry:                       On exit:
```

```text
 *    *    *    +    +    +       *    *    *   u14  u25  u36
 *    *    +    +    +    +       *    *   u13  u24  u35  u46
 *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
a21  a32  a43  a54  a65   *      m21  m32  m43  m54  m65   *
a31  a42  a53  a64   *    *      m31  m42  m53  m64   *    *
```

Array elements marked \* are not used by the routine; elements marked + need not be set on entry, but are required by the routine to store elements of U because of fill-in resulting from the row interchanges.
