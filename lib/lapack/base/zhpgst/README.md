# zhpgst

> @license Apache-2.0.

<section class="usage">

## Usage

```javascript
var zhpgst = require( '@stdlib/lapack/base/zhpgst' );
```

#### zhpgst( itype, uplo, N, AP, BP )

@license Apache-2.0.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var zhpgst = require( '@stdlib/lapack/base/zhpgst' );

var BP = new Complex128Array( [ 4, 0, 1, 2, 10, 0 ] );
var AP = new Complex128Array( [ 5, 0, 1, -1, 3, 0 ] );

zhpgst( 1, 'upper', 2, AP, BP );
```

The function has the following parameters:

-   **itype**: `itype`.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **BP**: input array `BP`.

#### zhpgst.ndarray( itype, uplo, N, AP, strideAP, offsetAP, BP, strideBP, offsetBP )

@license Apache-2.0, using alternative indexing semantics.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var zhpgst = require( '@stdlib/lapack/base/zhpgst' );

var BP = new Complex128Array( [ 4, 0, 1, 2, 10, 0 ] );
var AP = new Complex128Array( [ 5, 0, 1, -1, 3, 0 ] );

zhpgst( 1, 'upper', 2, AP, BP );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideBP**: stride length for `BP`.
-   **offsetBP**: starting index for `BP`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZHPGST`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZHPGST reduces a complex Hermitian-definite generalized eigenproblem to standard form, using packed storage.

If `ITYPE = 1`, the problem is $A \, x = \lambda \, B \, x$, and A is overwritten by $\operatorname{inv}(U^H) \, A \, \operatorname{inv}(U)$ or $\operatorname{inv}(L) \, A \, \operatorname{inv}(L^H)$

If `ITYPE = 2` or 3, the problem is $A \, B \, x = \lambda \, x$ or $B \, A \, x = \lambda \, x$, and A is overwritten by $U \, A \, U^H$ or $L^H \, A \, L$.

B must have been previously factorized as $U^H \, U$ or $L \, L^H$ by ZPPTRF.

### Arguments

#### ITYPE `[in]`

_INTEGER_

-   `= 1`: compute $\operatorname{inv}(U^H) \, A \, \operatorname{inv}(U)$ or $\operatorname{inv}(L) \, A \, \operatorname{inv}(L^H)$; = 2 or 3: compute $U \, A \, U^H$ or $L^H \, A \, L$.

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangle of A is stored and B is factored as $U^H \, U$;
-   `= 'L'`: Lower triangle of A is stored and B is factored as $L \, L^H$.

#### N `[in]`

_INTEGER_

The order of the matrices A and B. $N \ge 0$.

#### AP `[in,out]`

_COMPLEX\*16 array, dimension (N\*(N+1)/2)_

On entry, the upper or lower triangle of the Hermitian matrix A, packed columnwise in a linear array. The j-th column of A is stored in the array `AP` as follows: if `UPLO = 'U'`, `AP(i + (j-1)*j/2) = A(i,j)` for $1 \le i \le j$; if `UPLO = 'L'`, `AP(i + (j-1)*(2n-j)/2) = A(i,j)` for $j \le i \le n$.

On exit, if `INFO = 0`, the transformed matrix, stored in the same format as A.

#### BP `[in]`

_COMPLEX\*16 array, dimension (N\*(N+1)/2)_

The triangular factor from the Cholesky factorization of B, stored in the same format as A, as returned by ZPPTRF.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
