# zpptrf

> @license Apache-2.0.

<section class="usage">

## Usage

```javascript
var zpptrf = require( '@stdlib/lapack/base/zpptrf' );
```

#### zpptrf( uplo, N, AP )

@license Apache-2.0.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var zpptrf = require( '@stdlib/lapack/base/zpptrf' );

var AP = new Complex128Array( [ 10, 0, 2, 1, 8, 0, 3, -2, 1, 1, 6, 0 ] );

zpptrf( 'upper', 3, AP );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.

#### zpptrf.ndarray( uplo, N, AP, strideAP, offsetAP )

@license Apache-2.0, using alternative indexing semantics.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var zpptrf = require( '@stdlib/lapack/base/zpptrf' );

var AP = new Complex128Array( [ 10, 0, 2, 1, 8, 0, 3, -2, 1, 1, 6, 0 ] );

zpptrf( 'upper', 3, AP );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `ZPPTRF`. Indices are the 1-based Fortran indices of the source.

### Purpose

ZPPTRF computes the Cholesky factorization of a complex Hermitian positive definite matrix A stored in packed format.

The factorization has the form

$$
A = U^H \, U, \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$$
A = L \, L^H, \quad\text{if}\quad \mathrm{UPLO} = \text{'L'}
$$

where U is an upper triangular matrix and L is lower triangular.

### Further Details

The packed storage scheme is illustrated by the following example when $N = 4$, `UPLO = 'U'`:

Two-dimensional storage of the Hermitian matrix A:

a11 a12 a13 a14

a22 a23 a24 a33 a34 (aij = conjg(aji)) a44

Packed storage of the upper triangle of A:

`AP` = \[ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 \]
