# zlar2v

> Apply a vector of complex plane rotations with real cosines from both sides to a sequence of 2-by-2 complex Hermitian matrices.

<section class="usage">

## Usage

```javascript
var zlar2v = require( '@stdlib/lapack/base/zlar2v' );
```

#### zlar2v( N, x, strideX, y, strideY, z, strideZ, c, strideC, s, strideS )

Apply a vector of complex plane rotations with real cosines from both sides to a sequence of 2-by-2 complex Hermitian matrices.

```javascript
var zlar2v = require( '@stdlib/lapack/base/zlar2v' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );
var y = discreteUniform( N, -10, 10, opts );
var z = discreteUniform( N, -10, 10, opts );
var c = discreteUniform( N, -10, 10, opts );
var s = discreteUniform( N, -10, 10, opts );

zlar2v.ndarray( N, x, 1, 0, y, 1, 0, z, 1, 0, c, 1, 0, s, 1, 0 );
```

The function has the following parameters:

-   **N**: number of columns.
-   **x**: `x`.
-   **strideX**: stride length for `X`.
-   **y**: `y`.
-   **strideY**: stride length for `Y`.
-   **z**: `z`.
-   **strideZ**: stride length for `Z`.
-   **c**: `c`.
-   **strideC**: stride length for `C`.
-   **s**: `s`.
-   **strideS**: stride length for `S`.

#### zlar2v.ndarray( N, x, strideX, offsetX, y, strideY, offsetY, z, strideZ, offsetZ, c, strideC, offsetC, s, strideS, offsetS )

Apply a vector of complex plane rotations with real cosines from both sides to a sequence of 2-by-2 complex Hermitian matrices, using alternative indexing semantics.

```javascript
var zlar2v = require( '@stdlib/lapack/base/zlar2v' );

var N = 3;
var x = discreteUniform( N, -10, 10, opts );
var y = discreteUniform( N, -10, 10, opts );
var z = discreteUniform( N, -10, 10, opts );
var c = discreteUniform( N, -10, 10, opts );
var s = discreteUniform( N, -10, 10, opts );

zlar2v.ndarray( N, x, 1, 0, y, 1, 0, z, 1, 0, c, 1, 0, s, 1, 0 );
```

The function has the following additional parameters:

-   **strideX**: stride length for `X`.
-   **offsetX**: starting index for `X`.
-   **strideY**: stride length for `Y`.
-   **offsetY**: starting index for `Y`.
-   **strideZ**: stride length for `Z`.
-   **offsetZ**: starting index for `Z`.
-   **strideC**: stride length for `C`.
-   **offsetC**: starting index for `C`.
-   **strideS**: stride length for `S`.
-   **offsetS**: starting index for `S`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZLAR2V`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Applies a vector of plane rotations with real cosines and complex sines from both sides to a sequence of 2-by-2 symmetric/Hermitian matrices.

### Purpose

ZLAR2V applies a vector of complex plane rotations with real cosines from both sides to a sequence of 2-by-2 complex Hermitian matrices, defined by the elements of the vectors x, y and z. For $i = 1$,2,...,n

$$
\begin{pmatrix} x(i) & z(i) \\ \overline{z(i)} & y(i) \end{pmatrix} :=
$$

$$
\begin{pmatrix} c(i) & \overline{s(i)} \\ -s(i) & c(i) \end{pmatrix} \begin{pmatrix} x(i) & z(i) \\ \overline{z(i)} & y(i) \end{pmatrix} \begin{pmatrix} c(i) & -\overline{s(i)} \\ s(i) & c(i) \end{pmatrix}
$$

### Arguments

#### N `[in]`

_INTEGER_

The number of plane rotations to be applied.

#### X `[in,out]`

_COMPLEX\*16 array, dimension (1+(N-1)\*INCX)_

The vector x; the elements of x are assumed to be real.

#### Y `[in,out]`

_COMPLEX\*16 array, dimension (1+(N-1)\*INCX)_

The vector y; the elements of y are assumed to be real.

#### Z `[in,out]`

_COMPLEX\*16 array, dimension (1+(N-1)\*INCX)_

The vector z.

#### INCX `[in]`

_INTEGER_

The increment between elements of X, Y and Z. $\mathrm{INCX} > 0$.

#### C `[in]`

_DOUBLE PRECISION array, dimension (1+(N-1)\*INCC)_

The cosines of the plane rotations.

#### S `[in]`

_COMPLEX\*16 array, dimension (1+(N-1)\*INCC)_

The sines of the plane rotations.

#### INCC `[in]`

_INTEGER_

The increment between elements of C and S. $\mathrm{INCC} > 0$.
