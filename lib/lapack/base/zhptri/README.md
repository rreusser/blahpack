# zhptri

> Computes the inverse of a complex Hermitian matrix in packed storage using the factorization computed by zhptrf.

<section class="usage">

## Usage

```javascript
var zhptri = require( '@stdlib/lapack/base/zhptri' );
```

#### zhptri( uplo, N, AP, IPIV, WORK )

Computes the inverse of a complex Hermitian matrix in packed storage using the factorization computed by zhptrf.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var Int32Array = require( '@stdlib/array/int32' );
var zhptri = require( '@stdlib/lapack/base/zhptri' );

var AP = new Complex128Array( [ 4.0, 0.0, 1.0, 2.0, 5.0, 0.0 ] );
var IPIV = new Int32Array( 2 );
var WORK = new Complex128Array( 2 );

zhptri.ndarray( 'upper', 2, AP, 1, 0, IPIV, 1, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **IPIV**: input array `IPIV`.
-   **WORK**: input array `WORK`.

#### zhptri.ndarray( uplo, N, AP, strideAP, offsetAP, IPIV, strideIPIV, offsetIPIV, WORK, strideWORK, offsetWORK )

Computes the inverse of a complex Hermitian matrix in packed storage using the factorization computed by zhptrf, using alternative indexing semantics.

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );
var Int32Array = require( '@stdlib/array/int32' );
var zhptri = require( '@stdlib/lapack/base/zhptri' );

var AP = new Complex128Array( [ 4.0, 0.0, 1.0, 2.0, 5.0, 0.0 ] );
var IPIV = new Int32Array( 2 );
var WORK = new Complex128Array( 2 );

zhptri.ndarray( 'upper', 2, AP, 1, 0, IPIV, 1, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideIPIV**: stride length for `IPIV`.
-   **offsetIPIV**: starting index for `IPIV`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZHPTRI`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZHPTRI computes the inverse of a complex Hermitian indefinite matrix A in packed storage using the factorization $A = U \, D \, U^H$ or $A = L \, D \, L^H$ computed by ZHPTRF.

### Arguments

#### UPLO `[in]`

_CHARACTER\*1_

Specifies whether the details of the factorization are stored as an upper or lower triangular matrix.

-   `= 'U'`: Upper triangular, form is $A = U \, D \, U^H$;
-   `= 'L'`: Lower triangular, form is $A = L \, D \, L^H$.

#### N `[in]`

_INTEGER_

The order of the matrix A. $N \ge 0$.

#### AP `[in,out]`

_COMPLEX\*16 array, dimension (N\*(N+1)/2)_

On entry, the block diagonal matrix D and the multipliers used to obtain the factor U or L as computed by ZHPTRF, stored as a packed triangular matrix.

On exit, if `INFO = 0`, the (Hermitian) inverse of the original matrix, stored as a packed triangular matrix. The j-th column of inv(A) is stored in the array `AP` as follows: if `UPLO = 'U'`, AP(i + (j-1)\*j/2) = inv(A)(i,j) for $1 \le i \le j$; if `UPLO = 'L'`,

$$
\mathrm{AP}(i + (j-1) \, (2n-j)/2) = \operatorname{inv}(A)(i,j) \quad\text{for}\quad j \le i \le n
$$

#### IPIV `[in]`

_INTEGER array, dimension (N)_

Details of the interchanges and the block structure of D as determined by ZHPTRF.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (N)_

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
-   `> 0`: if `INFO = i`, $D(i,i) = 0$; the matrix is singular and its inverse could not be computed.
