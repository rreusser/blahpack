{{alias}}( uplo, N, A, LDA, TAU, strideTAU, WORK, strideWORK )
    Generates a complex unitary matrix Q which is defined as the product of
    n-1 elementary reflectors of order N, as returned by ZHETRD: if UPLO =
    'U', Q = H(n-1).

    Parameters
    ----------
    uplo: string
        specifies whether the upper or lower triangular part is referenced.

    N: integer
        number of columns.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    TAU: Float64Array
        `TAU`.

    strideTAU: integer
        stride length for `TAU`.

    WORK: Float64Array
        `WORK`.

    strideWORK: integer
        stride length for `WORK`.

    Returns
    -------
    out: Float64Array
        Result.

    ----------
