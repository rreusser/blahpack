{{alias}}( order, fact, uplo, N, nrhs, A, LDA, AF, LDAF, equed, s, strideS, B, LDB, X, LDX, rcond, FERR, strideFERR, BERR, strideBERR, WORK, IWORK )
    Computes the solution to system of linear equations A·X = B for positive
    definite matrices.

    Parameters
    ----------
    order: string
        Storage layout ('row-major' or 'column-major').

    fact: string
        One of 'not-factored', 'equilibrate', or 'factored'.

    uplo: string
        specifies whether the upper or lower triangular part is referenced.

    N: integer
        number of columns.

    nrhs: integer
        number of right-hand sides.

    A: Float64Array
        `A`.

    LDA: integer
        leading dimension of `A`.

    AF: Float64Array
        `AF`.

    LDAF: integer
        leading dimension of `AF`.

    equed: string
        `equed`.

    s: Float64Array
        `s`.

    strideS: integer
        stride length for `S`.

    B: Float64Array
        `B`.

    LDB: integer
        leading dimension of `B`.

    X: Float64Array
        `X`.

    LDX: integer
        leading dimension of `X`.

    rcond: Float64Array
        Output array; on return, `rcond[0]` is the reciprocal condition
        number estimate.

    FERR: Float64Array
        `FERR`.

    strideFERR: integer
        stride length for `FERR`.

    BERR: Float64Array
        `BERR`.

    strideBERR: integer
        stride length for `BERR`.

    WORK: Float64Array|null
        Workspace of length at least 3*N (allocated if null).

    IWORK: Int32Array|null
        Integer workspace of length at least N (allocated if null).

    Returns
    -------
    out: Object
        Result with properties `info`, `equed`, and `rcond`.
