# zunm22

> Multiplies a general matrix by a unitary matrix

<section class="usage">

## Usage

```javascript
var zunm22 = require( '@stdlib/lapack/base/zunm22' );
```

#### zunm22( order, side, trans, M, N, n1, n2, Q, LDQ, C, LDC, WORK, strideWORK, lwork )

Multiplies a general matrix by a unitary matrix

```javascript
var Complex128Array = require( '@stdlib/array/complex128' );

var Q = new Complex128Array( 25 );
var C = new Complex128Array( 20 );
```

<section class="notes">

## Notes

-   The unitary matrix `Q` has block form `Q = [[Q11, Q12], [Q21, Q22]]` where `Q11` is `N1 x N2`, `Q12` is `N1 x N1` lower triangular, `Q21` is `N2 x N2` upper triangular, and `Q22` is `N2 x N1`. The routine computes one of `Q*C`, `Q**H*C`, `C*Q`, or `C*Q**H`, overwriting `C`.

</section>

<section class="examples">

## Examples

```javascript
var uniform = require( '@stdlib/random/array/uniform' );
var Complex128Array = require( '@stdlib/array/complex128' );
var zunm22 = require( '@stdlib/lapack/base/zunm22' );

var M = 5;
var N = 4;
var n1 = 3;
var n2 = 2;

var opts = { 'dtype': 'float64' };
var Q = new Complex128Array( uniform( 2 * M * M, -1.0, 1.0, opts ).buffer );
var C = new Complex128Array( uniform( 2 * M * N, -1.0, 1.0, opts ).buffer );
var WORK = new Complex128Array( M * N );

var info = zunm22( 'column-major', 'left', 'no-transpose', M, N, n1, n2, Q, M, C, M, WORK, 1, M * N );
console.log( info );
```

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZUNM22`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

> Multiplies a general matrix by a banded unitary matrix.

### Purpose

ZUNM22 overwrites the general complex M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $Q \, C$ | $C \, Q$ |
| `TRANS = 'C'`: | $Q^H \, C$ | $C \, Q^H$ |

where Q is a complex unitary matrix of order NQ, with $\mathrm{NQ} = M$ if `SIDE = 'L'` and $\mathrm{NQ} = N$ if `SIDE = 'R'`. The unitary matrix Q processes a 2-by-2 block structure

$$
Q = \begin{bmatrix} Q_{11} & Q_{12} \\  &  \\ Q_{21} & Q_{22} \end{bmatrix}
$$

where Q12 is an `N1`-by-`N1` lower triangular matrix and Q21 is an `N2`-by-`N2` upper triangular matrix.

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^H$ from the Left;
-   `= 'R'`: apply Q or $Q^H$ from the Right.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: apply Q (No transpose);
-   `= 'C'`: apply $Q^H$ (Conjugate transpose).

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### N1 `[in]`

#### N2 `[in]`

`N1` is INTEGER `N2` is INTEGER The dimension of Q12 and Q21, respectively. `N1`, $N_{2} \ge 0$. The following requirement must be satisfied: $N_{1} + N_{2} = M$ if `SIDE = 'L'` and $N_{1} + N_{2} = N$ if `SIDE = 'R'`.

#### Q `[in]`

_COMPLEX\*16 array, dimension (LDQ,M) if SIDE = 'L'_

(`LDQ`,N) if `SIDE = 'R'`

#### LDQ `[in]`

_INTEGER_

The leading dimension of the array Q. $\mathrm{LDQ} \ge \max (1,M)$ if `SIDE = 'L'`; $\mathrm{LDQ} \ge \max (1,N)$ if `SIDE = 'R'`.

#### C `[in,out]`

_COMPLEX\*16 array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by $Q \, C$ or $Q^H \, C$ or $C \, Q^H$ or $C \, Q$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (MAX(1,LWORK))_

On exit, if `INFO = 0`, `WORK(1)` returns the optimal `LWORK`.

#### LWORK `[in]`

_INTEGER_

The dimension of the array `WORK`. If `SIDE = 'L'`, $\mathrm{LWORK} \ge \max (1,N)$; if `SIDE = 'R'`, $\mathrm{LWORK} \ge \max (1,M)$. For optimum performance $\mathrm{LWORK} \ge M \, N$.

If `LWORK = -1`, then a workspace query is assumed; the routine only calculates the optimal size of the `WORK` array, returns this value as the first entry of the `WORK` array, and no error message related to `LWORK` is issued by XERBLA.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
