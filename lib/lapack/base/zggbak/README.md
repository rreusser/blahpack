# zggbak

> Back-transform eigenvectors of a balanced pair of general real matrices.

<section class="usage">

## Usage

```javascript
var zggbak = require( '@stdlib/lapack/base/zggbak' );
```

#### zggbak( order, job, side, N, ilo, ihi, LSCALE, strideLSCALE, RSCALE, strideRSCALE, M, V, LDV )

Back-transform eigenvectors of a balanced pair of general real matrices.

```javascript
var zggbak = require( '@stdlib/lapack/base/zggbak' );

var N = 3;
var V = discreteUniform( N * N, -10, 10, opts );
var LSCALE = discreteUniform( N, -10, 10, opts );
var RSCALE = discreteUniform( N, -10, 10, opts );

zggbak.ndarray( 'both', 'left', N, N, N, LSCALE, 1, 0, RSCALE, 1, 0, N, V, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **job**: `job`.
-   **side**: specifies the side of the operation.
-   **N**: number of columns.
-   **ilo**: `ilo`.
-   **ihi**: `ihi`.
-   **LSCALE**: input array `LSCALE`.
-   **strideLSCALE**: stride length for `LSCALE`.
-   **RSCALE**: input array `RSCALE`.
-   **strideRSCALE**: stride length for `RSCALE`.
-   **M**: number of rows.
-   **V**: input array `V`.
-   **LDV**: leading dimension of `V`.

#### zggbak.ndarray( job, side, N, ilo, ihi, LSCALE, strideLSCALE, offsetLSCALE, RSCALE, strideRSCALE, offsetRSCALE, M, V, strideV1, strideV2, offsetV )

Back-transform eigenvectors of a balanced pair of general real matrices, using alternative indexing semantics.

```javascript
var zggbak = require( '@stdlib/lapack/base/zggbak' );

var N = 3;
var V = discreteUniform( N * N, -10, 10, opts );
var LSCALE = discreteUniform( N, -10, 10, opts );
var RSCALE = discreteUniform( N, -10, 10, opts );

zggbak.ndarray( 'both', 'left', N, N, N, LSCALE, 1, 0, RSCALE, 1, 0, N, V, N, 1, 0 );
```

The function has the following additional parameters:

-   **offsetLSCALE**: starting index for `LSCALE`.
-   **offsetRSCALE**: starting index for `RSCALE`.
-   **strideV1**: stride of dimension 1 of `V`.
-   **strideV2**: stride of dimension 2 of `V`.
-   **offsetV**: starting index for `V`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZGGBAK`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZGGBAK forms the right or left eigenvectors of a complex generalized eigenvalue problem $A \, x = \lambda \, B \, x$, by backward transformation on the computed eigenvectors of the balanced pair of matrices output by ZGGBAL.

### Arguments

#### JOB `[in]`

_CHARACTER\*1_

Specifies the type of backward transformation required:

-   `= 'N'`: do nothing, return immediately;
-   `= 'P'`: do backward transformation for permutation only;
-   `= 'S'`: do backward transformation for scaling only;
-   `= 'B'`: do backward transformations for both permutation and scaling. `JOB` must be the same as the argument `JOB` supplied to ZGGBAL.

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'R'`: V contains right eigenvectors;
-   `= 'L'`: V contains left eigenvectors.

#### N `[in]`

_INTEGER_

The number of rows of the matrix V. $N \ge 0$.

#### ILO `[in]`

_INTEGER_

#### IHI `[in]`

_INTEGER_

The integers `ILO` and `IHI` determined by ZGGBAL. $1 \le \mathrm{ILO} \le \mathrm{IHI} \le N$, if $N > 0$; `ILO=1` and `IHI=0`, if $N=0$.

#### LSCALE `[in]`

_DOUBLE PRECISION array, dimension (N)_

Details of the permutations and/or scaling factors applied to the left side of A and B, as returned by ZGGBAL.

#### RSCALE `[in]`

_DOUBLE PRECISION array, dimension (N)_

Details of the permutations and/or scaling factors applied to the right side of A and B, as returned by ZGGBAL.

#### M `[in]`

_INTEGER_

The number of columns of the matrix V. $M \ge 0$.

#### V `[in,out]`

_COMPLEX\*16 array, dimension (LDV,M)_

On entry, the matrix of right or left eigenvectors to be transformed, as returned by ZTGEVC. On exit, V is overwritten by the transformed eigenvectors.

#### LDV `[in]`

_INTEGER_

The leading dimension of the matrix V. $\mathrm{LDV} \ge \max (1,N)$.

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit.
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value.

### Further Details

See R.C. Ward, Balancing the generalized eigenvalue problem,

SIAM J. Sci. Stat. Comp. 2 (1981), 141-152.
