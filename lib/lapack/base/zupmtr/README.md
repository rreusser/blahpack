# zupmtr

> Overwrites a general complex matrix with a transformation from the unitary matrix Q returned by zhptrd.

<section class="usage">

## Usage

```javascript
var zupmtr = require( '@stdlib/lapack/base/zupmtr' );
```

#### zupmtr( side, uplo, trans, M, N, AP, TAU, C, LDC, WORK )

Overwrites a general complex matrix with a transformation from the unitary matrix Q returned by zhptrd.

```javascript
var zupmtr = require( '@stdlib/lapack/base/zupmtr' );

zupmtr.ndarray( 'left', 'upper', 'no-transpose', 4, 4, AP, 1, 0, TAU, 1, 0, C, 1, 4, 0, WORK, 1, 0 );
```

The function has the following parameters:

-   **side**: specifies the side of the operation.
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **trans**: specifies whether the matrix should be transposed.
-   **M**: number of rows.
-   **N**: number of columns.
-   **AP**: input array `AP`.
-   **TAU**: input array `TAU`.
-   **C**: input array `C`.
-   **LDC**: leading dimension of `C`.
-   **WORK**: input array `WORK`.

#### zupmtr.ndarray( side, uplo, trans, M, N, AP, strideAP, offsetAP, TAU, strideTAU, offsetTAU, C, strideC1, strideC2, offsetC, WORK, strideWORK, offsetWORK )

Overwrites a general complex matrix with a transformation from the unitary matrix Q returned by zhptrd, using alternative indexing semantics.

```javascript
var zupmtr = require( '@stdlib/lapack/base/zupmtr' );

zupmtr.ndarray( 'left', 'upper', 'no-transpose', 4, 4, AP, 1, 0, TAU, 1, 0, C, 1, 4, 0, WORK, 1, 0 );
```

The function has the following additional parameters:

-   **strideAP**: stride length for `AP`.
-   **offsetAP**: starting index for `AP`.
-   **strideTAU**: stride length for `TAU`.
-   **offsetTAU**: starting index for `TAU`.
-   **strideC1**: stride of dimension 1 of `C`.
-   **strideC2**: stride of dimension 2 of `C`.
-   **offsetC**: starting index for `C`.
-   **strideWORK**: stride length for `WORK`.
-   **offsetWORK**: starting index for `WORK`.

## Reference documentation

From the reference LAPACK 3.12.0 source of `ZUPMTR`, converted to Markdown with KaTeX math. Indices are the 1-based Fortran indices of the source.

### Purpose

ZUPMTR overwrites the general complex M-by-N matrix C with

|   | `SIDE = 'L'` | `SIDE = 'R'` |
| --- | --- | --- |
| `TRANS = 'N'`: | $Q \, C$ | $C \, Q$ |
| `TRANS = 'C'`: | $Q^H \, C$ | $C \, Q^H$ |

where Q is a complex unitary matrix of order nq, with $\mathrm{nq} = m$ if `SIDE = 'L'` and $\mathrm{nq} = n$ if `SIDE = 'R'`. Q is defined as the product of nq-1 elementary reflectors, as returned by ZHPTRD using packed storage:

if `UPLO = 'U'`, $Q = H(\mathrm{nq}-1)$ . . . H(2) H(1);

if `UPLO = 'L'`, $Q = H(1)$ H(2) . . . H(nq-1).

### Arguments

#### SIDE `[in]`

_CHARACTER\*1_

-   `= 'L'`: apply Q or $Q^H$ from the Left;
-   `= 'R'`: apply Q or $Q^H$ from the Right.

#### UPLO `[in]`

_CHARACTER\*1_

-   `= 'U'`: Upper triangular packed storage used in previous call to ZHPTRD;
-   `= 'L'`: Lower triangular packed storage used in previous call to ZHPTRD.

#### TRANS `[in]`

_CHARACTER\*1_

-   `= 'N'`: No transpose, apply Q;
-   `= 'C'`: Conjugate transpose, apply $Q^H$.

#### M `[in]`

_INTEGER_

The number of rows of the matrix C. $M \ge 0$.

#### N `[in]`

_INTEGER_

The number of columns of the matrix C. $N \ge 0$.

#### AP `[in]`

_COMPLEX\*16 array, dimension (M\*(M+1)/2) if SIDE = 'L'_

(N\*(N+1)/2) if `SIDE = 'R'` The vectors which define the elementary reflectors, as returned by ZHPTRD. `AP` is modified by the routine but restored on exit.

#### TAU `[in]`

_COMPLEX\*16 array, dimension (M-1) if SIDE = 'L'_

or (N-1) if `SIDE = 'R'` `TAU(i)` must contain the scalar factor of the elementary reflector H(i), as returned by ZHPTRD.

#### C `[in,out]`

_COMPLEX\*16 array, dimension (LDC,N)_

On entry, the M-by-N matrix C. On exit, C is overwritten by $Q \, C$ or $Q^H \, C$ or $C \, Q^H$ or $C \, Q$.

#### LDC `[in]`

_INTEGER_

The leading dimension of the array C. $\mathrm{LDC} \ge \max (1,M)$.

#### WORK `[out]`

_COMPLEX\*16 array, dimension (N) if SIDE = 'L'_

(M) if `SIDE = 'R'`

#### INFO `[out]`

_INTEGER_

-   `= 0`: successful exit
-   `< 0`: if `INFO = -i`, the i-th argument had an illegal value
