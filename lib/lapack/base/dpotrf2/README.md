# dpotrf2

> Computes the Cholesky factorization of a real symmetric positive definite matrix A using the recursive algorithm.

<section class="usage">

## Usage

```javascript
var dpotrf2 = require( '@stdlib/lapack/base/dpotrf2' );
```

#### dpotrf2( order, uplo, N, A, LDA )

Computes the Cholesky factorization of a real symmetric positive definite matrix A using the recursive algorithm.

```javascript
var dpotrf2 = require( '@stdlib/lapack/base/dpotrf2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

dpotrf2.ndarray( 'upper', N, A, N, 1, 0 );
```

The function has the following parameters:

-   **order**: storage layout (`'row-major'` or `'column-major'`).
-   **uplo**: specifies whether the upper or lower triangular part is referenced.
-   **N**: number of columns.
-   **A**: input array `A`.
-   **LDA**: leading dimension of `A`.

#### dpotrf2.ndarray( uplo, N, A, strideA1, strideA2, offsetA )

Computes the Cholesky factorization of a real symmetric positive definite matrix A using the recursive algorithm, using alternative indexing semantics.

```javascript
var dpotrf2 = require( '@stdlib/lapack/base/dpotrf2' );

var N = 3;
var A = discreteUniform( N * N, -10, 10, opts );

dpotrf2.ndarray( 'upper', N, A, N, 1, 0 );
```

The function has the following additional parameters:

-   **strideA1**: stride of dimension 1 of `A`.
-   **strideA2**: stride of dimension 2 of `A`.
-   **offsetA**: starting index for `A`.

## Reference notes

The mathematical description from the reference LAPACK 3.12.0 source of `DPOTRF2`. Indices are the 1-based Fortran indices of the source.

### Purpose

DPOTRF2 computes the Cholesky factorization of a real symmetric positive definite matrix A using the recursive algorithm.

The factorization has the form

$$
A = U^T \, U, \quad\text{if}\quad \mathrm{UPLO} = \text{'U'}, \quad\text{or}\quad
$$

$$
A = L \, L^T, \quad\text{if}\quad \mathrm{UPLO} = \text{'L'}
$$

where U is an upper triangular matrix and L is lower triangular.

This is the recursive version of the algorithm. It divides the matrix into four submatrices:

```text
    [  A11 | A12  ]  where A11 is n1 by n1 and A22 is n2 by n2
A = [ -----|----- ]  with n1 = n/2
    [  A21 | A22  ]       n2 = n-n1
```

The subroutine calls itself to factor A11. Update and scale A21 or A12, update A22 then calls itself to factor A22.
